# CPU: независимый объём растворителя

Единицы согласованы с основной гипотезой: loaded-contact V, headroom 4; исходное coverage 0..1 используется только как суррогат исходного V. Это не захваченный независимый solvent film.

Оператор: q=0.12*(Vi-Vj) на мокрых соседях, исходящий q ограничен 0.45*Vi, перенос каждого компонента P/C = q*(component/Vi) до изменения V. По каждой грани одинаковые take/land сохраняют сумму. 240 шагов на сетке 4px.

Дополнительный источник ограничен конечным бюджетом 0/0.25/0.5/1/2 от воды source, равномерно внутри source, только при наличии moving contacts. Это deliberately upper-bound/source sensitivity experiment, не восстановленный реальный расход кисти; recorded length/radius и waterLoad ещё не используются. Blob без движущихся контактов не получает дополнительный источник. Это контроль, не физическое правило неподвижной кисти.

Спираль: outside carrier 0.377% без источника, 0.996/1.555/2.384/3.320% по бюджетам. Даже запас воды порядка двойной исходной плёнки не даёт сильного распространения за 240 локальных шагов. Следовательно одного восстановления объёма недостаточно: пространственный диапазон/время flux оператора остаётся вторым limiter. Эти значения не сравнимы напрямую с итоговыми carry/settle PNG.

Массы 8 каналов сохраняются до 3e-11, воды до 4e-12, постоянная концентрация до 2e-14. Канал 0 — фактический pre-front P.a, 7 других синтетические; доказательство алгебраическое, не full actual RGBA GPU QA. Blob source dose не равна spiral dose. GPU не запускался. Не кандидат к интеграции.
