Ночной онлайн-QA #745, найдено при проверке совместной акварели с карандашом и ластиком.

Undo запускает пересборку слоя, пока другой участник ещё держит обычный инструмент. Пиксели незаписанного живого мазка исчезают до его UP. Журнал позднее способен восстановить результат, но во время рисования след пропадает. Четыре actual-pixel regression воспроизвели проблему, включая собственный удерживаемый карандаш.

Нужно дождаться безопасной границы только для затронутого слоя, сохранить живые пиксели, затем пересобрать по принятому журналу. Commit, cancel и disconnect/поздняя операция должны отпускать ожидание корректно; другой слой должен отменяться сразу. Структурное удаление слоя не превращать в бесконечное ожидание.

Подготовлен изолированный локальный кандидат, аппаратный повтор предстоит. Release track #314. Без push/deploy.
