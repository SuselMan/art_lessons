# #728: следующая фактическая Room matrix (контроллер и границы проверок)

Контроллер `matrix.mjs`, source immutable/APP_URL/WC_QA_HEAD/WC_RELEASE_ROOT обязательны. Root frontend5322/backend4538 сейчас защищены iPad; запуск только после grant/freeze. Один Chrome, максимум два auth-context/page одновременно, viewport640×480, кисть100. Физическая комната создаётся Custom 640×480; model.width/height сохраняются, размер PNG проверяется отдельно.

Сценарий: A чистая вода → B dry pigment той же траекторией → A второй цвет пересекает → UI sharedDry → A undo/redo своего второго цветного мазка (Dry остаётся done) → B собственный undo/redo → новый слой A/рисование/перемещение/скрыть/показать/удалить/undo/redo удаления → finalUI Dry → обычный reload B → новый третий auth late join (B закрыт перед C).

Undo чужого авторства не поддерживается OperationLog.applyUndo по userId; его нельзя выдавать за global undo. Общая сушка проверяется как серверная операция, но не отменяется; структурное undo проверяется на удалении слоя. Layer-команды идут через настоящий engine local append → Room onLocalOperation → Outbox → сервер; это **shared renderer/network QA, не слой-panel UI coverage**. Dry запускается видимой UI кнопкой. Без ручного snapshot POST: ждём реальный first-copy index, затем latejoin должен загрузить настоящий persisted layer blob.

Каждый барьер требует одинаковые упорядоченные LogEntry/state/serverSeq до snapshot; после snapshot допускается отсутствие покрытых operation_undo/redo, но все strokes, состояния и tail обязаны совпасть; historical seq подтверждается HTTP operations, отсутствие pending/settle/op/rebuild/reveal/live, одинаковую shared структуру слоёв; вид локального active/selected не сравнивается. LayerState сравнивается с нормализацией порядка ключей объектов. Canonical wholePNG nonempty и byte/premult comparison на одной Vega; поле влажности pigment должно быть реально записано. Любая delta останавливает как unresolved, не округляется до PASS. Snapshot и latejoin без HTTP blob не считаются подтверждёнными. CrossGPU потребует отдельного фактического отчёта без требования побайтного равенства разныхGPU.

CPU: node --check +preflight.mjs PASS, fixtures/именаопераций сверены с текущими shared контрактами. Сохранены частичные аппаратные прогоны; их ограничения перечисляются в отдельных отчётах. Outer360s, perbarrier30s, finally закрывает только собственный Chrome. Реальные selectors/permissions/backend/sourcepassport требуют hardware исполнения; dry-run не означает runtime PASS.

Семантический контроллер semantic.mjs: B undo до A второго цвета и после; полный журнал сериализуется из _log.entries.map(e => e.op), не doneOperations. Чистый PencilEngine получает тот же journal/paper/page и whole PNG сравнивается с текущим. Peer agreement само по себе не доказывает корректность undo.
