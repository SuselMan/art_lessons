# Hierarchical integer bins

The theorem is valid given byte-level input cones R,G,B≤A, depth RGB≤B, C.A=B, globally identical edge evaluation and closed boundaries. Set outgoing carrier bins floor(A*f), additionally ≤floor(recipientRoom/4), and stay=A−sum. Raw donor CFL<1 implies nonnegative stay. Each recipient has≤4 incoming bins, each≤floor(room/4), hence updated A≤255 even before subtracting outgoing. Arbitrary carrier/physical mass sums telescope exactly in integer arithmetic.

For channel total T≤sum bins S, distribute floor(T*b_i/S), then one extra unit to the L largest remainders with fixed tie ordering. Sum=T. Each allocated bin≤b_i: floor reaches capacity only when T=S, which has zero remainders and no leftovers; otherwise positive-remainder bins have free capacity. Hierarchy carrier→pigment→depth preserves all input byte cones, all channel totals, and color alpha must be assigned EXACT pigment bin, not independently rounded. Water/wet each use carrier bins. P5B4 with four carrier flux1 and stay1 allocates pigment [1,1,1,1,0] under fixed outgoing-first ties; depth4 same, so no P1/D4 orphan. This tie convention empties donor pigment before carrier and may create strong directional/stay bias. Alternative stay-first ties changes physics, though theorem remains.

CPU100k donor checks and periodic1D100steps pass exact totals/cones/capacity; proof.json records counts. Input violations from existing quantized pipeline cannot be repaired while preserving all original channel totals and strict cones. Specifically C.A != P.B needs a chosen authority/reconciliation, and Dbyte>Bbyte cannot be redistributed under this theorem. Audit actual fields first.

Locking persists: A=1 gives floor(A*f)=0 for every f<1, so no carrier movement. Conditional pigment allocation can send disproportionately concentrated pigment on tiny carrier bins: conservation doesn't preserve original ratio/tau per bin, only bounds. Fixed sorting ties produce grid/direction artefacts, repeated substeps can freeze more than float transport.

GPU recomputation: each recipient needs complete allocation for own donor plus four neighbouring donors, each donor four raw edge fractions and receiver rooms, 5-bin carrier, 5-bin pigment, and 3 depth +water/wet allocations. Naive full RGBA paths require roughly 5 donors×4 raw edges=20 edge evaluations per fragment plus at least 7 five-bin allocations and remainder comparisons per donor. Physical and color programs must reconstruct identical pigment bins from u_pigment; depth allocations additionally require donor u_paint.rgb. Static GLSL five scalar bins and pairwise rank sorting avoid dynamic arrays/loops, but ~20 comparisons per channel and numerous integer-valued float operations. ES1 highp float multiplication of 255*255 stays exactly representable; division/floor near integers needs care (CPU integer numerator/remainder cannot be directly assumed GLSL stable). No cheap Adreno claim, no GPU spec yet.
