# Конечный поглощающий и рассеивающий слой: диагностическая альтернатива

Источник первичной реализации: [NIST SCATMECH reflectance.cpp](https://pages.nist.gov/SCATMECH/code/reflectance.cpp), параметры и область модели: [официальная документация NIST](https://pages.nist.gov/SCATMECH/docs/reflectance.htm). Код NIST отдельно обрабатывает отсутствие поглощения и отсутствие рассеяния; коэффициенты имеют обратные единицы толщины. Ниже собственный вывод устойчивой эквивалентной записи и проверка границ, не цитата NIST. RGB — инженерная аппроксимация спектра.

## Вывод

Два встречных диффузных потока I+, I- в однородном слое:
I+'=-(K+S)I+ + S I-; I-'=(K+S)I- - S I+.
K,S,d >=0. Для свободного симметричного слоя a=1+K/S, b=sqrt(a*a-1), h=b*S*d.
R=sinh(h)/(a*sinh(h)+b*cosh(h)), T=b/(a*sinh(h)+b*cosh(h)).

Устойчивая форма без растущего exp: L=Kd,Q=Sd,H=sqrt(L*(L+2Q)), E=exp(-H), Z=1-exp(-2H), D=(L+Q)*Z+H*(1+E*E).
R=Q*Z/D; T=2H*E/D.
Для H<1e-3 в GLSL вместо вычитания близких чисел использовать Z≈2H*(1-H+2H²/3); CPU использует -expm1(-2H).

Пределы: d=0 → R=0,T=1. S=0 → R=0,T=exp(-Kd).
K=0,S>0 → R=Sd/(1+Sd),T=1/(1+Sd).
Толстый поглощающий слой: T→0,R→S/(K+S+sqrt(K*(K+2S)))=1/(a+b).
При K=0,d→∞: R→1,T→0. Никакого деления на ноль в специальных ветках.

Подложка с отражением B∈[0,1]: R_total=R+T²*B/(1-R*B). Это сумма обратных отражений в слое; при чистом поглощении R_total=B*exp(-2Kd), что совпадает с веткой NIST. Белая бумага B=1.

## Пассивность и границы

При K,S,d≥0 все числители неотрицательны. В форме a,b,E:
D0=a*(1-E²)+b*(1+E²).
D0 - [(1-E²)+2bE] = (a-1)*(1-E²)+b*(1-E)² ≥0.
Следовательно 0≤R,T≤1 и R+T≤1. Для подложки B≤1:
R_total≤R+T²/(1-R)≤R+(1-R)²/(1-R)=1.
Доказательство относится к однородному пассивному слою, не к точности RGB и GPU округлениям. CPU audit.py проверил 20000 случайных положительных троек K,S,d и B, включая широкий диапазон масштабов. examples.json содержит пять калиброванных плёнок.

## Калибровка без условий по листам

Текущий tau=-log(max(color,.02)) — безразмерная RGB-плотность, не измеренный спектральный K. Абсолютную толщину и S из одного swatch восстановить невозможно: только Kd и Sd. Поэтому установить единицу d=1 на обычной плёнке (тот же reference-film anchor, который обсуждается в reference05), один общий Sd0=0.2 как параметр семейства, и на CPU подобрать Kd0 отдельно по RGB каналам из R_total(Kd0,Sd0,1,1)=targetColor. Бисекция даёт точный обычный swatch. При другой массе d оба Kd,Sd умножаются на один d. Тогда изменение плотных скоплений — нелинейность слоя, а не подмена обычного цвета/дозы.

У чистого поглощения тот же обычный target соответствует Kd0=-log(target)/2. Использовать tau как K напрямую дало бы удвоенное поглощение на белой подложке. Пример target=.5,Sd0=.2: калибровка оставляет d1=.5, а толстый слой выходит на положительное отражение вместо Beer→0 (числа в examples.json).

Если ordinary film не имеет единственного физического doseanchor, калибровку пока нельзя объявлять определённой. current u_pigmentOpacity — скалярный эвристический параметр, не измеренный S(λ). Его можно исследовать как множитель Sd0 с фиксированным global scale, но нельзя отождествлять с физическим рассеянием. Один scalar S не описывает разные пигменты и спектральный цвет. Для смеси коэффициенты K/S должны складываться по составу; текущий optical-depth record хранит tau, а последний preset/u_pigmentOpacity не хранит состав смеси. Пилот только single-pigment; 7/3 обязательный непромотируемый mixed control.

## Предложение дешёвой shader-пробы

Сначала подобрать Kd0 на CPU для каждого текущего single-pigment swatch при общем Sd0 и документированном обычном film anchor. Одна composite функция вместо Beer exp читает локальную массу d и три откалиброванных Kd0 + scalar Sd0: один sqrt/exp на RGB канал, ветки zero K/S; использует исходные deposit/coverage/contour, без шума и изменения массы. Не вычислять бисекцию в каждом пикселе. Ввести отдельные diagnostic uniforms только runtime exact patch; sampler/operation contract не менять. На d1 изображение должно совпадать с reference05/целевым обычным swatch; d→0 и d→∞ проверяются до GPU. Полезность: отделяет эффект толстой непрозрачной краски от недостающей массы, проверяет finite saturation. Не исправляет геометрию и транспорт, не обещает живые скопления.
