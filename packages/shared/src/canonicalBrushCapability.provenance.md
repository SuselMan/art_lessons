## Closed primary-image pressure-texture semantic extractor

extractCanonicalPrimaryTextureCapability classifies a schema-verified original
image descriptor plus ordinary declared asset side metadata. It returns a copied,
frozen primary asset, square pattern rectangle/pin and pressure-identity-v1
strength program. It is NOT CAS/descriptor authentication, source compilation,
profile permission, whole effect admission or a renderer/BEGIN grant. Callers
still require canonicalSourceEffectReject for their genuine selected profile.
No textureEnabled=false descriptor copy is made. The existing private image
helper accepts an internal verified texture policy; its default and all old
single/pipe public APIs retain texture refusal and their previous checks.

The new raw boundary captures own-data scalar settings before source schema
inspection. This does not promise zero getter execution on arbitrary descriptor
objects: the ordinary API contract requires schema-validated descriptors. The
new strength subset requires explicit original enabled/version2/UseCurve/
UseSameCurve/Value1/curveMode0/Sensor fields and rejects unknown Strength keys
and competing Custom/Curve sources. It never infers raw provenance from legacy
grainDepth modulation. The whole Sensor input has a 2048-code-unit ceiling and
a constant-depth consuming grammar: optional EXACT harmless <!DOCTYPE params>,
one params id=pressure, one attribute-free curve with literal endpoint sequence
0,0;1,1;. ASCII whitespace and either quote are accepted. Other DTDs, entities,
comments, XML declarations, extra attributes/children/sensors/trailing content
are refused; there is no XML engine, expansion or substring-search grant.

Descriptor texture requires hard subtract, strength1, fixed integer phase,
exact square pattern period/rectangle and power-of-two declared storage2..2048.
Pin validation is shared with canonicalPrimaryTexturePin, not reimplemented CAS
verification. Dual/mixer/wet effects and color adjustment remain unsupported;
no auto/image pipe support is implied. Output changes cannot mutate the source,
and source changes cannot alter the returned copied pin/assets.
