# Soft source pins and native outer composition

A source-data-ready soft descriptor is not necessarily executable by the current
canonical outer-over law. Shared hasCanonicalOverComposition checks verified
descriptor semantics: erase must be absent/false, native blend normal, wetEdges
and burntEdges zero. Missing optional fields retain the descriptor's existing
normal/zero defaults. This helper does not replace schema, alphaDarken, rendering
mode or other caller execution policy. Source-data extractors remain unchanged.

Soft descriptor binding applies that guard after SHA/profile policy validation
and before data extraction. An eraser importer normalizes its native blend to
normal while retaining behavior.erase; checking blend alone would fake paint.
No unsupported blend is remapped to over. The server resolver uses this same
shared law for PNG/default/Gaussian/soft while retaining its other restrictions.
Old default/Gaussian direct data-binding helpers are unchanged by this unit;
those DTOs never independently authorize execution.

Independent actual NEW original soft descriptors retained in private R52 prove
source data readiness6/6, but only3 Airbrush Soft binds to the current over law.
Indices59/60/61/62/63 are color/colorDodge/lighten/multiply/overlay respectively
and are explicitly refused. Their source curves stay valid for later native
blend implementations; this is not a whole-brush compatibility regression.

Checks:45/45tests across soft material/mapped schema/capability; shared TypeScript,
scoped lint and diff-check PASS. Baseline exposed five actual nonnormal binding
acceptance failures; test fixture independence was corrected by deep-copying its
shared descriptor. Final independent normal-blend eraser/wet/burnt tests prove

## Explicit whole-pipeline profile argument

The source binding's optional final argument5 selects the shared profile-aware
composition law; argument4 remains sourceSlot and primary0 remains the only grant.
Omission is the old Over-only policy. The new V2 profile admits four native modes
only for retained wash, while Color, erase, wet/burnt, historical unsupported data,
missing/mismatched mapped radial curves and mask/dual material remain refused.
No source-pin field or material bytes are changed, and source extractors remain
readiness-only. Actual NEW descriptor proof distinguishes readiness6 from old
paint-bindings1 (index3) and new bindings5 (3/60/61/62/63);59Color remains closed.
