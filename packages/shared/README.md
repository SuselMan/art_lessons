# shared — общий контракт

Пакет `@grafetto/shared` — единственное, что импортируют и клиент, и сервер: тип `Operation`,
сущности, события сокета, таблица REST-маршрутов, кодек дабов. Сам ничего нашего не импортирует.

Чистая геометрия исходных масок (аффинные матрицы, PNG pyramid, размеры и начальные
координаты выборки) также общая: клиент и сервер проверяют сохранённый материал
одной формулой до работы с пикселями. Здесь нет GL, загрузки изображений или
перечисления покрытых строк. Кодек `canonicalMaterialCodec` сохраняет F64-рецепты
и границы входных сегментов; наличие кодека само по себе не включает новый путь
в существующих операциях или отрисовке. Лимит UTF-8 манифеста библиотеки общий
для каталога и долговременного хранилища, независимо от квот пикселей CAS.

## Заметки

- Смысловые куски этой папки — группы карты (`docs/architecture/map.yaml` → `groupings`):
  shared-contract, shared-dab-codec. В коде этих групп нет; когда папку разложат по подпапкам,
  описание группы переедет в README новой подпапки.
