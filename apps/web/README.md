# web — конфиг сборки

Vite: PWA-плагин, dev-сервер с `--host` для планшетов в локальной сети, режимы http/https.

## Заметки

- Сам модуль — только конфиг сборки. Код клиента — в подмодулях: `src/` (приложение), `landing/`
  (лендинг), `scripts/` (запекание ассетов и пред-сжатие).
