# i18n/core — словари и перевод

Свой минимальный слой i18n без библиотеки: плоские типизированные ключи, английский — источник
истины для набора ключей, любая другая локаль типизирована как Dictionary, поэтому пропущенный
перевод — ошибка типизации. Выбор локали по умолчанию, правила множественного числа и сам
`translate()` — чистые функции, стора не знают.

## Заметки

- Отдельно от хуков `useT`/`useLocale` в `../` (#650): стор настроек хранит `Locale`, реестры
  в `lib/` хранят `TranslationKey`, а service worker переводит уведомление — всё это ниже стора
  и не может импортировать барреля, который его читает.
