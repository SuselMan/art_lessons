# i18n — переводы для компонентов

Лицо слоя i18n для React: `useT()` и `useLocale()` читают выбранный язык из стора настроек,
остальное реэкспортируется из `core/`, так что компоненту хватает одного импорта `../../i18n`.

## Заметки

- Сами словари, ключи и функция перевода — в подмодуле `core/`, слоем правее стора (#650):
  стор и `lib/` переводят и хранят `TranslationKey`, не импортируя хуки, которые читают стор.
  Код ниже стора импортирует `i18n/core/...`, а не этот баррель.
- Dev-панели (флаги, тюнинг, отладочные оверлеи) остаются английскими намеренно.
