# pages/Room/viewport — вьюпорт

Локальная камера пользователя `{cx, cy, zoom, angle}`: математика камеры, пинч, перевод
координат указателя в холст, позиционирование плавающих панелей. У каждого участника своя —
по сети не ездит.
