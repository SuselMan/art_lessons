# pages/Room/editing — выделение и трансформация

Операции над содержимым, а не над кистью: попадание в аннотацию, куда лечь вставке из буфера,
какой слой сейчас активен, и поверхности, с которых инструменты «нажатие по холсту» берут свой
жест (`CanvasCatchers`, #493). Математика трансформации — в `lib/transform` (её типы хранит стор, #650).
