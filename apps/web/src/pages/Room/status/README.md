# pages/Room/status — баннеры состояния

Вся обратная связь о том, что происходит с комнатой и связью: подключение, заморозка, закрытие,
оффлайн, не загрузилась бумага, потерян WebGL-контекст, идёт восстановление, потерялась работа,
статус синхронизации, ворота входа.

## Заметки

- NoWebGL (#570) — экран вместо редактора, когда браузер не даёт WebGL-контекст (проверка —
  lib/browser/webgl.ts, до того как отработает хоть один хук редактора). До него движок бросал
  исключение из эффекта, React размонтировал корень, и человек видел чёрную страницу без
  единого слова.
- RoomFailureOverlay — общая форма «комната не открылась», RestoreFailedOverlay подставляет в
  неё причину. Причин ровно две, и они не взаимозаменяемы: пиксели не доехали по сети (#533)
  или доехали и упали при выкладке на экран (#538). Назвать человеку не ту причину — это стоить
  ему следующей попытки.
