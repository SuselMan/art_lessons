# pages/Room/net — сетевой слой комнаты

Всё между движком и сокетом: исходящая очередь операций и её сохранение на диск, оптимизм до
подтверждения, догон пропущенного, очередь входа, ворота и восстановление снапшота, оживление
сокета, статус синхронизации, троттлинг курсора, восстановление потерянной работы из outbox. И
обработчики событий сокета, вынесенные из эффекта Room по доменам (#493): вход и повторный
вход, маршрутизация room_state, поток подтверждённых операций, пиры и живые штрихи, доски и
класс, решения владельца и очередь входа.
