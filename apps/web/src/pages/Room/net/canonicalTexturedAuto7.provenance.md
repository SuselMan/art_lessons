# Coherent frontend ingress for material7

This proposal extends the existing seven frontend owners; it does not create a read, delivery, author, cache, queue, or renderer authority.

Original authorTexturedAutoSource is captured from full room metadata or the original indexed Offer. OPEN, FOLLOW, recovery, accepted cuts and controller services retain exactly that permission. Indexed outer permission fields are forbidden. Historical author4/5/6 permissions remain independent.

BEGIN7 captures the prepared named context and its own-DATA resolved phase before socket emission. The original7 token and descriptor SHA are mandatory. The ACK must use material7 and match the captured entire context, descriptor identity, request RGB/composition/gesture and saved phase. Later caller mutation cannot select ACK policy or phase. Cancellation uses the existing single-attempt listener/timer lifetime.

Recorded7 uses the same actual original input and its original delivery lifetime. Genuine pattern-only assets pass the existing verified availability helper before page/evidence exposure, including READ7 with AUTHOR7 OFF. No legacy Soft lookup or dummy image is synthesized. The helper's size limits, finite cancellation and busy latch remain unchanged.

The metadata fixture is the unchanged tracked genuine normal Reptile37 descriptor and pattern metadata. It is controlled socket DATA, not server admission/CAS proof or a pixel/native-Krita oracle. Tests cover request capture, context/phase/SHA/policy mismatch, downgrade refusal, late ACK cancellation, original metadata equality across lifecycle, genuine pattern availability and cancellation, controller forwarding and current eligibility. Execution/type/lint gates are pending ROOT cue and coherent shared/engine RAM dependencies. No online buildup, full compatibility or performance claim follows.
