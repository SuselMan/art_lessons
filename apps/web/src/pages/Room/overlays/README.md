# pages/Room/overlays — слои поверх холста

Всё, что рисуется поверх канваса и живёт в экранных координатах: сетка, линейка, рамка
выделения, гизмо трансформации, курсоры соседей, кисть-курсор, диск угла грифеля, аннотации.
И то, как выглядит сам указатель в каждом режиме (`cursorController.ts`, #393) — решается в
одном месте. `CanvasOverlays` (#493) — их общий набор, который Room ставит на обёртку холста
или на обёртку мира бесконечной комнаты.
