# Завершение ответа метрики открытия комнаты

`saveRoomOpenMeasurement` читает небольшой JSON-ответ сервера перед завершением попытки. Вызов остаётся асинхронным и не блокирует открытие комнаты; ошибки чтения используют существующий ограниченный повтор с тем же идентификатором.

На Samsung Chrome контроль ABBA для одного endpoint и одного таймера подтвердил: оба ответа без чтения тела получили все байты, затем ERR_ABORTED по таймеру; оба ответа с чтением завершились loadingFinished. Это объясняет наблюдаемые ошибки метрики, но не устанавливает причину отдельных сбоев загрузки каталога.

Проверка: четыре теста, включая удерживаемый поток ответа и ошибку тела после заголовков; два корневых файла TypeScript без диагностик; oxlint без ошибок. Доказательства: fixes-v52/room-open-body-consumption-root-{red,green,typecheck}.log, http-unconsumed-body-abba-v1-result.json. Проверка на Samsung выполнена на неизменённом стенде b7a267d7a; исправленный клиент ещё не развёрнут.
