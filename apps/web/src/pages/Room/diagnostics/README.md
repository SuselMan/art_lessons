# pages/Room/diagnostics — диагностика комнаты

Отчёты о том, как прошли открытие и восстановление: тайминги входа, что именно восстановилось из
снапшота. Это то, по чему мы узнаём о сбое раньше учителя.
- `devEngineHandle.ts` (#308) — в dev-сборке кладёт живой движок и стор комнаты в
  `window.__engine`/`window.__roomStore` для стендов и e2e. Переехал сюда из
  `lib/observability` (#650): он читает стор, а слой платформы стор не импортирует.
