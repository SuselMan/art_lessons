# pages/Room/tools — клавиши и колодец цвета

То, что редактор добавляет к реестру инструментов: раскладка горячих клавиш редактора и колодец
цвета. Сам реестр — какие ползунки у какого инструмента, кривые отклика, картинки типов —
переехал в `lib/tools` (#650), ниже стора, который хранит настройки в его форме.

## Заметки

- colorWell.ts (#542) — одно правило «что показывает колодец цвета» для всех мест, где он
  нарисован. На старой карте числился в ui-color рядом с компонентами колодца, но лежит в Room.
