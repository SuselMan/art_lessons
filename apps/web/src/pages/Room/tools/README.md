# pages/Room/tools — инструменты и их параметры

Реестр инструментов: какие ползунки у какого инструмента, как ключ перевода превращается в
подпись, кривые отклика на нажим и наклон, раскладка горячих клавиш редактора.

## Заметки

- Реестр хранит TranslationKey, а не готовую подпись — иначе инструмент нельзя перевести.
- colorWell.ts (#542) — одно правило «что показывает колодец цвета» для всех мест, где он
  нарисован. На старой карте числился в ui-color рядом с компонентами колодца, но лежит в Room.
