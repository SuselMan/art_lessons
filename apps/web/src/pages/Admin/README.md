# pages/Admin — админка

Панель для одного читателя (#585): кто онлайн и в каких уроках, регистрации, пользователи и
уроки со счётчиками, бан аккаунта с причиной, журнал действий. По-английски, как все внутренние
панели. Всем, кроме адресов из `ADMIN_EMAILS`, отвечает обычной 404. В сам рисунок чужого урока
не пускает — только миниатюра.
