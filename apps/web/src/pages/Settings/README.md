# pages/Settings — настройки приложения

Общие настройки, которые переживают любую комнату: язык, тема, тип устройства, компактная
раскладка и ведущая рука. Режим левши/правши сохраняется в этом браузере и меняет местами
панели редактора; тот же выбор доступен в настройках внутри комнаты (#836).
