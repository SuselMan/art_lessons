# components — общие компоненты

Переиспользуемые React-компоненты: панель слоёв, цвет, плавающая панель инструментов и её
контролы, общая обвязка интерфейса (меню, модалки, уведомления), выбор набора инструментов,
доступ к комнате, превью бумаги, калибровка нажима, фильтры слоя. Каждый компонент — своя папка;
какие из них вместе образуют одну тему, говорит только карта.

## Заметки

- У папок компонентов нет своих README, поэтому все они — один модуль, а темы из нескольких
  папок — группы карты (`docs/architecture/map.yaml` → `groupings`): ui-layers, ui-color,
  ui-tool-panel, ui-chrome, ui-toolset, ui-room-access, ui-paper, ui-pressure, ui-filters. В
  коде этих групп нет. Компонент, которому нужна своя карточка на карте, получает README в
  своей папке — и становится подмодулем.
