# components — общие компоненты

Переиспользуемые React-компоненты: панель слоёв, цвет, плавающая панель инструментов и её
контролы, общая обвязка интерфейса (меню, модалки, уведомления), выбор набора инструментов,
доступ к комнате, превью бумаги, калибровка нажима, фильтры слоя. Каждый компонент — своя папка;
какие из них вместе образуют одну тему, говорит только карта.

## Заметки

- У папок компонентов нет своих README, поэтому все они — один модуль, а темы из нескольких
  папок — группы карты (`docs/architecture/map.yaml` → `groupings`): ui-layers, ui-color,
  ui-tool-panel, ui-chrome, ui-toolset, ui-room-access, ui-paper, ui-pressure, ui-filters. В
  коде этих групп нет. Компонент, которому нужна своя карточка на карте, получает README в
  своей папке — и становится подмодулем.

## Базовые контролы

- `Button`: внешний вид — `variant`, поведение формы — нативный `type`
  (по умолчанию `button`). `ref`, `disabled`, `aria-*` проходят к DOM.
  `IconButton` требует доступное имя; `aria-pressed` задаёт состояние переключателя.
  Для ссылок роутера есть `Button/buttonStyles.ts`: та же геометрия и палитра,
  но семантика остаётся у ссылки.
- `TextInput`: нативные атрибуты и ref, связанные `label`, `description`, `error`.
  Размер оформления — `controlSize`, нативный `size` сохраняет смысл HTML.
  `className` относится к input, `wrapperClassName` — к размещению всего поля.
- `Badge`: нейтральный/предупреждающий счётчик, обычный/маленький размер.
- `OptionGroup` сам задаёт размеры кнопок и иконок вкладок; внешние экраны
  отвечают за размещение, не переопределяют внутренние кнопки.

Новые варианты и состояния добавляются в stories. Цвета интерфейса берутся из
`styles/tokens.css`; цвета рисунка, математические цветовые шкалы и debug-панели
не подменяются цветами темы. Токены для контраста поверх изображений и бумаги
остаются фиксированными в обеих темах.
