# pwa — PWA и service worker

Service worker, политика обновления версии и обработка навигационных ответов — то, что делает
приложение устанавливаемым и переживающим потерю сети.

## Заметки

- При диагностике прода сначала сверь хеш загруженного бандла: SW отдаёт сборку, которая была до
  деплоя, и симптом легко списать не на то.
- Слой — платформа, а не оболочка (#642): pwa ничего из приложения не импортирует, а его
  политику обновления читает `lib/registerServiceWorker.ts`. На старой карте он стоял в
  «Оболочке», левее lib, и эта связь рисовалась красной — ошибка самой карты, не кода.
