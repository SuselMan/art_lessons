# Krita preset tool photographs

Generated physical-tool representations for the flat Grafetto tool chooser.
Each PNG is keyed by the imported preset id and optimized to at most 320×128
with transparency. They are display assets, not brush masks or rendered stroke
samples. They do not change brush behavior.

Original author artwork is preserved under
`docs/brush-reference/krita-default-previews` with pinned upstream provenance.
The photographs use the preset name and purpose to choose a corresponding
physical drawing, erasing or blending implement. Native eraser and fingertip
photographs are adjacent in `assets/tools`.

Generation template: one realistic artist implement, working tip left, handle
right, horizontal side view, soft product photography, transparent cutout.
No text, branding, paper, sample marks or extra objects. Material and working
end are chosen to evoke the corresponding Krita preset.
