# lib — общие помощники

Всё, что нужно клиенту, но не принадлежит ни одному экрану. Сама папка кода не держит — только
подмодули: `api` (клиент API), `sound` (звук), `layers` и `boards` (чистые помощники слоёв и
досок), `input` (примитивы ввода), `browser` (обёртки браузера и локальное хранение),
`observability` (Sentry, логи, dev-инструменты), `annotations` (пометки учителя), `tools`
(реестр инструментов и их параметров).

## Заметки

- Зависимости между подмодулями идут в одну сторону — к `browser`: его берут `api` и `input`,
  сам он из `lib` ничего не импортирует.
