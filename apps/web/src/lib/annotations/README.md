# lib/annotations — аннотации

Модель пометок поверх работы ученика — то, чем учитель разбирает домашку, не трогая её.

`reviewHistory` выводит заметки и их undo/redo/revoke из подтверждённых операций до
готовности движка. Это временная проекция общего журнала, а не отдельное хранилище
комментариев; пиксельные операции продолжают обычное восстановление (#704).
