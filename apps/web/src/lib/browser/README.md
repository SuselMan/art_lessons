# lib/browser — обёртки браузера

Всё, что упирается в конкретное поведение браузера: полноэкранный режим, перехват кнопки
«назад», безопасность перезагрузки, регистрация SW, версия приложения, тема, работа с
изображениями и миниатюрами, буфер обмена, локальные настройки комнаты и UI-предпочтения в
localStorage, тип устройства, цветовые преобразования, проба WebGL.

## Заметки

- `webgl.ts` (#570) — «даст ли этот браузер WebGL-контекст», спрошено до того, как от ответа
  что-то зависит: CreateRoom до навигации на /room/<id>, Room до первого хука редактора.
  Пробный canvas сразу отпускается через WEBGL_lose_context, чтобы не занимать слот рядом с
  настоящим.
