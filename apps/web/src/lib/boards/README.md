# lib/boards — помощники досок

Чистые функции ленты досок (#176): свёртка событий board_* в список, доска учителя, куда
попасть на входе, правило следования и перестановка в ленте, правила режима класса. Общие для
стора (roomSlice складывает события) и экрана комнаты (решает, когда перелистывать).
