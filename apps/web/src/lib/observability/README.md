# lib/observability — наблюдаемость и dev-инструменты

Sentry, диагностический лог, отчёты об инвариантах, часы сервера и метр задержки, флаги фич и
ручка движка для консоли. То, чем мы узнаём о поломке и чем ковыряем её вручную.

## Заметки

- Оверрайд зерна графита живёт в localStorage и per-origin — легко принять за баг рендера или
  драйвера.
