# lib/sound — звук

Синтез звука карандаша по бумаге в реальном времени (несущая разложена на mid/body/hiss) и
щелчки интерфейса. Живой движок — `PencilSound.ts`; вариант на AudioWorklet
(`pencilSoundV3/`) отброшен. История настройки — `PENCIL_SOUND_TUNING_LOG.md`.

## Заметки

- Когда настройка на слух буксует — рендери выход синтеза в файл и сравнивай с эталонными
  записями одним анализатором, а не ушами.
