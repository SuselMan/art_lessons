# lib/tools — реестр инструментов

Какие параметры у какого инструмента, их значения по умолчанию, шкалы и подписи
(`toolSchemas.ts`), плюс то, из чего реестр собран: кривые отклика на нажим и наклон, картинки
типов инструмента, шкала ползунка, разбор введённого числа, формы выделения. Чистые данные и
функции, без React и без стора.

## Заметки

- Переехал из `pages/Room/tools` (#650): стор инструментов держит настройки в форме, которую
  описывает реестр, и берёт из него значения по умолчанию, а `SettingField` рисует по его
  дескрипторам — оба слоем выше редактора и импортировать страницу не могут. В Room остались
  то, что знает про редактор: колодец цвета и горячие клавиши.
- Реестр хранит TranslationKey, а не готовую подпись — иначе инструмент нельзя перевести.
  Импорт ключа — из `i18n/core/en`, не из барреля `i18n`: баррель читает стор.
- `sliderScale.ts` и `numberInput.ts` раньше лежали в компонентах `PrecisionSlider` и
  `NumberField`; компоненты их по-прежнему используют, но дескриптор реестра объявляет шкалу и
  разбирает градусы теми же функциями, поэтому они ниже обоих.
