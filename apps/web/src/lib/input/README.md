# lib/input — ввод и жесты

Переиспользуемые примитивы ввода: горячие клавиши, калибровка нажима, пороги касания,
перетаскивание-регулятор, долгое нажатие, позиционирование поповеров, закрытие по клику
снаружи, компактная раскладка, углы.
