# lib/transform — математика трансформации

Как жест гизмо превращается в матрицу трансформации слоя (#120): 3×3-проективные матрицы, рамки,
повороты вокруг опоры, какой жест делает ручка. Своя математика, а не `matrix.ts` движка:
здесь — жест, там — отрисовка. Жила в `pages/Room/editing`, но её типы хранит стор слоёв
(`layerSlice`), а стор не может импортировать редактор — поэтому она слоем ниже, в lib (#650).
