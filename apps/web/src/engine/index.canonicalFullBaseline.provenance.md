# Full original history under the existing engine baseline transaction

The explicit full-room-prefix-v2 read can enter the same finite, single-layer
source-wash baseline owner as V1. It does not activate an ordinary room, HTTP
suffix, live metadata writer, image source or new renderer. Original read/tail,
geometry, scope and per-atom delivery remain mandatory before canvas access.

The complete original operations, including close and undo/redo, enter the staged
OperationLog. The shared whole-history fold determines final gesture visibility;
one first-frame undo per hidden gesture marks its frame entries undone in that
staged journal. Metadata rows retain their original identities and order. This is
an atomic final-state rebuild, not an animation of intermediate undo/redo states.
The existing live undo/redo editor path is not opened by this change.

Painting uses a separate bounded projection of those SAME original input pointers:
visible frames and their actual recorded seals. Seals enter the existing
coordinator's enqueueRecordedSeal; no END fence or missing operation is invented.
An unsealed unfinished gesture remains outside this baseline domain. A fully
hidden history performs no source painting and retains an unprepared warm owner,
matching an empty baseline. All sources still undergo the existing full pin,
geometry, target-union and CPU/GPU admission checks, including hidden sources.

Accepted journal proofs retain the actual normalized entry read pointers and
frozen operation-state values. They do not require identity between an original
input read and the journal's validated read copy. Physical context recovery uses
the same original full read, unchanged journal/revision and final visibility.
Source preparation, task scheduling, coordinator, display/export and cleanup use
the existing transaction and services.

Host tests exercise actual original preparation and the real engine/coordinator:
ended, recorded-partial, hidden ended, hidden partial, redo of hidden partial;
exact original input/sequence in every journal entry; no frame or seal deposition
for hidden gestures; recorded seal deposition for visible partial gestures;
copied/stale read rejection before canvas access; physical-loss recovery for
visible and hidden partial histories. Existing V1 baseline, recovery, persistent
layer and pointer-author tests remain regression coverage. MockGL tests make no
hardware pixel, stylus-latency or cross-device claim.
