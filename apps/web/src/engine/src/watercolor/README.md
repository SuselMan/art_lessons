# engine/src/watercolor — CPU-модели акварели

Эталонные модели акварели на CPU: цвет смеси пигментов (`pigmentOptics.ts`), диффузия пигмента в
стоячей воде (`wetDiffusion.ts`) и водный домен операции — куда растекается вода и где встаёт
фронт высыхания (`waterFront.ts`). Боевой путь — GLSL-проходы в `raster/shaders.ts`; эти
модели — оракулы, по которым алгоритм можно проверить без GPU.

## Заметки

- `waterFront.ts` пока ни откуда не импортируется (предупреждение no-orphans): это эталон для
  GPU-порта водного домена (ADR 011 §17.24), который ещё не подключён.
