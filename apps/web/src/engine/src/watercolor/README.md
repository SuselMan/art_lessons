# engine/src/watercolor — CPU-модели акварели

Модели акварели на CPU: цвет смеси пигментов (`pigmentOptics.ts`), диффузия пигмента в стоячей
воде (`wetDiffusion.ts`) и водный домен операции — куда растекается вода и где встаёт фронт
высыхания (`waterFront.ts`). Диффузия и водный домен — эталоны для GLSL-проходов в
`raster/shaders.ts`, по которым алгоритм проверяется без GPU. Но это не только эталоны: фасад
движка берёт отсюда в работу расписание и коэффициенты диффузии (`WET_DIFFUSE_*`) и поглощение
пигмента (`pigmentAbsorption`) — правка этих файлов меняет картинку у всех.

`foreignWater.ts` строит компактную CPU-маску предшествующей мокрой области из геометрии
дабов. Записанные мокрые контакты выбирают область, по которой фронт нового штриха может
идти, даже если у мазков разные `washId`. Маска передаётся в GPU-проход фронта; краска
старого залива в новый при этом не копируется.

## Заметки

- `waterFront.ts` пока ни откуда не импортируется (предупреждение no-orphans): это эталон для
  GPU-порта водного домена (ADR 011 §17.24), который ещё не подключён.
