# engine/src/oplog — операционный лог и снапшоты

Лог операций внутри движка, кодек снапшотов, аудит покрытия снапшота, gzip, хранилище
чекпойнтов (бюджет, вытеснение, закреплённый снапшотный чекпойнт, поиск по префиксу — первый
шов декомпозиции движка, #494), учёт публикации снапшота (что нового публиковать, что уже
покрыто восстановлением, что публиковать нельзя). То, из чего комната собирается заново после
перезахода и с чего начинается пересборка слоя при отмене.

## Заметки

- Полные логи операций хранятся сознательно, как актив для обучения моделей (#375). Сырой ввод
  пера при этом не сохраняется.
