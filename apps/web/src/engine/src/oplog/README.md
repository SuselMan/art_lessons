# engine/src/oplog — операционный лог и снапшоты

Лог операций внутри движка, кодек снапшотов, аудит покрытия снапшота, gzip, хранилище
чекпойнтов (бюджет, вытеснение, закреплённый снапшотный чекпойнт, поиск по префиксу — первый
шов декомпозиции движка, #494), учёт публикации снапшота (что нового публиковать, что уже
покрыто восстановлением, что публиковать нельзя), и `SnapshotIO` поверх них — запекание слоя в
снапшот и контрольное запекание полным реплеем, восстановление слоя из скачанного снапшота с
аудитом, вливание страницы истории в лог без отрисовки (#494). `StructuralOps` — слияние и
дублирование слоёв: живой путь с немедленным чекпойнтом, структурный путь для операции, уже
покрытой снапшотом, и реплей из пересобранных источников (#494). Можно ли печь слой прямо сейчас
(очередь чужих операций, открытый залив акварели, пересборка) решает движок. То, из чего комната собирается заново после
перезахода и с чего начинается пересборка слоя при отмене.

## Заметки

- Полные логи операций хранятся сознательно, как актив для обучения моделей (#375). Сырой ввод
  пера при этом не сохраняется.
