# engine/src/filters — фильтры слоя

Арифметика пяти фильтров слоя — размытия, тон/насыщенность, кривые, цветовой баланс — на CPU,
целочисленно и без тригонометрии: фильтр пересчитывает каждый участник, и число должно совпасть
на любом устройстве.

## Заметки

- Слой фильтруется по тайлам, каждый — с полем шириной в радиус действия фильтра; поэтому
  результат не зависит от того, где у клиента прошла сетка тайлов. layerFilters.test.ts
  проверяет это побайтно — сломать это свойство значит разойтись с остальными участниками.
