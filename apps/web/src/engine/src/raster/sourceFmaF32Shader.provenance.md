# Compact finite FMA component primitive, diagnostic WebGL1

`SOURCE_FMA_F32_GLSL` exposes `sourceFmaF32(vec3 a,vec3 b,vec3 c)` with inputs `(negative0or1, significand24, exponent)` validated by the CPU finite-components contract. Output is `(negative,significand,exponent,class)`; class0 is finite, class1 is signed overflow infinity. Zero sign remains explicit. No raw32-bit bit-pattern is stored in one highp float. NaN/Inf inputs, malformed components, FENV, NaN payloads and non-RNE profiles are outside this contract.

The80-bit signed-window arithmetic and discarded-tail borrow proof are in `sourceFmaF32Model.provenance.md`. This translation uses11 byte limbs (10 retained plus carry), a6-byte product, fixed loops and static-selection array reads. All significand intermediates are exact integers representable by binary32 highp. It neither assumes a GPU fused instruction nor substitutes multiply/add for FMA. It has no texture, renderer, wire, material, shader-factory or session activation. Byte-split arithmetic follows the existing affine16 pattern; no unrelated transform helpers or native implementation bodies are copied.

The first WebGL1 compilation assessment rejected integer `max` and reverse-index temporary array reads under ES100. The final primitive uses integer ternaries and the common static-selection reader. On actual Samsung SM-T970 / Adreno650 it compiles as a3635-byte complete diagnostic fragment. The initial successful compile took144.4ms, later cached compiles5.7–10.8ms. This is a size/feasibility gate, not responsive compositor performance proof: per-case uniform/draw/readPixels probes intentionally serialize the GPU, and integrating many calls may multiply instruction/register costs.

`fixtures/sourceFmaF32Shader/samsung.native.json` records exact frozen primitive/fragment/input hashes and actual GPU results:11200 independent unchanged host true-fmaf triples and1113 compact physical Samsung finite-FRECPS triples, zero differing output bits and GL errors. The probe packs the resulting components into four separate output bytes; CPU reconstructs a U32 only after readback, checking signed zero/subnormal/overflow exactly. Expected values are independent retained native fixtures, not computed by the shader operation model. General finite normal/subnormal/cancellation/tie/overflow values are present in the host oracle. This does not claim the installed compositor uses this primitive, active GUI dispatch, native paint-device partitioning, or equivalence on untested GPUs.
