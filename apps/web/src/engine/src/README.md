# engine/src — внутренности движка

Внутренности WebGL-движка за фасадом `engine/index.ts`. Снаружи движка сюда не импортируют —
только через `PencilEngineAPI` (правило `engine-public-api-only`). Сама папка кода не держит,
только подмодули: `buffers` (буферы и тайлы), `dabs` (дабы и геометрия следа), `presets`
(характеры инструментов), `paper` (бумага), `input` (указатель и линейка), `oplog`
(операционный лог и снапшоты), `raster` (шейдеры и растровые операции), `filters` (фильтры
слоя), `watercolor` (CPU-модели акварели).
