# engine/src/paper — бумага

Зерно бумаги: загрузка запечённых текстур, манифест вариантов, константы, «зацеп» грифеля за
зерно, влажность бумаги под акварелью. Живая GPU-запечка, общий PNG и аналитический шейдер были
испробованы и отброшены.

`PaperState.ts` (#494) — бумага одной комнаты внутри движка: жизнь текстуры (заглушка до
загрузки, загрузка и повтор после отказа, мип-цепочка, перезаливка после потери контекста) и
геометрия листа (размер листа, на сколько растянуто зерно, обрезка акварели по листу). Движок
строит его один раз и отдаёт проходам по ссылке: смена бумаги меняет текстуру внутри, а не сам
объект. В `paper.ts` (дверь для кода вне комнаты) он не попадает — там нельзя тянуть движок в
стартовый бандл.

## Заметки

- `paperAssets.test.ts` читает запечённые текстуры из `apps/web/public/paper` по пути от своей
  папки; если бумага не запечена (`npm run bake:paper`), его тесты пропускаются, а не падают.
