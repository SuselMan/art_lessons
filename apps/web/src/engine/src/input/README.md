# engine/src/input — указатель и линейка

Приём событий указателя: нажим, скорость по часам сэмпла, наклон, аналитический перевод
координат через `setTransform()`, притяжение к линейке.

`AuthorTaskScheduler` — общий транспорт пробуждений существующих владельцев
работы движка: author FIFO и canonical RebuildJob. Очереди и отмена принадлежат
этим владельцам; каждый снимает собственный token. `resetIfIdle()` закрывает
порты после отмены одного владельца, сохраняя принятые пробуждения другого.
