# engine/src/buffers — буферы слоёв и тайлы

Хранение пикселей: аккумуляционный буфер штриха, тайловый буфер слоя с вытеснением и
мип-уровнями, математика тайлов, ретайлинг снапшота. Обычная комната — сетка тайлов с границами
по 1024, а не одна текстура.

`RibbonScratchPool` владеет свободными временными GPU-буферами ленты: выдаёт их по размеру,
учитывает занятые и свободные байты, удерживает их во время перестройки и возвращается к
прежним лимитам после неё. `RibbonStrokeScratch` хранит состояние отдельного штриха или
продолжающейся акварельной заливки: исходную картинку, покрытие, воду и пигмент, временную
плёнку жеста и скалярные параметры продолжения. Он копирует это состояние в чекпойнт или
паркует его в компактных GPU-буферах и восстанавливает на тайлах целевого слоя.

Порядок операций, кэш заливок, сушка и решение, когда сохранять или выгружать состояние,
остаются в `PencilEngine`. После потери контекста классы забывают недействительные GL-объекты;
при обычном завершении возвращают живые буферы владельцу. Эти внутренние классы не входят
в публичный API движка (#494).

## Заметки

- Формат приколотых чекпойнтов (#467) намеренно живёт только в памяти процесса: на диск не
  пишется, на сервер не едет, в снапшот не входит. Проводной формат — за snapshotCodec.ts, и
  совместимость держать обязан он.

`RibbonReplayCache` хранит активный кэш жестов и заливок реплея, их авторов,
компактные припаркованные состояния и очередь копирования. LRU и восстановление
буферов принадлежат кэшу; пересборка слоя, сушка и политика бюджета памяти
вызываются через контекст движка. Подмена кэша на время шага пересборки остаётся
в `PencilEngine`, чтобы сохранить прежний порядок операций.

`SettleField` описывает десять рабочих текстур сушки акварельного залива
и их общее уничтожение. Само поле и правила его повторного использования
принадлежат движку; план сушки получает готовое поле через контекст.

`BufferResidency` — opt-in общий LRU реальных RGBA8 буферов, без изменения физики,
журнала или геометрии страницы. Для ограниченной фабрики создавать
`new AccumulationBuffer(gl, w, h, filter, cache)`: admission предшествует GL allocation.
`buffer.enableResidency(cache)` подключает уже существующий буфер; его прежнюю
аллокацию кэш задним числом ограничить не может. Бюджет включает потенциальные
мип-уровни POT текстур; каждый буфер должен помещаться отдельно и весь draw должен
помещаться одновременно. При полном pinned/bound бюджете возникает явная ошибка.

Вытеснение сохраняет lossless bottom-up RGBA8 в CPU, однородные плоскости хранят
только один RGBA texel. Восстановление возвращает фильтры, мипы и GL bindings;
внутренние transfers временно нормализуют pack/unpack и возвращают их значения.
`begin*`/`endDraw` образуют scope и для обычных output: output и полученные через
`texture` sampler inputs защищены до `endDraw`. Вызывающий обязан использовать
`try/finally { out.endDraw() }`, в том числе при ошибке/отмене. Уже привязанные
sampler textures дополнительно защищены внутри draw, framebuffer — всегда.
Вне draw старые sampler bindings не удерживают данные в GPU; удалённая texture
при восстановлении GL state заменяется на null, а не привязывается повторно.
`cache.runPinned(buffers, callback)` нужен для транзакций; copy API делает это сам.

`destroy()` удаляет запись и освобождает живые handles один раз. `cache.dispose()`
уничтожает принадлежащие кэшу буферы. При настоящей потере контекста использовать
`cache.forgetContext()`: без readback/delete, все прежние буферы недействительны;
текущее содержимое GPU нельзя выдумать из устаревшей копии. Менеджер пересоздаёт их
через replay/restore. Подключение к M70 и управление пулом остаются за владельцем.
