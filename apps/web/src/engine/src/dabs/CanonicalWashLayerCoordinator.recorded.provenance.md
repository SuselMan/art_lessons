# Recorded prefix ownership (isolated; ingress OFF)

The existing coordinator Entry owns the source-bound recorded prefix summary and executor. `CanonicalRecordedDelivery.ts` contains types only: original network owners mint the exact-input delivery and stable room-lifetime assertion. Data copied from OperationLog, material metadata, same numeric epoch or a valid shared attachment does not mint this local authority.

`enqueueRecorded` validates original delivery/current lifetime, shared closed V2 attachment and source-bound decoder, ordinal/fence transition, recorded global sequence and source context before mutating the existing lane. A fresh source callback receives the original input; its procedural pin is normalized through the existing canonical source-pin helpers and must match the verified snapshot before executor construction. No V1, mask or image source is granted here. Namespace is JSON `[roomId, boardEpoch, originalUserId, strokeId]`; scope object AND local lifetime identities remain fixed. Existing raw entries cannot be promoted, and raw enqueue/close cannot bypass a genuine recorded entry.

Each new genuine Entry adds a 4096-byte ledger allowance for bounded summary strings/scalars and references, released by the existing metadata cleanup. This is not a measurement of JS snapshot heap. The Entry retains one immutable snapshot reference and prefix state, not full frames, an ID registry, or another queue. Existing executor metadata has its separate charge.

`enqueueRecordedSeal` requires original delivery, SAME lifetime/scope and existing complete open prefix; shared verifyCanonicalRecordedClose checks authoritative IDs/seq/N/target before the existing C2 close control. No source is resolved by a close-only input. Material summary/fences and frame count are not fabricated. Global ID uniqueness and complete ordered same-layer delivery remain authoritative-ingress preconditions.

Every new input and GL advance rechecks the original stable scope. Stale-lifetime checks run before the GL turn and intentionally retain accepted caller-owned lane resources. They perform no pixel writes, no automatic replay or authority replacement. The caller must cancel/discard and rebuild from a genuine refreshed baseline; cancellation still retires accepted resources through the existing attempt-all cleanup. A regression checks unchanged draw/clear/upload counters after stale advance, followed by explicit cancellation and zero CPU/scratch residency. A speculative/live-only state cannot enter these genuine entries through public raw admission. Actual production live-only reconciliation/baseline replay remains unimplemented: no engine/ingress guards or server producer are enabled by this unit.

Tests use a real coordinator/executor, bounded CPU ledger, actual source pin and shared V2 encoder/decoder over mocked GL. They prove source/lifetime/namespace/sequence/closure and cleanup mechanics, not native GPU pixels or a physical DB. The broader executor suite retains C2 ordering/target-budget coverage.

A host integration additionally calls the actual `prepareCanonicalRoomState` with the fixture's shared-validated V2 operation/attachment, sends its original nonenumerable delivery into the real coordinator, expires the original `isCurrent`, and verifies no GL writes plus complete explicit cancellation. It imports no network mint factory and opens no close ingress. Validation: 138 tests / two suites before that host addition, then all 11 recorded-owner tests including host integration PASS; final combined web app + service-worker TypeScript PASS.
