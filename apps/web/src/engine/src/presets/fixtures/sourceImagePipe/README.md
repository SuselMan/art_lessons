# Incremental GIH mechanism fixture

`mountains.native.json` comes from original index92 `z)_Stamp_Mountains_Distant.kpp` and `mountains_distant.gih` in the retained Krita4 default bundle SHA4180f474052305e9de6eaac1d832c1ddeb0654142bcde2eb2460629cf23796d0. Original KPP/GIH SHA and four compressed CAS planes are recorded in JSON. Each of four 256×256 one-channel GBR payloads matches its CAS coverage plane byte-for-byte (262144 pixels total). This is native input provenance, not a new GUI/ARM bit-exact claim.

The fixture uses the normal importer with the existing mapped curve provider, profile/build/binary/source-lock pinned in JSON. No curve/brush/spacing/pressure values are fitted. Native width256/height256/scale1.40625/angle0 gives effective360px; source2wash, spacing.92, only pressure Size/Opacity active, constantFlow1. Unlike Impressionism/LargeSplat, this pipe has no active fuzzy consumers. The registered temporary compiler was removed after fixture construction; no native ELF or runtime copies remain.

Source behavior: pinned bd6e8d061d2f0388c5b10278786cf0fe62e3135f `KisDabRenderingQueue::addDab` assigns an increasing sequence starting0 before cache lookup; resource sync calls `prepareForSeqNo`, which applies incremental seq%rank and chooses the resulting frame. Job regeneration reuses the same sequence. `notifyStrokeStarted` marks pipe uninitialized; the new queue's explicit seq0 anchors the next stroke. `needsMovement` is false for incremental (the parser only enables it for angular). Cache keys include frame index. Small-size paint rejection and spacing/timing-only queries precede addDab and do not consume frames.

The web mechanism follows that boundary with the existing material-cache nextSequence, not the logical query count. The selected asset is emitted in the SAME image recipe and encoded once; replay never reselects it. An explicit ordered `primaryImageFrames` context allows those frames only, with a shared common native grid. No renderer, cache, wire version, or global budget is added. Tests cover four-frame cycling, static regressions, no frame advance on too-small queries, checkpoint/resume after every yield, two fresh strokes, missing assets, and distinct pixels through the existing NativeImageBank. This does not grant random/multidimensional/color GIH, unequal geometry, dual, texture, or smudge support.

Pinned source and audit receipts: R52/mountains92-native-caller-source-audit.json, mountains92-source/source-lock.json, mountains92-native-gbr-cas-proof.json. Retained upstream brush source headers carry GPL-2.0-or-later attribution to Boudewijn Rempt and Bart Coppens; original default brush bundle attribution/CC-0 metadata remains with its retained input. The public source behavior is referenced, not copied into an alternate renderer.

## Random GIH

`pencilRandom.native.json` is original index13 Pencil4 Soft, graphite_grain.gih, seven grayscale128² frames, scale.125/effective16px/literalangle1.5708. Normal importer retains actual Size/Rotation/Opacity/Flow controls; existing mapped provider compiles the active Size curve. No seed is fitted to GUI; no originalARM arithmetic/GUI pixel claim. Provider hashes are in JSON; the temporary registered resource was strictly removed.

Random selection uses SAME `KritaRandomSource.generate(0,frameCount-1)` inclusive range after Opacity/Flow, before materialMirror and spacingMirror. Static/incremental paths keep historical RNG counts. Too-small rejection and spacing/timing queries consume no frame RNG. Repeated frame choices may reuse mask cache, but consume one selection; malformed declarations consume none. Saved/encoded asset and index prevent reroll on replay. Optional material trace captures Mirror's start AFTER pipe selection, so that RNG draw is not mislabeled as Mirror.

Tests cover cursor order, fixed-seed reproducibility, every-yield resume, seven actual pixel planes, and ordered A,B,A with unique CAS metadata. Ordered frames remain distinct from deduplicated assets/bank. Room/server source grants are separate; this mechanism does not activate arbitrary presets or imply nativeGUI seed identity.

The current source import requires declared rank/count to equal actual frame count and at least two frames. A native pipe with a truncated frame count must not be treated as modulo actualCount: native selection first uses declared rank, then modulo actual frame count, and even a one-frame random pipe can consume RNG. Those inputs remain outside this source capability; their legacy imported frame data is preserved. A negative importer witness covers declared3/actual2.
