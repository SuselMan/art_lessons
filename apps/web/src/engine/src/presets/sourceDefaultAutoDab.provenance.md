No ink-alpha/color/composition, background, stochastic tips, Gaussian/curve masks, PNG/CAS, author/wire/room activation is inferred.

Every call returns a fresh caller-owned A8 Uint8Array, actual maskSize and continuous geometry. Plane ≤1,048,576bytes; each side ≤4096. Caller-supplied pixel/work reservations are checked before pixel allocation; max sampled work16,777,216 and finite intermediates are additionally preflighted by the reused kernel. Tests replace the A8 constructor to verify malformed/overbudget inputs do not allocate. No cache, pool, queue, scheduler or new quota layer is created. Execution is synchronous and bounded, not a tablet latency guarantee; asynchronous worker/upload ownership remains a separate step.

Math.sin/cos matches original Bionic only for retained oracle inputs; universal/cross-browser libm identity remains unproven. Profile selection is explicit, never inferred from a stock brush ID or screenshot. No device/runtime resource was created for this service unit.
