# Gaussian coverage with explicit native coefficient input

This is an isolated CPU reference, with no descriptor/importer/author/wire/renderer activation. It accepts an explicitly chosen scalar orNEON numerical profile and **native-derived post-setScale coefficients**. It does not infer that arbitrary eight numbers came from a valid KPP, re-evaluate source options/RNG, or provide generic coefficient admission. Immutable KPP lowering and source-query ownership remain separate work.

The request contains original ycoef, center, distfactor, alphafactor, radius, U8fadeStartValue, continuous fadeStart and fadeCoeff. Effective physical axes select the original3×3/6×6 scalar fallback; explicit center/cos/sin preserve the raw-angle/continuous-hotspot contract. Output/work/finite-intermediate bounds are checked before allocating a mask. The reference's4Mpixel/16Msample/4096axis caps are explicit admission limits, not native capability claims.

Scalar evaluation uses common exact F64 FMA for source transforms/norm/interpolation and the separately documented finite Bionic erf/closed exp reference. Source U8 truncation occurs per transparency sample before integer stencil averaging. NEON evaluation uses common F32 FMA/refined division/RNE helpers, generic integer-constructed ARM reciprocal-square-root estimate with the actual refinement order, source F32 VcExtraMath erf/exp, source254.974f saturation, normalized transparency, and the original pigment four-lane-prefix RNE versus scalar-tail truncation. The per-pixel reference may omit arithmetic in excluded lanes when that cannot alter stored values; it does not claim instruction scheduling, all-lane FP exception flags or paint-device packet identity.
