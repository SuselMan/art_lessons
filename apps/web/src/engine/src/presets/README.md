# engine/src/presets — пресеты инструментов

Числовые характеры инструментов: карандаш и его грифели, уголь, маркер, линер, кисть-перо,
акварель с пигментами, цифровая кисть и её набор — вместе с формой даба по инструменту
(`dabShaping.ts`), растровыми кончиками и текстурами кисти, которые генерируются на CPU
одинаково на любом устройстве (tipMasks), наклон и его кривые, тактильное зерно, зерно
растушёвки.

## Заметки

- `dabShaping.ts` и пресеты кисти-пера, маркера, цифровой кисти и акварели импортируют друг
  друга (цикл по файлам известен и лежит в базе нарушений); внутри одного модуля это
  терпимо, а по разные стороны границы модулей — нет, поэтому `dabShaping` живёт здесь, а не
  в `dabs`.
