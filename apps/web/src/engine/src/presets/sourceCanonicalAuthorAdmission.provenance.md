# Общий data-only admission для будущего выбора кисти

canonicalSourceAuthorAdmission выносит без изменения прежние static gates _prepareCanonicalAuthorBrush: canonicalSourceEffectReject → wash/sourceStamp v2 procedural auto3/timing → Size[0,1]/one-pressure → Ratio/Rotation/Scatter/Mirror и unsupported curve sensors. Причины и порядок отказа engine сохраняются. AA не запрещён заново; actual native Basic2(index4) и Basic5(index8) проходят в native/browser profiles.

Engine использует helper до reservation/hash/SourceAuthorDescriptor. Public engine/brushLibrary export ссылается на ту же функцию. Это query над уже валидированным descriptor, без renderer, program/evaluator, source compiler, GPU, quota или BEGIN. Небольшие return metadata не являются compiler/resource/execution authority. Source/data object не клонируется и не меняется. Подготовка по-прежнему отдельно проверяет compiler/source pin, budget, original owner, digest, actual BEGIN и lifetime.

Тесты покрывают реальные retained descriptors, отсутствие/legacy image/timing, erase/wet/grain, допустимый pressure Size, negative/nonfinite/overflow/multiple/nonpressure sensors, Ratio/Rotation/Scatter/Mirror и unsupported sensor payloads. Если изменённый payload уже нарушает shared source schema, отказывает прежний первый composition/schema gate; тесты не требуют выдуманного более позднего reason. Tests-first import нового helper отсутствовал; после реализации static cases + actual engine author/Size regression проходят. Public boundary identity и immutable descriptor input проверяются отдельно.

Room/store/tool picker в этом unit не меняются. Unsupported defaults/popups этот leaf ещё не исправляет: единый UI availability dataflow требует следующего согласованного unit. Новых ресурсов/процессов устройства unit не создаёт.

Итог: 40 тестов/3 suites (static admission +actual author/Size) PASS, отдельный public-boundary suite16 PASS; общий app+SW TSC1559 PASS на frozen Color+C+helper графе; lint exit0 с прежними index warnings, diff-check PASS.
