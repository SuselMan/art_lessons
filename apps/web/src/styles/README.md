# styles — токены и глобальные стили

CSS-переменные (цвета, отступы, размеры тач-целей) и глобальные стили. Всё остальное — CSS
Modules поверх этих токенов.

`tokens.css` — единая шкала отступов `--space-N`, где N равно числу CSS-пикселей.
Она сохраняет существующую геометрию, включая компактные промежуточные шаги.
Используйте её для padding, margin и gap; `--panel-inset` — семантический alias
на `--space-16`. Ноль, auto, отрицательные оптические поправки и вычисляемые
отступы остаются локальными. Токены `--radius-sm/md/lg` задают 6/8/16px,
`--radius-pill` — 999px для капсул; круги используют 50%.

Глобальные правила запрещают выделение/каретку на кнопках, вкладках, пунктах
меню и других не редактируемых контролах. В input, textarea и contenteditable
выделение и видимая каретка сохранены; клавиатурный focus outline не убирается.
