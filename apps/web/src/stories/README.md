# UI workshop · Storybook (#859)

Живые примеры существующих компонентов Grafetto. Истории импортируют компоненты
и CSS проекта; копий UI здесь нет. Глобальная панель переключает dark/light и en/ru.

Из корня: `npm run storybook` (порт 6006), `npm run build-storybook`.
Проверка типов конфигурации: `npm -w apps/web run typecheck:storybook`.
Сборка лежит в `apps/web/storybook-static`, отдельно от приложения и его PWA.
Backend, база, кисти и запечённая бумага каталогу общих контролов не нужны.

Для нового варианта дополняйте историю соответствующего компонента. Матрицы
показывают сочетания вариантов/размеров и disabled; hover и keyboard focus
проверяются реальным наведением/Tab. Controls меняют props интерактивного примера.
Палитра Foundations читает имена и значения из tokens.css, без второй копии цветов.

Функциональные экраны комнаты сюда не переносятся: их сценарии проверяет e2e.
Это каталог текущего состояния, не автоматическое утверждение всех стилей как нормы.


`Foundations/Palette playground/Interface` — рабочий экран из общих компонентов
с редактором всех `--color-*` из tokens.css. Пробы сохраняются только в localStorage
с ключом grafetto.storybook.palette.v1, отдельно для dark/light; выход из истории
восстанавливает CSS-переменные. Кнопка копирования выдаёт только изменённые
объявления для обеих тем. Значения с var() сохраняют ссылки между токенами.
Математические шкалы и пример рисунка не переопределяют палитру интерфейса.
