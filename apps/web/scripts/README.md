# web/scripts — запекание и сжатие

Офлайн-скрипты веб-клиента, которые запускаются при сборке, а не в браузере: запекание ассетов
(бумага, иконки, шрифт, образцы мазков) и пред-сжатие дистрибутива для nginx.

## Заметки

- Смысловые куски этой папки — группы карты (`docs/architecture/map.yaml` → `groupings`):
  build-assets, build-dist. В коде этих групп нет; когда папку разложат по подпапкам, описание
  группы переедет в README новой подпапки.
