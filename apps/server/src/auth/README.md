# server/src/auth — аккаунты и вход

Беспарольный вход по коду на email, выдача и проверка кодов, личность запроса, ограничение
частоты. Устройства и адреса, с которых человек заходит (#589): кука `al_dev`, запись визитов,
окружение от клиента, срок хранения. Множество забаненных аккаунтов (`bans.ts`): его читают
identityHook и хэндшейк сокета на каждом запросе.
