# server/src/admin — админка и баны

`/api/admin/*` за allow-list email (#586) и бан аккаунта (#587). Само множество забаненных
живёт в памяти процесса (`auth/bans.ts`): его читают identityHook и хэндшейк сокета на каждом
запросе, а пишут только маршруты бана отсюда — после записи в базу и журнал `AdminAction`.
