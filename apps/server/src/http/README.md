# server/src/http — помощники REST

Общая обвязка ручек: типы маршрута, выведенные из общей таблицы REST (`apiRoute.ts`, #623), и
чтение полей запроса, которому клиент ничего не обещал (`input.ts`). Ими пользуются все модули
с REST — комнаты, вход, админка, — поэтому они не живут ни в одном из них.
