# server/src/roomRoutes — HTTP-ручки комнат

REST поверх тех же комнат: список и папки, доступ и приглашения, форк, доски, миниатюры,
снапшоты. Состояние комнат здесь не живёт — ручки читают и меняют его через `rooms/`.

`reviewRoutes` хранит отдельно полный PNG последнего Share for review и его мировой
прямоугольник. Чтение и запись проверяют доступ к доске через тот же механизм, что
миниатюры; экспорт не является снапшотом и не участвует в восстановлении слоёв (#704).
