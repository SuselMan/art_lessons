# Trusted single-PNG canonical gesture binding

`CanonicalBrushCapabilityResolver` is the executable binder used by
`CanonicalRoomTransport` for the guarded canonical protocol. It uses real resident `rooms` and `lessonRecordOf`, not payload authority.
It does not open straight rooms, expand Operation, install socket handlers, pin
assets, relay, or persist anything. Legacy channels still reject reserved canonical fields before side effects;
new canonical channels use the concrete coordinator. Straight opening remains closed. This unit does not claim native GUI identity.

The shared `extractCanonicalSinglePngCapability` is also called by the existing
web author compiler. It extracts the structural single-primary, inverse-gray,
fixed-material class from schema-validated descriptors. It is not an author
option compiler or an assertion of original native resource provenance. Web
still owns option compilation/sensor/RNG execution. Server additionally requires
identity curves or a retained schema-checked coefficient dictionary. No stock
name/index allowlist, embedded native fixture, RNG, image resize, or sensor
execution participates in admission. The existing accepted17 source inventory
classifies 17/17; this is a classification check, not a new GPU receipt.

At authenticated beginGesture, the server checks real paint permissions, current
straight raster version, exact id/version from operator+authenticated-owner+room
catalog, immutable descriptor conflicts, exact CAS metadata and bounded CAS
hash/length read. It pins a SHA256 of recursively key-sorted, JSON-normalized
**whole descriptor**, exact crop, and saved source brush scale/angle. Material
preflight reuses shared geometry/cost, additionally requiring the pinned static
scale/angle. Recipe dynamic scale/ratio/rotation remain canonical material input;
server does not regenerate them from pointer/RNG. The execution law accepts an
inverse-gray CAS policy; L8 bytes alone do not attest an original PNG's opacity.

Begin RGB8/outer resource opacity are range-validated user-selected settings from
the authenticated principal, then copied/frozen. They do not require independent
colour attestation; later frame colour/composition/profile claims cannot change
them. Outer opacity is not the source Opacity option or descriptor opacity.
AlphaDarken variant comes only from an explicit server whitelist/config policy;
there is no inferred KPP/default creamy variant. Raster numerical profile is an
explicit required server option. Painting mode uses the saved reader flag and
checks its consistency with PaintOpAction: absent is buildup, value1 is buildup,
other saved integers are wash.

`canonicalPaintRejectReason` reuses the existing operation gate's editing-policy
body. No fake legacy stroke is constructed. Membership, existing layer, closed
lesson, personal-board rights, shared locks, room/participant freezes and owner
locks are checked; owner exemptions are preserved. Every resolver call rechecks
current permissions and exact board **and lesson** object identity. Equal begin
retries return the same grant; changed resources/lifetime reject.

Epochs identify resident board+lesson record lifetimes, not durable DB epochs.
The bounded grant map never evicts stroke tombstones opportunistically. A trusted
close must clear both binder and CanonicalStrokeAdmission state; after reload or
reconnect the caller must reconstruct persisted gesture prefixes before enabling
new admission. This service is not a persistence/hydration substitute. Current
socket/room creation gates intentionally remain closed pending the whole writer.

Focused tests exercise real BrushStorage temporary manifests/CAS, real room
registry records, policy changes and lifetime replacement, immutable resource
retry/mutation, unavailable revisions, conflicting descriptors/corrupt CAS,
explicit alpha policy, bounded capacity and actual CanonicalStrokeAdmission
shared-frame decoding. The full existing room/socket suites check that factoring
permissions does not change the legacy gate or activate canonical transport.
Tests clean their own temporary directories; no server/device/runtime is started.

## Outer-operation admission is distinct from source data

The actual binder now rejects descriptor erase, non-normal outer blending,
non-buildUp/shape-ceiling/maxAlpha rendering, wet/burnt edges, gamma/luminance
transforms, mask threshold and unimplemented wet/grain/taper/bleed effects BEFORE
constructing a gesture grant or reading/pinning CAS. The current frame protocol
has only outer Over; a valid retained source/option dictionary cannot silently
reinterpret these additional destination/effect laws as Over. The source-data
extractors and raw settings remain available; no effect support is invented.

An independent verified operator manifest with each schema-valid unsupported
setting now fails before binder state, pixels, CAS, room seq or history changes.
Existing actual image and seven default-auto begin/live/record/reconnect tests
remain green. Gaussian server admission is still off (including its soft eraser),
while its closed mask/GPU diagnostics are source/composition evidence only.
