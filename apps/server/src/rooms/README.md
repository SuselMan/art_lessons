# server/src/rooms — комнаты и релей

Сердце сервера: комнаты в памяти, подкреплённые Postgres, ретрансляция операций всем
участникам, живые штрихи и курсоры, undo/redo, заморозка. Сервер никогда не рендерит — он
пересылает операции. Внизу реестр (`roomRegistry.ts`): запись комнаты, Map, правило урок/доска,
очередь записи в Postgres; над ним — какие строки комната пишет по ходу (`roomPersistence.ts`).
Поверх него отдельно: структурный лог, проверка операций, правило покрытия снапшотом
(`snapshotCoverage.ts`), хранилище снапшотов (`snapshotStore.ts`), выбор безопасного покрытия и адресная
история зависимостей для входа (`snapshotReplayPlan.ts`, `snapshotReplayLoader.ts`), рычаги владельца — заморозка,
инструменты, закрытие, доступ, блокировки слоёв (`ownerControls.ts`) — и живой класс: доски,
задания, подсветка, руки (`classroom.ts`). Холодная загрузка из Postgres — `roomLoader.ts`;
журнал операций — `operationLog.ts`; взгляды для здоровья, сторожа и админки — `roomStats.ts`;
кто может войти в комнату по сокету — `roomAccess.ts`; доступ к содержимому по HTTP независимо
от подключения, с проверкой сохранённого входа, актуального пароля, блокировки и видимости — `boardContentAccess.ts`; проводной вид сущности комнаты —
`roomMapper.ts`. В `rooms.ts` остаются создание, вход и выход, выселение и room_state. Сокетный
протокол целиком — `socketHandlers.ts`.

## Заметки

- Эвакуация удаляемой доски (#786) повторно проверяет live socket и его текущие
  board/lesson после async snapshot query. Отключённое соединение не воскрешается;
  уже ушедшее на другую доску не перетаскивается обратно. Вернувшийся на удаляемую
  доску B после B→C→B по-прежнему эвакуируется. Независимый pending join в C остаётся
  актуальным и может завершиться после эвакуации.

- Residency lease (#784) удерживает доску и её урок на время async create/join.
  Reference counts живут в registry отдельно от presence/isIdle. Loader добавляет
  обнаруженный parent до await его загрузки; любой idle eviction, включая memory
  admission и повтор после pending writes, проверяет pin. finally снимает lease,
  затем освобождает только idle записи; успешный seat и другие pending requests
  сохраняют residency. Durable строки не удаляются.

- Асинхронный вход (#783): create_room и join_room имеют общий номер намерения на
  сокет. После await подключение и номер проверяются до посадки участника; устаревший
  запрос получает существующий transient server_busy. Клиентский переход доски
  также проверяет поколение, чтобы старый отказ не сбросил новую попытку B→C→B.

- Присутствие (#780): один участник на userId в уроке, пока жив хотя бы один его сокет.
  Последний вошедший сокет задаёт доску участника; при его уходе место переходит последнему
  оставшемуся подключению, с `peer_board_changed`. Роль, цвет, заморозка и поднятая рука
  сохраняются; `peer_left` и удаление руки происходят после последнего подключения.
  Незавершённые live-штрихи учитываются отдельно для каждого сокета (до 128 ID длиной
  до 256 символов). При разрыве отменяются только его хвосты, без затрагивания других вкладок.

- Работа в классе (ADR 015): личная доска — доска урока с владельцем-учеником. Кто её видит,
  решает одна функция canSeeBoard (`lessons.ts`) — и для join_room, и для REST, и для
  LessonState, который собирается под получателя и шлётся событием lesson_state.
- Map остаётся источником правды для всего живого; запись в Postgres — fire-and-forget, её не
  ждут на горячем пути. Плата: операция, проигравшая гонку падению сервера, выпадает из истории,
  хотя уже была ретранслирована.
- Комната, которая читается как стёртая, — это испорченная строка RoomLayerState, а не
  потерянные данные.
- `rooms.ts` разбирается по доменам (#612).
- Снимок структуры и снимки пикселей имеют независимое покрытие (#737). Поздний undo/redo
  покрытой структурной операции включает computed `replayStructure`: исходный лёгкий
  structural prefix складывается от `IMPLICIT_LAYER_IDS`, безопасные per-layer blobs
  сохраняются, тяжёлая история читается только для затронутых слоёв и их источников.
  Этот режим не переписывает сохранённый RoomLayerState или coveredSeqByLayer. Неизвестная
  snapshot-only база без исходных layer/folder creation отказывается восстанавливаться
  догадкой; актуальные alive IDs не являются её исходной базой.
