# Cold-certified fixed framebuffer ownership

Consumer scope: BrushGlBatch.ts, CanonicalLayerTargets.ts, CanonicalFrameExecutor.ts and their three lifecycle/ownership tests. The cold certificate producer in AccumulationBuffer is a separate root-owned change.

Only actual straight buffers publish a frozen certificate after per-allocation framebuffer status and COLOR_ATTACHMENT0 verification. The same existing ephemeral batch target map records certificate, source, owner epoch, declaration identity and geometry. Admission, post-acquisition and before/after bind checks require the current certificate identity; storage retirement invalidates the producer getter. bindFramebuffer remains unconditional. Foreign/cache targets and standalone composite calls retain hardware checks. No general GL state guard is removed.

The existing owner limit remains 64; each admitted unique certified framebuffer adds 96 bytes to the existing CPU reservation. No persistent registry, pixel mirror, renderer, queue or wire authority is introduced. A certificate is a trusted internal exclusive-borrow promise: arbitrary internal GL reattachment behind the owner is forbidden, rather than detected by a hot query.
