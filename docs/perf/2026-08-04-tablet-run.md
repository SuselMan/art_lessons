# Прогон перед выкаткой — Android-планшет, 04.08.2026

Issue: #324 (трек #314 §9). Замер на устройстве, против прода — не против dev-сервера,
потому что разница в сети и в сборке существенная.

**Устройство:** Samsung Galaxy Tab S7+ (SM-T970), Android 13, Chrome 150, приложение
установлено как PWA. Сеть — домашний wifi.
**Сборка:** `801a095` (`index-Bh8vYhQ8.js`), прод `grafetto.com`.
**Метод:** CDP по adb-over-wifi (`.claude/tablet-debugging.md`). Ввод пера синтетический —
`Input.dispatchMouseEvent` с `pointerType: 'pen'`; касания для панорамирования и зума —
`Input.dispatchTouchEvent`. Кадры — rAF-монитор: разрыв между вызовами, где ~16.7 мс это
нормальный кадр при 60 Гц, >33 мс пропущенный, >200 мс то, что §9 запрещает.

Одна оговорка о честности прогона: прод обновился в середине сеанса (другая ветка,
`#380`, очередь заявок на вход). Все числа ниже пересняты на итоговой сборке `801a095`;
цифры, снятые до обновления, отличались в пределах шума.

## Отсутствие фризов

Ни одного залипания главного потока > 200 мс **ни в одном** сценарии — во всех прогонах
`over200 = 0`.

| длинный штрих (120 сэмплов) | 25.8 мс | 0 |

| панорамирование, 100% | 29.1 мс | 0 |
| панорамирование, 567% | 28.8 мс | 0 |

| вращение | 25.7 мс | 0 |
| переключение инструментов | 31.0 мс | 0 |

Панорамирование бесконечного холста (#151) проверено отдельно, в отдельной infinite-комнате
с содержимым: на 100% и на 567% — ноль пропущенных кадров.

## Чего в этом прогоне нет

Пороги §9 требуют **оба** целевых сценария, здесь закрыт один.

- **iPad** — не проверялся вовсе.
- **ПК с графическим планшетом** — не проверялся.
- **Очень малый зум на бесконечном холсте.** Свести пинчем ниже 100% синтетическим
  вводом не удалось (жест не регистрировался), так что зона, где жили #363 и #365,
  этим прогоном не покрыта. Это ручная проверка на пять минут.
- **Мобильная сеть** — только wifi, см. выше.
- **Удобство** («записать, что раздражает») — субъективная часть, её делает Илья.

## Что сравнивать после релиза

именно эти строки, а не «ощущается быстрее».
