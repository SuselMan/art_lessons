# Галерея кистей и образцы штрихов

Согласовано владельцем 20 ноября. Задачи #837 (строки и штрихи), #838 (галерея).

Кисть — неизменяемое содержимое: параметры модели и ссылки на ресурсы. SHA-256
считается по каноническому JSON без имени, исходного файла и внешнего id. Версия
формул и исходный размер входят в содержимое. Пользовательские названия, доступ,
избранное и состав комнаты хранят ссылки, не создают копии содержимого.
Отдельный хэш исходного файла позволяет повторно использовать результат конвертации.
Текстуры уже хранятся по SHA-256. Общий объект не делает личную кисть публичной.

Набор выбора комнаты отделён от append-only ресурсов истории: удаление из выбора
не удаляет описание или текстуры старых операций. Участник может рисовать кистями
набора, но изменение набора использует существующее право настройки комнаты
(сейчас владелец). Новое право со своей системой ролей не вводится.

Галерея возвращает страницы лёгких записей без дескрипторов и масок. Исходные
превью Krita сохраняются. Образцы создаются движком Grafetto, публикуются один раз
и кэшируются по хэшу содержимого и версии генератора. Для ластиков используется
цветная подложка, для растушёвок — два цветных пятна. Весь каталог не рисуется
на клиенте при открытии списка. Общие UI-компоненты берутся из submodule UiKit.

Старый формат manifest v1 читается; новые записи используют ссылки на CAS.
Неиспользуемые CAS пока не удаляются автоматически: корректность истории важнее
преждевременной сборки мусора. Это не означает готовность всей задачи — приёмка
включает UI, приватность двух пользователей, холодный вход и сохранность штрихов.


Текущий набор сохраняется одной атомарной CAS-манифест-записью в sets, вместе
с нативными ссылками. rooms содержит ресурсы принятых штрихов, а не всех когда-либо
выбранных кистей. Первый live-пакет/операция закрепляет нужное содержимое до
принятия в журнал. Доска использует набор родительского урока; соответствие
доски уроку берётся из БД и сохраняется для синхронного приёма операций.
Прежние манифесты читаются без удаления и переписывания защищённых архивов.
