# Остаток поддержки кистей Krita

Срез 08.11.2026, исходный код e0020a2c. Это 14 блоков разного размера, не оценка трудозатрат и не процент готовности.

Критерий: ожидаемое поведение активных настроек, работа общего движка и онлайна. Пиксельная идентичность Krita не требуется. Наличие 16 семейств и 144 названий не означает поддержку произвольного KPP.

Порядок: закончить01; выполнить02; затем выбирать03–12 по количеству реальных затронутых кистей и важности. Не начинать следующий малоиспользуемый механизм ради самого расширения списка.

- [ ] **01. Закрыть Bristle Soak** — Код готов; GPU/онлайн не закрыты.
  Закрытие: Подхват цвета щетинками, сохранение цвета по штриху, история и второй участник. Исправляются ошибки QA-подготовки, результат пока не принят.
  Основание: krita_bristle.py:15; BristleSoakGather139.ts.

- [ ] **02. Привязать остаток к реальным кистям** — Нужна инвентаризация.
  Закрытие: Повторный импорт штатного каталога и независимых бесплатных наборов: для каждого активного предупреждения сохранить кисть, опцию и причину. Убрать устаревшие предупреждения. Это определяет приоритет пунктов ниже; число затронутых кистей пока не известно.
  Основание: krita_import.py; текущие compatibility notes.

- [ ] **03. Источники холста Deform и Spray** — Не реализовано полностью.
  Закрытие: Deform/useOldData должен читать начало штриха; Spray canvas sampling тоже должен сохранять исходный холст вместо текущего перед каждым запросом. Две отдельные реализации и проверки.
  Основание: krita_deform.py:13; krita_spray.py:144.

- [ ] **04. Дополнительные режимы Clone** — Не реализовано.
  Закрытие: Healing, perspective correction, merged projection и taper. Для каждого режима — самостоятельный результат, а не включение флага.
  Основание: krita_clone.py:9-10,22.

- [ ] **05. Filter: недостающие фильтры и smudge** — Частично.
  Закрытие: Есть Gaussian, Unsharp, Invert, Desaturate, Posterize. Нужны Filter/smudgeMode и конкретные дополнительные фильтры из инвентаризации02; полный набор фильтров редактора Krita не включать автоматически.
  Основание: krita_filter.py:10-14.

- [ ] **06. Experiment: заливка узором** — Не реализовано.

  Закрытие: Цветной RGBA-tip вместе с активными HSV/dual; Texture Lightness/Gradient в сочетаниях Wash/dual вне разрешённых областей. Gradient tip + Wash138 уже готов и не входит в остаток.

- [ ] **09. Композиция и Color Smudge** — Частично.

- [ ] **12. MyPaint pigment** — Не реализовано.

  Основание: mypaint_import.py:18; krita_import.py:507.

- [ ] **13. Итоговая функциональная совместимость** — Приёмка после реализации.
  Закрытие: На каждом зафиксированном в02 примере активные опции работают либо явно обозначены ограничением. Для изменённых механизмов live/undo/redo/перезаход/восстановление контекста; несколько одновременных авторов и старые инструменты без регрессии.

- [ ] **14. Планшеты: плавность и память** — Итоговая проверка не закрыта.
  Закрытие: Samsung и iPad: обычные и тяжёлые кисти, длинные сессии, первый и повторный штрих, память и отсутствие перезагрузок. Сравнить задержку с нашим карандашом; реальные доступные датчики.
  Основание: Настоящие устройства; не CPU paintDabs вместо задержки пера.

## Что не считаем недописанным алгоритмом

Округление/AA, native RNG-последовательность, ICC/HDR и точные пиксели не входят в цель. Размеры bitmap, число частиц/волосков, GPU/CPU-бюджеты и безопасный SVG — отдельные явные ограничения. Необоснованные отказы действительных кистей учитываются в02, но лимиты не убираются вслепую.

## Правило закрытия

Код, импорт и фактическое поведение отмечаются отдельно. Один законченный блок — один сгруппированный прогон затронутых возможностей; повторный полный прогон только при новом риске или сбое. Число тестов и строк кода не заменяет закрытый пункт. Новые пробелы добавляются только с примером активной настройки и ссылкой на реализацию.
