# Галерея и образцы кистей — проверка 20 ноября

Задачи #837 и #838 реализованы в agents/unified-brush-engine. Production и main
не обновлялись. Используется прежний пользовательский стенд и прежняя QA база.

## Что проверено

- 108 тестов в9 файлах: личные библиотеки, CAS, приватность масок и PNG, доступ
  к текущему набору до первого штриха, история после удаления, общий набор досок,
  гонка уведомления со старым запросом, полная работа кэша без запуска браузера,
  импорт, API ресурсов и регрессии существующего конвейера.
- TypeScript frontend/backend по исходникам этой рабочей копии, без shared/dist.
- map:check прошёл; map:rules —0 ошибок,73 предупреждения существующего графа.
  Три чужих untracked исходника явно исключены из сканирования, чтения и сборки.
- Настоящий браузер через HTTPS: поиск, добавление, избранное, создание комнаты
  с7 нативными и1 выбранной Krita кистью; два независимых автора, обычный и Krita
  штрих с одинаковым экспортом, Undo/Redo, отказ участнику в изменении набора,
  удаление из выбора без потери рисунка и холодный перезаход с теми же пикселями.
- Реальный предоставленный владельцем Bundle:1 импортированная кисть,1 пропущенная
  с отчётом. Два независимых пользователя видят собственные загрузки и готовые
  штрихи; загрузки сохраняются после reload. Повтор того же файла не меняет
  инвентарь assets/contents/artworks/sources — тяжёлые данные не копируются.
- В публичной галерее190 Krita +7 нативных инструментов; готовые серверные PNG
  для всех197 записей. Визуально просмотрены рисующая кисть, ластик, clone,
  desktop и мобильный viewport. Это не новая оценка точности всех движков.

Использован VPS software WebGL. Производительность и UX на настоящих Samsung/iPad
этим прогоном не объявляются проверенными. Аппаратный пункт старого чек-листа
остаётся открытым. Тестовые браузеры закрываются в finally.

## Хранение и публикация

Набор выбора хранится отдельно от ресурсов реально записанных операций.
Старые форматы и архивы читаются без удаления. Неиспользуемые CAS пока не
собираются автоматически; использованные данные и комнаты защищены.

UiKit подключён submodule на опубликованном27d6262, совпадающем с Sports и health.
Код библиотеки не изменялся. Строка нового потребителя добавлена в CONSUMERS.md
локально; публикация этой документации и Git push Grafetto в запрос не входили.

Компактные доказательства и хэши сборки: temp/brush-gallery-20261120/.
Оставлены рабочие backend/web службы и база стенда; прежнее frozen окружение
нужно для отката и Python importer. Промежуточные gallery-v1…v4 удаляются после
проверки gallery-v5. Страница прогресса и карточка сервиса используют прежние ссылки.
