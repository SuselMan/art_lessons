# Завершение поддержки кистей Krita

Состояние:2026-11-07. Публичный QA frontend/backend11c23f8a1.
Представлены16 современных семейств;144 выбираемых штатных пресета,
171 историческое определение. Это покрытие семейств и выбранного каталога,
а не всех механизмов произвольных KPP.

## Что означает готовность

Принцип и активные настройки кисти выполняются ожидаемо. Пиксельное совпадение,
идентичная случайная последовательность и одинаковое сглаживание не требуются.
Отличие принципа, проигнорированная активная настройка и замена режима другим
не считаются поддержкой. Детерминизм между участниками Grafetto обязателен.

Каждый пункт закрывается конкретными входными пресетами, проверкой поведения,
сохранением в операции, live/undo/redo/cold и отсутствием регрессии старых инструментов.
Проверки группируются после законченного блока; планшеты нужны для итоговой
отзывчивости и датчиков, не для каждой правки импортера.

## Порядок работ

- [x] 0. Зафиксировать границу и проверить предупреждения. Исключать выключенные
  родительские опции из списка потерянных механизмов. Исправлен ложный флаг динамики
  силы выключенной текстуры. Полная ревизия остальных предупреждений остаётся в п.1.
- [ ] 1. Общие датчики и композиция ответов. Инвентаризация активных пробелов,

  числа контроллеров; затем Mirror с динамикой и оставшиеся Rotation/locked-angle

## За пределами цели

Полный редактор Krita, её управление документами и пиксельная эквивалентность не
переносятся. Chalk/Dyna удалены из современной Krita; legacy совместимость —
отдельная цель. Ограничения формата/размера и безопасности должны быть явными.

## Доказательства и актуальность

Исходники импортера — `scripts/brush-import/krita_*.py`, общий контракт —
`packages/shared/src/brush*.ts`. QA-артефакты: `temp/device-runs/krita-stroke-20261024`.
Исторические compatibility notes не доказывают наличие текущего дефекта: старые
определения сохраняются ради replay. Аудитировать исходный пресет текущим импортером.
Число пресетов с предупреждением не равно числу сломанных кистей.

### Пункт1: первая реализация

Общий `BrushDynamic.combine`: product/sum/max/min/difference scaling-группа,
сумма signed additive-сигналов, отдельные кривые, не более16 плоских листьев.
Константа линейной опции применяется до ограничения, не дублируясь в результате.
Время и keyed per-stroke randomness обнаруживаются внутри выражения; pressure
switches Grafetto отключают только pressure-листья Size/Opacity/Flow. Старые
product-профили не переписываются. Новый формат57; обычный Mirror58 использует
один порог0.5 для обеих включённых осей, включая дочерние маски.

Остаются: twist/pressure-in и прочие отсутствующие датчики; ColorRate с
неединичной константой и новым выражением (нелинейное преобразование требует
отдельной проверки); native non-painting RNG/timer-события (пункт4). Для специальных
растеризаторов без mirror-pass активный Mirror отклоняется. Сам пункт1 ещё не закрыт.

Rotation: scaling-группа теперь поддерживает все5 способов объединения без size-like clamp перед переводом в угол. Additive tilt-direction и до16 листьев; стандартный product-путь сохранён.

Следующий блок: native checked Rotation без кривой (constant half-turn), absolute
DrawingAngle с собственной кривой/offset/Lock и смешанными датчиками. В size-like
выражениях absoluteOffset сохраняет отдельный множитель. Новый input-policy нужен
только новым форматам61/62; исторические product-профили не переписываются.
Независимый child absolute input остаётся пунктом3.

Distance: геометрический прогресс в world pixels из канонической записанной
центральной траектории, с длиной/повтором и собственной кривой. Это не Fade
(счётчик дабов). Вычисление согласовано до/после paint admission и сохраняется
в scratch snapshots; обычные кисти не выделяют дополнительное состояние.
Отличия подразделения кривой от Krita допускаются; сетевые границы не влияют.
Фото инструментов наследуются между rendering-ревизиями той же пары source/name,
приоритет собственной картинки сохраняется; новые файлы изображений не создаются.

### Параллельный блок 07.11 (локально, ещё без device QA)

Pixel: standard ellipse/rectangle поддерживает checked constant/per-dab Softness,
меняющую native fade coefficients; форма/opacity остаются независимыми. Формат64,
отсутствие параметра сохраняет старый путь. Не относится к soft-curve generator,
spikes/density/randomness; Color Smudge по native сохраняет softness1.

ColorRate: снимается отказ nonunit constant combined-sensors. Существующее
выражение применяет constant перед clamp; современная стратегия возводит уже
полученный rate в квадрат, legacy compensation сохраняется. Нового wire нет.

Bristle: только внутренний pure CPU helper расхода каждого волоска и продолжения
порциями. Descriptor admission и renderer v2 не включены. Это подготовка,
не заявленная поддержка depletion/soak/max-alpha в приложении.

### Интеграция 07.11: блок проверки

Soft-curve Softness68 подключена к импорту, bounded CAS lookup, существующим
primary/mask sampler и per-dab uniforms. Нет дополнительной CPU-копии ресурса
в рендерере; старый radialCurve не переписывается. Gaussian и прямоугольный
soft-generator не подменяются этим профилем.

Bristle66: aliased non-compositing request использует whole-RGBA alpha winner
с DEPTH16 и strict GREATER, не MAX по компонентам цвета. Подготовка перед
локальным/peer/cold paint, lifecycle/context reset, staging переиспользуется.
Depletion/soak пока не допускаются: pure helper ещё не streaming renderer.

Hatching67: opaque background записывается общим source.background RGBA8.
Default brush background Grafetto белый; custom через setBrushBackground API,
UI picker пока отсутствует. Бумага и цвет принимающего клиента не читаются.
Legacy setHatchingBackground — alias. Shape/request opacity применяются один раз.

Общие проверки этого блока:344 unit/47 modules и320 Python PASS. Реальная GPU
проверка выполняется отдельно; до неё этот блок не объявляется проверенным стендом.
