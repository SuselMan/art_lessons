# ADR 017: Импорт кистей как данные общего движка

Статус: QA-прототип #806. Расширение ADR013; не меняет минимальный объём §15 релиз-трека.

## Принцип

Разделяем описание кисти, ресурс изображения и алгоритм нанесения материала.
Встроенные и импортированные цифровые кисти используют общий `BrushDescriptor`
из shared и существующий stamp renderer. Графит и физическая акварель сохраняют
свои модели материала и общий путь пера, дабов, слоёв и журнала; им не добавляется
ветка по расширению импортированного файла. Новую универсальную модель всех
материалов этот этап не вводит.

## Импорт и совместная работа

Владелец запускает offline CLI `scripts/brush-import/convert.py`. Форматы
Procreate brush/brushset и ABR6.1/6.2 имеют отдельные читатели, выход общий.
Коммерческие архивы и полученные текстуры остаются вне Git. HTTP-загрузки
пользовательских файлов пока нет: парсер не является публичным upload endpoint.

Сервер при старте читает каталог из `GRAFETTO_BRUSH_LIBRARY_DIR`, проверяет
структуру, размеры и SHA256 и удерживает неизменяемые ресурсы. Без env каталог пуст.
Этот каталог предназначен для закрытого QA-стенда: он доступен всем пользователям
данного экземпляра сервера. Персональная библиотека, права на ресурсы конкретной
комнаты и квоты ещё не реализованы; включать такую библиотеку на публичном сервере
до решения этих вопросов нельзя.

В начале клиент получает только метаданные. Исходное разрешение изображений
сохраняется до2048², снижение выше этого порога отмечается. Форма и зерно адресуются
хешем raw grayscale bytes. Перед выбором кисти, обработкой входящего штриха или
восстановлением истории клиент загружает нужные ресурсы и проверяет SHA256.
Входящие события ожидают в общей очереди без изменения порядка. Ошибка ресурса
не подменяет импортированную кисть стандартной: рисование останавливается с сообщением.

Штрих хранит обычный `brush:imported-<hash>@1` preset-токен. Передача raw изображений
в Operation Log не нужна. Каталог и все использованные версии необходимо сохранять
вместе с данными сервера; нельзя заменять каталог при наличии ссылающихся рисунков.
Пока нет автоматического GC, регистрации ссылок комнаты и переноса ресурсов при
экспорте в другой сервер. Улучшение конвертера требует нового ID/version.

CPU хранит загруженные ресурсы для синхронного undo/replay (верхний предел каталога
256МиБ). GPU имеет LRU до4 импортированных форм и4 зерна на renderer — примерно
43МиБ с mip levels при2048². Mip levels строятся CPU integer box filter так же,
как у встроенных кистей. Совпадение пикселей на разных GPU требует отдельной проверки.

## Точность

Это перенос поддержанного подмножества настроек, а не совместимость движков.
Wet Mix, dual brush, grain movement, сложные динамики и режимы Photoshop/Procreate
не считаются воспроизведёнными. Каждая кисть содержит warnings; отсутствующие
встроенные изображения дают skipped вместо подстановки. UI различает источники
ABR/Procreate. Детальная матрица и команды — README конвертера.

Оригинальные встроенные пресеты и их исторические версии не изменяются.
