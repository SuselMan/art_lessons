Акварель — проверка исправлений

Версия e5d50e71. Свежие тестовые штрихи на Fine; повторы реальных мазков смотрите в основной галерее.

Вода и проход через лужу

Область перерисовки теперь включает всю изменившуюся карту воды, а не только прямоугольник вокруг курсора. Это устраняет расходящиеся частичный и полный кадры. При входе в лужу после сухого начала учитывается максимальная влажность всех порций штриха.

Зигзаг

Слева в каждом снимке — чистая вода, справа — пигмент. Короткое торможение на повороте теперь не оставляет мгновенное максимальное скопление краски.

Сухая кисть

Контакт считается по высоте бумаги. Настройку по фотографиям сухой кисти ещё предстоит сделать.

Окончание штриха

Четыре свежих штриха через события пера: круглая кисть с постоянным и падающим нажимом, затем плоская с постоянным и падающим нажимом. При отрыве продолжение сужается от последнего реального отпечатка. В старых повторах галереи дабы окончания уже записаны прежним движком.
