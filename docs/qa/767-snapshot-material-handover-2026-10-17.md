# #767: передача снимка вместо прежней мокрой сцены

Публичный `restoreLayerFromSnapshot` оставлял прежний resident/parked M70 source и sliced rebuild живыми. Воспроизведение: accepted wet B (seq2) → reconnect bitmap (covered3) → Dry (seq4). Bitmap сначала точно появляется, затем Dry копирует goal прежней лужи поверх него. `0019eec5` фиксирует этот baseline pixel FAIL. Snapshot upload вызывается из `restoreLatestSnapshot`/`restoreRoomState`; periodic snapshotSync только публикует, сам снимки не накладывает. Network replayGate не закрывает уже удерживаемую physical lease.

Перед upload отменяется незаписанный физический хвост этого слоя, снимается lease, останавливается stale job и удаляется прежний wet source **без Dry**. Принятые chunks и pending outbox остаются в журнале. После pin нового bitmap учитываются уже известные подтверждённые room serverSeq; local op.seq не является watermark. Известный pending/послеснимочный tail пересобирается поверх bitmap. Уже отменённый covered target использует существующий history-repair gate; неизвестная последовательность accepted tail тоже требует backfill, вместо угадывания покрытия.

Если snapshot уже содержит pending stroke, это невозможно доказать до ACK по одному watermark. Pending не выбрасывается и остаётся непубликуемым. При позднем ACK с seq≤coverage его ID отмечается covered и слой пересобирается, удаляя временное двойное нанесение. После этого bitmap+tail точно сходится с независимым полным replay. Другого blob queue или копии decoded snapshot не добавлено.

Проверки: stale wet goal не перезаписывает bitmap последующей сушкой; pending local ink сохраняется; известный confirmed prefix не наносится повторно; late ACK включает covered ID и исправляет двойное нанесение; snapshot отменяет только held unrecorded tail, сохраняя ровно один отправленный wet chunk, повторно построенный с новым original substrate; pending Undo не воскресает из bitmap; unknown-seq tail fail-closed. Дополнительно forced reconnect drain + remote Clear(seq2) + held UP + confirm(seq3): actual nonempty canonical pixels равны decoded full replay. Targeted 3 файла / 86 тестов PASS, web typecheck PASS. Native fluid target/presentation в этих engine fixtures заменены; художественная точность требует hardware QA.
