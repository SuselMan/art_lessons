# Морфинг R2: убрать зернистое проявление цели

Запрос16.10 14:53–14:54: точка пигмента в чистой воде, ранний ореол распадается на пиксели. Базаa93fc39e, #728.

## Воспроизведение и причина

Samsung SM-T970/Adreno650, М70 live, настройки Ильи. Кистью260px проведена чистая вода (пигмент0), затем поставлена точка90px с пигментом100 и цветом#403b9b. Сняты фиксированные стадии0/10/25/42/65/100% через diagnosticMorphAt; PRNG/время/ввод фиксированы. Это наш воспроизводимый вход, не точный лог фотографии пользователя.

В presentation.MORPH стоял независимый hash по floor(worldPixel/3). Разные3×3px клетки получали разные времена появления целевого изображения, даже если цель гладкая. На42% это создаёт крап в слабом ореоле. Низкое разрешение/неоднозначность flow тоже могут создавать другие артефакты; их устранение этой правкой не заявляется.

## Изменение

В М69/М70 живой режим включает compile-time smoothArrival. Сохраняется пространственный перенос через matching-flow, но добавление целевого изображения теперь использует единую плавную долю прогресса без случайной клеточной arrival-модуляции. Нелинейные часы120с, источник, расчёт цели и кнопка Dry не менялись. Сама цель не подвергалась дополнительному blur. Старые контроллеры по умолчанию оставлены на legacy arrival. В интерфейсе новая анимация названа «морфинг R2».

Дополнительных текстур/проходов нет; из активного шейдера убрана случайная проявка. Фактическое GPU ускорение не измерялось. diagnosticMorphAt — только просмотр фиксированного кадра без изменения канонического материала.
