# М04: локальность обновления цели

Поручение Ильи20:07: убрать влияние далёких мазков, не повышать влажность всей лужи при увеличении её площади; исходную волосатость менять отдельно.

Исходная М03 неизменна. Новый adapter native-target-v04 сохраняет предыдущую цель P/C/coverage и разрешает обновление только в локальной области последнего жеста. Область — объединение записанных wetContacts (с геометрией эллиптической кисти) плюс конечное плечо влияния8–24px. Для слабой воды используются brushTravel, для отсутствующей траектории — область последнего ctx.bounds. Маска строится одним GPU draw по всем контактам, без readPixels в живом пути. При prepare больше не используется максимум радиуса/standing из dryCtx всей старой лужи: используются radius и standing последнего жеста. Новый сухой wash сбрасывает сохранённую цель.

Это ограниченная модель локального воздействия, не новый консервативный решатель количества воды на площадь. Перенос воды на большие расстояния и независимые часы каждой лужи здесь не реализованы: clock/presentation пока общие, цель может быть промежуточной, если предыдущий solver отменили до завершения. Финальные поля вне области нового воздействия сохраняются; это не доказательство неизменности каждого экранного пикселя анимации. Возможны заметные границы области влияния — нужна художественная проверка. Полный solver пока по-прежнему считает общий кандидат, затем локально объединяются результаты; ускорение вычисления не заявляется.

Samsung SM-T970/Adreno650: пять жестов size90. Первая лужа x200; далёкие x800 и845; соседнее расширение x260; чистая вода (pigment0) обратно x200. После каждого жеста ждали target.done (не полной естественной сушки). Поля цели первой лужи P/C/coverage: после далёких жестов0изменённых байтов; при соседнем расширении старый противоположный край x<180:0изменённых байтов. После воды в том же месте поля меняются (P139677/C102977/coverage19866байт) — локальное повторное увлажнение не отключено. Затем Dry→done:true, GL0/lostfalse/pageerrors[]. Это единичный функциональный прогон, не количественное доказательство реалистичности или отсутствия швов при всех размерах кисти.
