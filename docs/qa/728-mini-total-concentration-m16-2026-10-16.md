# М16: направление переноса по полной концентрации

Основа М15 c0a10523 + UI89d2c505. Причина: carry15/16 использует trav*mobile.a/capacity, не полное количество пигмента. Local phase split делает подвижную долю неодинаковой; светлая область может иметь больше mobile, чем тёмная, и отдавать ей пигмент. Это подтверждённая возможность одного оператора, не доказательство происхождения каждого светлого пятна на фото Ильи.

## Изменение

Только carry15/16 в изолированной работе М16: потенциал trav*(mobile.a+fixed.a)/water. Water=solvent.a с floor.02 при plateauphase, иначе1 (за пределами доступной водной модели это плотность, не измеренная физическая концентрация). Неизменны выбор source/background, пути фронта, spatial conductance/capillary pair, ограничение переносимого количества мобильной долей, фоновые diffuse и остальные native операции. ДляP/C отдельные shaderprograms с правильным FIELD_OP_COLOUR. Runtime hooks временно подменяются только синхронно внутри собственной операции, затем восстанавливаются finally. +2programs, нет новых постоянных текстур относительноМ15.

Одна цель из всей rawлужи; отмена без очереди и предыдущего результата. М15/frozen версии сохранены. ПорогиUI общие сМ15, скопированный JSON указываетМ16.
