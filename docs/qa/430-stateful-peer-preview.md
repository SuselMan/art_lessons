# #430 — превью чужого маркера и растушёвки

Основа `ce3aadba67fc554b515fb9a2c926182de1fea673`, трек #825.

## Причина

Fallback reveal подтверждённой операции рисовал в прозрачный AccumulationBuffer.
Ribbon и SmudgePainter такие цели пропускают: до коммита мазок отсутствовал,
затем появлялся целиком. Обычный физический live stream уже рисовал в слой.

## Исправление

Маркер и растушёвка раскрываются в настоящем слое, сохраняя состояние жеста.
Префикс временно защищён существующим протоколом unrecorded ink. Каноническая
операция забирает уже показанные дабы без повторного нанесения. Snapshot запрещён
до передачи владения журналу. Отмена, flush и потребитель без коммита убирают
временные пиксели пересборкой. Асинхронный коммит удерживает claim; callback
доставляется один раз, в том числе при потере контекста и reentrant live packet.
Передача физическому потоку возвращает accepted operation, а известный префикс
не наносится поздним packet zero повторно. Legacy operation без strokeId имеет
частный carrier по op.id, который освобождается после reveal.

Переносимая краска SmudgePainter раньше принадлежала только участнику. Старый
штрих того же автора при replay другого слоя затирал текущий imprint и курсор.
Теперь состояние принадлежит буферу и участнику; factory движка задаёт destroy
hook буфера, который освобождает imprint. Временный replay/export не загрязняет
живой слой. Потеря контекста забывает все мёртвые GPU handles. Тема понимания #834;
статус понимания Ильи не повышался автоматически.
