# Перенос выбранного M70 R2 в Grafetto — этап выделения ядра

Запрос Ильи 16.10 15:04, #728. Эталон: локальная метка
`watercolor-m70-r2-approved-20261016`, commit 960e94eb; художественная база b7a40cfc.
Точные параметры и кисть: `prototypes/mini-puddle/presets/approved-m70-r2-20261016.json`.

## Выполнено

В `apps/web/src/engine/src/watercolor/puddle` перенесены без изменения формул:
отбор оптического избытка и фильтр площади компонентов, мягкое смешивание M70,
пространственный presentation R2, нелинейные часы и изолированный расчёт цели.
Mini использует эти же модули через небольшие адаптеры, без второй копии математики.

`PuddleTargetHost` явно задаёт владельца GPU, scratch pool, существующий settle plan,
проверку исключительного доступа и инвалидирование front paths после отмены.
По умолчанию цель получает замороженные утверждённые параметры. Mini отдельно
передаёт читатель своих изменяемых ползунков. Ядро не читает globalThis/localStorage.
Цвет/вода/пигмент кисти остаются данными мазка, не частью параметров solver.

## Свежая проверка

Samsung SM-T970, Adreno650; существующий Mini QA5383, без нового сервиса.
Typecheck web и scoped oxlint прошли; map:check прошёл.
`mini-live-morph.cjs` теперь принимает MINI_PRESET для проверки утверждённых настроек.

1. Выделение фаз/presentation, затем отдельное выделение цели: сырой P/C/coverage
   и конечная цель совпали побайтно между обоими этапами на одинаковом входе.
2. На утверждённых семи параметрах живой режим и контурный расчёт дали одинаковые
   сырой материал и конечную цель.
3. Пройдены отмена предыдущей цели следующими мазками, изменение/возврат параметров,
   переключение режима без изменения исходника, Dry с тем же финалом и проверка,
   что новый отдельный мазок после Dry не меняет старую сухую область.
4. GL error=0, context loss=false, page errors=[].

Артефакты `temp/device-runs/m70-port-20261016/summary.json`, подкаталог approved.
Это не проверка комнат и не измерение физической задержки пера.

## Ещё НЕ сделано — не выдавать за готовый комнатный перенос

- Подключение общего raw-материала слоя к принятому логу всех участников вместо
  per-stroke FIFO. Конечная цель всегда из исходного материала, не из морфинга.
- Записанная версия модели/фиксированные параметры; восстановление после undo/redo,
  повторного входа и снимков; единая логическая граница Dry.
- Обобщение square single-tile адаптера на плитки/размеры документа, бюджет памяти,
  освобождение при удалении слоя/перестроении/потере контекста.
- Переносимый источник шума: исходный M70 использует sin-hash в GPU reconstruction.
  Он сохранён для точного сравнения с утверждённым эталоном, но не годится как
  доказательство детерминизма на разных GPU. Перед активацией нужны фиксированный
  источник шума и сравнение на двух настоящих GPU.
- Комнатный Samsung smoke: быстрые пересекающиеся мазки, масштаб, сушка,
  второй участник, undo/redo, rejoin. Нынешний QA Grafetto остаётся прежним v4.

Mini reference сохранён. Галерея не пересчитывалась; push/main/production не менялись.
Собственные CDP-вкладки закрыты, ADB forward/reverse удалены. Остались существующие
Mini/Grafetto QA сервисы, общий backend и зарегистрированная сборка Mini.
