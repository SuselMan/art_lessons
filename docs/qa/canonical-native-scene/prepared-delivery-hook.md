`buildCanonicalStrokeCommandsFromDelivery(CanonicalPreparedDeliveryInput)` is pure with respect to gesture state. It consumes already computed kept dabs, previous, wetOf, delivery maps, anchored gesture scalars/preset/profile/options and a tile; it does not prepareDrawable/prepareDelivery/noteWetContacts again. Original canonical preparer now calls the same helper after its single delivery advance. Optional `RibbonStrokePainterContext.onPreparedWatercolorDelivery(request)` runs synchronously just after production's prepareDelivery and before reach/target guard/per-tile GPU phases. Request contains CPU input without tile, targets (null in deferred ownership), scratch, bounds/compositeBounds, actual anchored landedWet/wetPeak/strokeDir. Caller builds per-target commands immediately via `{...request.input,tile}`. Callback is a synchronous observer: do not retain mutable scratch/maps/dab references, await later or advance state again. Commands own generated Float32 vertices, but metadata ownership/freezing is the consuming executor's responsibility.

OFF/unset observer preserves current GL path. Hook does not skip foreign-water imports, scratch GPU allocation, legacy raster/composite or finish lifecycle. It is a safe CPU seam, not completed native Room routing. Foreign import exists before this hook; native delegation must explicitly route that ownership and retain noteFinish/cancellation/queue semantics rather than return from an arbitrary tile loop.
