# #419: удаление живого урока

База: `7377ab77dca3128d727f088c3b4f71f56e61e448`.

Удаление строки в БД раньше оставляло урок и доски в resident Map. Сокеты
продолжали получать подтверждения операций, данные которых уже некуда сохранять.

После успешного DELETE отменяются текущие cold loads урока/досок, принудительно
удаляются resident records и presence indexes, затем подключённые сокеты
получают существующее `kicked` и покидают content/social channels. Транспорт
остаётся подключён для других проектов; socket metadata больше не позволяет
отправлять операции. На клиенте остаются рисунок для экспорта и уже существующее
предупреждение, что дальнейшая работа не сохраняется.

Cancellation tokens живут только во время холодных загрузок, с уборкой в
finally: постоянного списка удалённых ID нет. Перед публикацией resident record
проверяется отмена. Сокет, успевший переключиться в другой урок за await адаптера,
не удаляется из нового урока. Ошибка/отказ DELETE не отбирает доступ у участников.

## Свежая проверка

- Browser baseline на старом коде: FAIL97.2s, DELETE200 без предупреждений;
  последующие thumbnail uploads доходили до HTTP500/P2003 (FK удалённой комнаты).
- После исправления: 44 профильных unit/integration теста; весь server rooms +
  roomRoutes **550/550, 24 файла, 30.74s**, exit0. Включены реальные Socket.io
  server/client: owner на уроке, student на другой доске, оба получают kicked,
  поздняя operation отклонена как not_joined, повторный вход not_found,
  транспорт жив. Проверены отмена нескольких стадий cold load, независимый урок,
  отказ/сбой DELETE и переключение сокета во время адаптерного await.
- Chromium/SwiftShader, отдельные Postgres/API/frontend offset419: **PASS53.9s**.
  Создание урока, гостевой вход, переход по UI на вторую доску, реальный штрих,
  DELETE, предупреждения владельцу/ученику, сохранение видимого рисунка для
  экспорта, HTTP403 на snapshot index удалённого урока и доски. JS errors и
  HTTP5xx запрещены; после исправления их нет.
- Узко отмечены штатные HTTP отказы: thumbnail403 до завершения create_room,
  thumbnail429/throttle и уже начатые thumbnail/snapshot403 после DELETE.
  Первый 403 зафиксирован раньше socket created room; это запрет записи до
  получения права, не ошибка DELETE. Остальные console errors запрещены.
- Полный typecheck (workspaces/e2e/scripts), lint:fix, map:check/map:rules:
  exit0; после уточнения E2E его typecheck повторён, exit0. Новых нарушений
  архитектуры нет, имеющиеся предупреждения сохранены.
- Первый after-run прошёл функциональные assertions и остановился на учёте
  стартового thumbnail403; финальный прогон учитывает конкретный отказ.
  Один расходный запуск с неверным grep не нашёл тестов; его стек тоже убран.

Собственные browser/context и API/frontend закрыты. Пять одноразовых Postgres
контейнеров и anonymous volumes удалены; disposable trace/video удалены
qa-cleanup с marker/nonce и проверкой отсутствия процессов. Dependency views,
собственная копия generated Prisma/shared/dist и ссылка на paper удалены.
Временных работающих ресурсов не осталось. Worktree и компактные логи/один
скриншот baseline сохранены в игнорируемом temp/419-delete-live-room/.
