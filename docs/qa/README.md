# Каталог QA Grafetto

Сценарии для повторных проверок живой совместной работы. Задача: #689.

- Стабильные сценарии: [scenarios/collaboration.md](scenarios/collaboration.md).
- Результаты конкретного запуска: `runs/<дата>.md`.
- Большие артефакты, логи, снимки и замеры: `temp/device-runs/<запуск>/`.
- Автоматизация: существующие `e2e/specs/`, стенд описан в `e2e/README.md`.

Каждый результат содержит версию, устройства, число независимых участников,
условия, шаги, ожидаемый и фактический результат, статус и ссылку на дефект.
Статусы: PASS / FAIL / BLOCKED / NOT RUN. Не считать эмуляцию реальным устройством;
синтетическое перо через bridge проверяет pipeline, но не физическое перо и ладонь.

Новый дефект: воспроизвести, сохранить доказательства, создать bug issue,
добавить регрессию, проверить её на исходном коде, исправить и повторить сценарий.
Исправленный локально дефект остаётся открытым до мержа и проверки.
