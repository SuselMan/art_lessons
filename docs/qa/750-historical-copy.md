# Исторические источники копии и merge: #750 / #751

Функциональный релиз-трек #825, раздел сохранности рисунка. База:
`95251c63f6b1d1b2961ee6adb5ade33303dd44d3`. Ветка:
`agents/750-historical-copy`, исправление `0ef837154`.

## Исправление

Исторический источник читается на момент структурной операции. Раньше
`layerPixelOps(source, beforeSeq)` отбирал старые операции, но использовал их
**нынешние** состояния. Поздняя отмена автора поэтому стирала уже созданную
чужую копию при полном replay. Теперь состояния префикса восстанавливаются
обычной машиной Undo/Redo/revoke с контролами, попавшими до границы копирования.
Известные будущие контролы не меняют прошлое; разрешённые состояния неполной
истории без доступных контролов сохраняются как fallback. Учтены авторство,
порядок контролов и многочастные жесты. Кэш ограничен четырьмя префиксами на
контекст и инвалидируется ревизией журнала.

При replay источника используется этот же исторический контекст, включая
вложенные копии/merge. Нынешние checkpoints оригинала в таком replay отключены:
они могут содержать более позднюю краску. Обычные rebuild/checkpoint пути
сохраняются. Контекст журнала восстанавливается в finally; зависящий от него
кэш wet-replay инвалидируется при входе/выходе. Шейдеры, формулы инструментов,
формат операций и сервер не менялись.

Исправление адаптировано из сохранённых локальных `2bd6176ca`, `8680f05f2`,
`4343b1db7`; акварельные изменения той ветки не переносились.

## Проверки

- До правки две исходные engine-регрессии падают: replay после Undo пустой;
  replay со свежим снимком оригинала отличается от исходной копии.
- После правки 16 целевых тестов проходят: оба дефекта, merge, вложенные
  структурные источники, многочастные штрихи, Undo/Redo/ветвление, revoke,
  неизвестные контролы, авторство и инвалидация кэша.
- Весь набор движка и модели слоёв: **1971 PASS / 166 файлов**, 303.19 с,
  один worker.
- Полные typecheck, lint:fix, map:check и map:rules прошли. У линтера остаются
  существующие предупреждения; map:rules сообщает 5 предупреждений, 0 ошибок.
- Браузер: два новых сценария на исходном коде падают по целевым причинам
  (98.1 с), с исправлением оба проходят (111.8 с). Реальный Chromium,
  явно выбран SwiftShader. Это не проверка физических устройств или различий GPU.
- Первый сценарий: автор рисует через настоящий ввод; другой участник дублирует
  слой через UI; Undo/Redo оригинала и холодный вход автора копии сохраняют
  пиксели. Сравниваются все RGBA-байты декодированных тайлов через SHA-256
  вместе с геометрией тайлов, у обоих участников и при полном replay.
- Второй: после копирования автор рисует в оригинале ещё штрих; реальные текущие
  тайлы оригинала устанавливаются через restoreLayerFromSnapshot с подтверждённым
  серверным seq. Полный replay старой копии исключает новый штрих. Это
  контролируемая установка checkpoint, а не ожидание автоматической серверной
  публикации снимка.
- Подготовительный браузерный запуск с ошибочными координатами за листом не
  засчитан; в итоговой версии перед копированием проверяются непустые пиксели.

## Воспроизведение

После настройки совместимых зависимостей, сборки shared, актуального Prisma
client и baked paper:

```sh
npx vitest run apps/web/src/engine apps/web/src/lib/layers --maxWorkers=1
npm run typecheck
npm run lint:fix
npm run map:check
npm run map:rules
E2E_GL=swiftshader E2E_PORT_OFFSET=750 npx playwright test e2e/specs/historicalCopy.spec.ts
```

Изолированный стек: API 5241, frontend 6241, Postgres 56241. Базы разработки и
production не использовались. Результаты локальных запусков сохранены в
игнорируемом `temp/historical-copy`.

Все собственные браузеры и процессы остановлены; контейнеры и их anonymous volumes
удалены. Расходные trace/video, временные dependency views и сгенерённая сборка
shared убраны; сохранены компактные журналы и два снимка исходных дефектов.
Worktree и исходные коммиты сохранены. Main/push/deploy этой пачки не выполнялись;
issue остаются открытыми до поставки.
