# #761 — старый контроль уже учтён в снимке

Основа: `81c67b445fbd0886de8a7cb997b8337dd40b1a7d`, после #775.
Релизный трек #825, общая история обычных инструментов, без переноса M70-акварели.

## Исправление

При исторической свёртке устанавливается положительная причина изменения цели:
последний подходящий addressed Undo/Redo/Revoke, с учётом автора, группы strokeId
и порядка чанков. Локально отказанные события причиной не являются. Причина с
подтверждённым исходным `serverSeq <= coveredSeq` уже запечена в снимок: повторная
догрузка не требует карантина правильного bitmap.

Pending, неизвестный порядок и более поздний контроль сохраняют прежний ремонт.
Если частичная история знает новый контроль с ещё неизвестной целью, нельзя
доказать, что это не sibling того же жеста: сохраняется fail closed. Новый контроль
по известному другому слою не блокирует этот слой. Ранее установленный ремонт
такой проверкой не снимается; он разрешается только существующим полным префиксом.

Используется исходный серверный порядок, никогда локальный индекс журнала.
Существующий cause-параметр движка передаётся до SnapshotIO; сетевой контракт не
меняется. Семантика глобального неотменяемого paper_dry остаётся прежней.

## Проверки

- Baseline: 3 FAIL/10 на исходном main для уже запечённых Undo/Redo/Revoke,
  когда сначала загружается цель, потом контроль. Иной порядок страниц сохранён.
- После исправления расширенная выборка: 81/81, четыре файла. Положительные
  случаи сохранения исходных пикселей и возможности публикации; отрицательные
  pending/поздний/неизвестный контроль блокируют публикацию. Контроль101 после
  snapshot100 нельзя спутать с локальным индексом1.
- Жест через два слоя, старые grouped regressions #759, отвергнутые события #775,
  известный несвязанный слой и неизвестная ещё цель нового контроля.

Браузер использует два standalone WebGL движка: настоящий непустой снимок с уже
учтённым Undo; частичные страницы3/4 при отсутствующих1/2/5; затем новый revoke6
должен включить защиту. Начальный стенд не обновлял composite order после restore:
его чтение пустого framebuffer до композиции не считается доказательством бага.

- Первый полный движок: 1923 PASS/1924, один timeout неизменённого chisel-теста

  расхождение assertion. Отдельный повтор без браузера: все 27/27 тестов charcoal
  PASS, 16,17 с; тест и его timeout не менялись. Финальная выборка снимков

- Room: 690/690, 68 файлов, 65,17 с. Typecheck workspace, lint:fix,
  map:check/map:rules — exit 0; предупреждения существующие.
- Финальный браузер: Chromium и реальный Samsung, 2 PASS, 58,5 с со стартом
  стека. Darkness исходного снимка и после старого Undo: 0,8667; pending repairs
