## Новая проверка

Архив `494-snapshot-io/temp/ab494/rig.mjs` на VPS отсутствует. Это повтор
описанного сценария с новым входом, а не заявление о воспроизведении точных
старых координат, GPU-драйвера или причины тех19 пикселей.

Новая интеграционная проверка создаёт настоящую комнату и100 коротких штрихов
через native pointer pipeline движка. Операции проходят настоящий outbox,
Socket.io, серверное хранение и ACK. После появления снимка seq100 следуют
три длинных жеста углём и три карандашом. Каждый продолжается до собственного
chunk boundary движка, затем завершается pen-up: шесть gesture IDs и12
операций хвоста. Операции напрямую в журнал не подставляются.

Затем тот же автор проходит холодный вход с прежней cookie, а новый участник
в отдельном browser context входит в ту же комнату. Для обоих проверяются:

- все112 stroke IDs в исходном порядке;
- ровно12 операций после восстановления;
- прозрачный PNG совпадает по всем пикселям и компонентам RGBA, maxDelta0.

Chromium/SwiftShader, актуальный сервер и WebGL. Это не физический S Pen,
не iPad/Surface и не доказательство межвендорной GPU-детерминированности.
