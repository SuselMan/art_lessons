# Компактное поле при прежнем размере ячейки

Код `2d385b9f`, ветка `agents/728-watercolor-room-integration`. Модель `front8-detail-flow-v2`, QA opt-in `?qaFastDry=compact` (GPU pacing8). Default остаётся одобренным Б, production/push не выполнялись. Новая версия требует ручной художественной оценки.

Минимальный размер S2 поля уменьшен с768² до512². Размер ячейки остаётся2 мировых пикселя, минимальный S1 остаётся1536², большие рабочие области по-прежнему округляются вверх до256. Вспомогательный S4 контакт сохраняет прежний размер ячейки4, но тоже использует меньший прямоугольник. Ни бумага, ни fine отпечаток кисти не уменьшаются. Все остальные формулы flow-v1 сохранены. Уменьшение поля меняет граничные условия и float sampling, поэтому это отдельная записанная версия, а не exact оптимизация прежних мазков. Переключение cached extent между версиями проверено unit-тестом.

Для512² вместо768² объём основной группы из10 RGBA8 текстур уменьшается с22,5 до10MiB. Семь дополнительных контактных текстур384²→256² экономят ещё2,19MiB. Это оценка этих17 текстур, не всего потребления браузера/GPU. Число ячеек таких проходов меньше на55,6%, но общее ускорение ограничено остальными этапами и каденсом.

Выраженного нового прямоугольного контура при осмотре центральной капли не обнаружено; художественное одобрение не заявлено.

Временные ресурсы: активные собственные GPU harness, disposable на VPS/ноутбуке и ADB19223 остаются на время продолжающейся проверки. Два прежних QA frontend и один backend сохранены, новых сервисов нет.

Другие эксперименты поверх v2 (не включены): paired P/C в одном RGBA32F fragment и два распаковывающих прохода. На Samsung172/1032 пар для2/12мазков exact, GL0, но12Dry6239→6562мс; AMD2334→2301мс, ничтожный однократный выигрыш. Persistent packed state уменьшает распаковки до24 на1032пульса, но дал белые пробелы и max249/meanAbs3,765 на2мазках Samsung. Явный highp sampler не устранил дефект. Ошибка этого прототипа не локализована; не объявляем математическую невозможность подхода и не переносим его в source. Увеличение только Dry-порции до8/16 в очереди также не ускорило существенно: Samsung6269→6542/6422мс, AMD2317→2342/2288мс. Все эти route/runtime adapters существуют лишь в диагностике, старые и новые сохранённые модели ими не менялись.

Adreno WebGL1 сообщает float color target capability, но не EXT_disjoint_timer_query; асинхронное ожидание GPU на timer query для этого устройства не реализовывали. Список расширений сохранён в отчёте полной комнаты.

Два настоящих устройства одновременно в общей QA-комнате: AMD Renoir+Adreno650, два разных автора, один shared layer, CDP pen через PointerInput. Оба мазка приняты и доставлены до ordered Dry. На каждом устройстве redo вернул его baseline точно; Samsung reload/rejoin также exact. GL0/no loss/errors[]. Между GPU:415449 отличающихся из4194304 каналов полного1024²RGBA tile, meanAbs0,1534326/255, max208. Это не аппаратно независимая побайтная модель. Среднее включает весь tile, а не только окрашенную область; редкие крупные расхождения не исключены. Согласованность истории внутри GPU подтверждена, художественную приемлемость межаппаратной разницы ещё оценивает человек.
