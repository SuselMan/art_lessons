# Оптимизированный Mini1024, 18.10.2026

Интерактивный native-direct стенд имеет исходный и оптимизированный профили. Переключение открывает чистый лист. Режим подтверждается runtime, worker/source/build связаны SHA. Старый Worker-стенд и production не изменены. Ссылка хранится приватно в project-services; публичных ключей доступа в Git нет.

## Что ускорено

- Для доказанно пустой переносимой краски:35 шагов фронтов заменены3 проходами с сохранением рельефа,14 переносов и13 проходов диффузии — очисткой нулевых выходов. Восстановление цвета, обработка фона, защита сухих пикселей и сушка выполняются по прежним формулам.
- Guard узкий: текущая модель, масштаб1, один пигмент, отключённые контакты и отсутствие других экспериментальных режимов. Непустая краска и два цвета используют обычный путь. Доказательство получено из уже прочитанной CPU-маски, новых GPU-чтений ради него нет.
- Отдельно ускорена CPU-подготовка QA-изоляции: перенос целых32-битных пикселей, заимствование неизменяемого входа и подложки; бесцветные компоненты исключаются только из расчёта общего C после проверки нулевого C подложки. Вода остаётся в источнике. Этот wrapper не участвует в живом Mini.

## Измерения Samsung Tab S7+ / Adreno650

Прямой расчёт одной эталонной волны: **147.8→101.5 мс**, около31% в этой серии. Это медианы10 тёплых повторов на профиль: порядок исходный/оптимизированный/исходный/оптимизированный, по одному отдельному прогреву перед пятью измерениями каждой группы. Все выбросы сохранены; разброс существенный. Граница: существующий GPU-источник → reset/step/dry → полное чтение C в CPU. Это не чистое время GPU и не задержка после отпускания пера.

В остальных шести эталонных сценах короткий путь не включился. Общее ускорение активного переноса на этих сценах не заявляется. Например, первые тёплые повторы двухцветного fallback203.2/190.3 против200.4/204.9 мс — вариативность, не доказанный выигрыш.

Отдельный QA-wrapper, неизменный исходный kernel, один прогрев+3 повтора/вариант:

| Вариант | Медиана полного общего C |
|---|---:|
| Исходный |684.3 мс|
| Только быстрая подготовка |542.3 мс|
| Только исключение бесцветных задач |364.9 мс|
| Оба сокращения |251.7 мс|

Порядок фиксированный; это ablation, не чередующийся performance-тест. Его нельзя подставлять вместо скорости интерактивного Mini.

## Корректность и живое поведение

Samsung:7 сцен×2 профиля×3 повтора — все конечные P/C/покрытие побитно равны исходному профилю, семь входных карт неизменны. Эталонная волна активирует короткий путь каждый раз; шесть других сцен остаются fallback. Чередующаяся серия дополнительно проверяет те же SHA на всех повторениях.

На Intel UHD выполнены две **device-local** пары: волна и два цвета, по3 повтора исходного/оптимизированного. Внутри каждой пары входы/выходы точны; wave ускоренный, два цвета fallback. Это не доказательство межустройственного детерминизма: первоначальный строгий прогон обнаружил, что исходный brush/replay на Intel уже даёт иные сырые карты, чем Samsung. Этот предсуществующий случай сохранён отдельно; его не исправляли и не скрывали сменой ожиданий.

Живые последовательности на опубликованном HTTPS: волна→второй цвет; очистка→точка→чистая вода→новый пигмент. Переходы empty→empty→active проходят без залипания guard. Проверены профиль, чистый лист при смене режима, отзыв кнопки, экспорт PNG, ширина390, отсутствие ошибок GL. Живая геометрия не идентична эталонным записям, поэтому31% ей не приписывается. В проверенной последовательности полная цель была готова через243–499 мс после отпускания: здесь дополнительно есть ввод, подготовка, холодный старт и очередь GPU.

Основной UI-показатель включает контрольное полное чтение C после готовности цели. Длительность этого вызова включает ожидание уже запущенного расчёта, а не только копирование4MiB. Worker и GPU остаются разными границами; интерфейс не называет JS-submit готовым GPU-результатом.

## Проверки и сохранение

Frontend typecheck, strict Mini/runtime/UI typecheck, opt-in transformed strict source check, профильные CPU-тесты и lint:fix прошли. Общий monorepo typecheck остановился на отсутствующем Prisma Client в переиспользованной QA-среде сервера; backend не менялся. Новые зависимости не устанавливались, selected shared types временно собраны из этой рабочей копии.

Обновлена схема flow/anatomy.html: фактические сокращения отмечены у этапов, прямой native benchmark и QA-wrapper показаны раздельно. Старые CPU-интервалы блоков явно относятся к исходному разбору; GPU-время каждого эффекта не выдумывается.

Компактные доказательства, измеренные сборки/manifest, исходники, SHA, PC-аудит и PNG хранятся вне расходного cache в native-mini/evidence. Адреса/секреты не коммитятся. Временные runtime, браузеры, пробросы и зависимости-ссылки удаляются при завершении; worktree и исходники сохраняются.
