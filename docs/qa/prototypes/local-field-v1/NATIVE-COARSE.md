# Следующая проверка: native-coarse-v1 (11.10.2026)

Человеческая проверка local-field-v1: быстро, но неприемлемый вид. Илья указал
пиксельный край, потерю гребёнки, неправильное смешение, отсутствие подтёков и
расхода пигмента. Упрощённый материал отклонён; не переносить его в production.

`/watercolor-native-v1` использует настоящий PencilEngine и native preset/nib,
оптику, ribbon, расход кисти, мокрые контакты, перенос и tide. Это самостоятельный
лист без сервера, а не альтернативный replay старой комнаты. UI позволяет изменить
цвет/размер/воду/пигмент, Undo/Redo/clear и PNG export. Рисунок исчезает при reload.

Изменение внутри solver: для радиуса >=8 и окна >128 используется существующее
2x coarse resampling; минимальная рабочая текстура тоже уменьшается с1536 до768
только при scale=2 и явном DEV-флаге watercolorCoarseTransport. Без него код
production/комнат остаётся прежним. Сохраняется масштаб пустого внешнего поля
в мировых координатах. Маленькие кисти и другие потребители остаются прежними.
Это изменение разрешения, не готовая новая физическая модель.

96 unit-тестов planner/DEV-gate прошли. Новый тест: два цвета,90pxкисть,
сокращение суммарного числа обработанных front texels более4x, меньше front passes,
сохранение связанной плотности при переносе цвета/пигмента. MockGL проверяет
организацию вычислений, НЕ внешний вид/байты/реальную скорость GPU.
Typecheck прошёл; lint:fix без ошибок, существующие warnings остаются.

Chromium/SwiftShader: реальный pointer stroke на smoke-листе256² дошёл до
getError=0, pageerror отсутствуют. Закрытие browser зависло, собственное дерево
процессов принудительно остановлено и его temp profile удалён. Это ограниченный
smoke, а не успешная проверка latency, экспорта и истории нового материала.
Свежий HTTPS smoke загрузки: правильный route, coarse=true, GL0, ошибок нет,
browser закрыт штатно. Временных browser процессов не оставлено.

Остаются риски: coarse transport может сгладить гребёнку после растекания,
изменить оттенки/плотность, края и подтёки. Пауза на UP всё ещё возможна: legacy
canonical finish не заменён, не включать отвергнутый deferred finish.
Следующее решение — только после сравнения Ильёй внешнего вида и скорости.
Не считать native-coarse переносом всех достоинств production до этой проверки.
Серверных логов/совместной работы для этого варианта нет.
