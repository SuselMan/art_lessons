# Послойный по времени расчёт тайлов: первый эксперимент

Продолжение #805. Проверяется **только внешний поиск путей** из кандидата
«4+5+6 · С маской воды»: тот же `EXPANSION_FRONT_FRAG_805`, stride2,12 шагов,
неподвижная бинарная вода. Здесь нет полного переноса P/C, осаждения, общей
кромки, настоящей кисти, комнаты, журнала или морфинга. Синтетическая волна
с отверстием проверяет пересечение вертикальных, горизонтальных границ и углов.

А2 соответствует действующему конечному формату Grafetto:3508×2480.

## Механизм

Тайл хранит два состояния стоимости пути и неподвижную воду. Вокруг ядра —
два пикселя соседнего состояния: максимальное смещение данного shader-прохода.
Каждый шаг:

1. Все новые ядра вычисляются из предыдущего состояния.
2. GPU `copyTexSubImage2D` копирует новые края **и углы** в соседние новые ореолы.
3. Все пары src/dst меняются местами одновременно, затем начинается следующий шаг.

Копирование не читает пиксели на CPU. Порядок команд WebGL обеспечивает зависимость;
промежуточного `finish`/`readPixels` нет. Копирование читает только готовые ядра,
поэтому запись ореола не влияет на последующие копирования. Внешний край листа сухой.
Это точный размер ореола **этого прохода**, не всего акварельного алгоритма.
Остальные этапы потребуют собственных границ и синхронизации связанных P/C.

Режим «без обмена» — отрицательный контроль. «Сравнить» отдельно вычисляет
целую область и сравнивает каждый пиксель стоимости пути, а не только уменьшенные
превью. Требуется ненулевое число семян и расширение за их пределы.

## Время и отзывчивость

Это диагностический прототип с созданием входов и чтением всей карты для
побайтной проверки. `totalMs` включает подготовку,12 кадров ожидания между шагами,
GPU, чтение и CPU-превью. `submitMs` и `exchangeSubmitMs` — время выдачи команд,
**не GPU-время**. RAF измеряется во время всей операции, включая подготовку.

Сейчас все тайлы и три карты на каждый находятся в GPU одновременно. На А2 это
около100.5МиБ. Это проверка корректности границ, **не готовое решение бюджета памяти**.
Ограниченный кеш и повторное использование рабочих полей ещё не реализованы.
Сверху можно рисовать простой диагностической кистью; плавность настоящей кисти
и накопление нескольких расчётов этим не подтверждаются. Стенд не выполняет расчёт
при закрытой странице и ничего не сохраняет из нарисованного.

## Воспроизведение

Существующий совместимый esbuild берётся из798-wave-buffer, новые зависимости
не устанавливаются. Вывод — только в зарегистрированный disposable-каталог:

```
node --test docs/qa/prototypes/tile-step-805/grid.test.cjs
QA_OUTPUT=<registered-dir> node docs/qa/prototypes/tile-step-805/build.cjs
QA_OUTPUT=<registered-dir> QA_ADB_DEVICE=<verified-serial> node docs/qa/prototypes/tile-step-805/verify.cjs
```

Для Samsung сначала home-device-access и проверенный endpoint, ADBforward19336,
экран Awake. Проверка создаёт и закрывает собственную вкладку; пользовательские
вкладки не изменяются. После проверки убрать свой forward и disposable-сборку.
