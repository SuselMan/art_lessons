# Простое расширение краски внутри исходной воды

Два отдельных QA-кандидата: ровный и с неоднородным краем. Это другая художественная гипотеза, не эквивалентная оптимизация. Production не меняется.

`source.cjs` применяется к QA-копиям `ContrastPhase.ts` и `WatercolorSettlePlan.ts` перед anatomy-transform. Основные кандидаты сохраняют родной отбор контраста/Q, CPU-фильтр островков и reference P/C; меняются только пути растекания. Исходные карты не меняются. Старую гипотезу «вся мокрая краска участвует» можно включить отдельно явным `allWetMobile:true`: она обходит CPU-отбор двумя GPU-проходами, но не является основным сравнением.

`installNativeExpansion805(engine,controller,{noise,allWetMobile:false,radiusPx:24})` заменяет фронтовый примитив на дешёвый обмен между восемью соседями. `allWetMobile` по умолчанию равен `false`. Внешний фронт выполняет N единичных проходов независимо от этой политики, поэтому не достигает точек дальше N соседних пикселей. Вода берётся из неизменяемых GPU-карт источника. Сухие пиксели и диагональные пути через сухие углы запрещены. Внутренние фронты общей кромки тоже используют дешёвый примитив. Prefix-карты не строятся.

Ровный вариант имеет одинаковую стоимость пути; шумный — 1…1,7 в зависимости от заранее рассчитанной на CPU карты плавного шума. Он местами сужает расширение. Алгоритм не штампует цветовую копию расширяемой формы: родные carry/diffusion/rim продолжают перемещать P/C. Точное сохранение массы и одинаковые результаты разных GPU не заявляются.

Installer возвращает `{restore(),metadata,stats}`. `restore()` обязателен после всех повторов. Флаг действует только в `diagnosticRunCore`, исходные/конечные proof reads идут вне него. Для всех вариантов используем отдельный whole-GPU query. Основной `false` сохраняет contrast-события; историческая ветка `true` их обходит и несовместима с семью старыми группами.

Проверки кода: `node --test docs/qa/prototypes/native-expansion-805/expansion.test.cjs`. Они проверяют композицию реальных исходников, отсутствие CPU-readback в all-wet ветке, неизменяемые ссылки на воду, область действия политики и очистку ресурсов. Рисунок, отсутствие выхода за исходную воду, сухие пиксели, чистая вода, узкие связи и отверстия дополнительно требуют настоящего GPU. Эти проверки не заменяются MockGL.
