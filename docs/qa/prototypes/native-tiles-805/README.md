# Настоящая акварель на А2: обработка полного прохода по тайлам

Продолжение#805, запрос19.10.2026,08:27. В каноническом Mini режим
«Акварель · А2 / тайлы» использует **тот же PencilEngine, настоящую кисть,
PuddleTarget, контрастный отбор, перенос P/C, осаждение, общую кромку,
BackgroundMix и защиту сухого пигмента**, что обычный Mini. Профиль выбирается
обычным селектором, основной кандидат — combomask («4+5+6 · С маской воды»).
Ни Canvas2D-кисть, ни упрощённая карта путей, ни синтетическая волна не участвуют.

## Что именно разделено на тайлы

`shared-pass.ts` разбивает каждый нативный drawArrays в AccumulationBuffer на
непересекающиеся прямоугольники назначения. Весь проход заканчивается до
следующего прохода алгоритма. Шейдеры и их UV не меняются, чтение идёт из общей
текстуры предыдущего состояния: соседние значения уже доступны без копирования
ореолов. Существующий scissor пересекается с ядрами; blending не повторяется
на границах. Внешние края и мировая сетка остаются общими. Это не отдельный
полный solve каждого тайла и не растушёвка готовых картинок.

**Рабочие поля пока общие полноразмерные. Это НЕ физическое раздельное хранение
и НЕ решение бюджета памяти.** Следующий этап — хранить состояния отдельными
страницами и передавать необходимую границу между проходами. Текущий вариант
даёт полноценный художественный и численный эталон для такой реализации.
Режим «Целая область» отключает только partition исполнения, не меняя модель.

В источнике кисти пока используется один прямоугольный материал всего листа,
с полными P/C/водой/покрытием. Это явное QA-отличие от комнатных1024тайлов.
А2=3508×2480, геометрия естественная S1, без снижения разрешения. Старый cap1536
снимается **только** при явном флаге QA-владельца. Поле ровно размером листа,
без добавленной256пиксельной полосы: эту геометрию видит и tiled, и whole oracle.
Изменений production-исходников нет: cap меняется сборочным source.cjs.

## Поведение и ограничения

Настоящий исходный мазок виден во время движения. Расчёт после отпускания
выполняется пачками4нативных операций между RAF; каждый проход внутри пачки
обрабатывает все ядра. Следующий мазок отменяет прежний расчёт и использует
сохранившийся raw-материал. Морфинг в этом режиме временно выключен, чтобы
не добавлять полноразмерные presentation-текстуры; обычный Mini его сохраняет.

Замер после пера включает полный C-readback в CPU, то есть ожидание готовности
всей карты. Он честно измеряет готовый результат, но сам блокирует UI и пока
мешает требованию плавности. После него на экране нативный сухой target.
Средние времени/RAF разделены по размеру листа, размеру тайла, tiled/whole,
профилю, потоку и морфингу. Данные1024не смешиваются сА2.

Кнопка «Сравнить с целой областью» повторяет целый и tiled solve из того же
raw-материала и сравнивает SHA всех трёх карт: P,C,coverage. Это отдельная
синхронная QA-проверка, не часть живого замера; на ней возможна долгая пауза.
Пока новой цели нет, кнопка отключена. Другие устройства/комнаты/undo/replay
этим прототипом не сертифицированы.
