# Версии Мини-стенда

С 15.10.2026 изменения для ручной проверки получают последовательные номера. В интерфейсе всегда видны номер и исходный commit. Переключение открывает чистый лист; рисунки между версиями не переносятся.

- М01 (`?mode=morph&v=1`), 672cecc4: до облегчения старта, публикация каждой промежуточной цели, быстрый старт морфинга. Обычная детализация; неудачный fullResolution опыт отключён.
- М02 (`?mode=morph&v=2`, по умолчанию), ea121870: меньше копирований на DOWN, промежуточная публикация максимум10Гц, тот же быстрый clock.

controller-v01/v02 и material-blend-v01/v02 — сохранённые исходники двух вариантов. Их не менять при следующем опыте: создавать М03. Остальные модули сейчас общие и совпадают с обоими исходными коммитами; перед изменением общей зависимости сохранять её для старых вариантов и обновлять импорты снимков. Это стенды одной сборки, без дополнительных frontend процессов.

Проверка 15.10: Samsung загрузил М01 и через select перешёл в М02, GL0 в обоих, новый epoch0. Это проверка маршрутизации/UI, не повторная художественная оценка. Собственная вкладка/ADB-пробросы закрыты. Прежние два QA frontend и backend сохранены, новых сервисов нет.
