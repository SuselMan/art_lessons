# #474 — ошибка загрузки GPU завершает восстановление

Основа `9e82188ad9df53a01d5d4776b681d9d56c63ca4e`, функциональный трек #825.

## Найденный незавершённый критерий

Счётчики намерения/резидентных тайлов, сбор `gl.getError`, отчёт о частично
применённых слоях и фильтрация удалённых слоёв в snapshot index уже реализованы.
Но ошибка GPU оставалась исключительно диагностикой: слой получал coverage,
`markPublished` и новый snapshot checkpoint, а сетевой restore возвращал
`restored`. Комната объявлялась открытой; последующее сохранение могло закрепить
потерю пикселей, хотя исходные данные на сервере оставались целы.

## Исправление

После сохранения audit, до выдачи coverage/checkpoint, любая ненулевая GL-ошибка
прерывает восстановление. Слой dirty и непригоден для публикации. Существующий
путь failed restore показывает ошибку входа и запрещает запекать неполную комнату.
Отчёт сохраняет код GL, уже применённые слои и ошибку текущего слоя. Новый
успешный restore снова делает слой авторитетным. До загрузки ошибки GL по-прежнему
дренируются: чужая предыдущая ошибка не приписывается снимку.

## Проверки

- Baseline3 FAIL/35: ошибка upload не бросается, реальный движок внутри сетевого
  restore возвращает restored даже после успешного первого и сломанного второго
  слоя. После исправления111/111, пять файлов.
- Отдельно64/64: GL_OUT_OF_MEMORY и INVALID_OPERATION, запрет публикации,
  сохранение audit, успешный повтор, отсутствие новой coverage/checkpoint после
  неудачи, сохранность старого checkpoint при неудачной замене; серверный index
  отдаёт живые слои, при нечитаемой структуре не теряет нужные blobs.
- Браузерный baseline FAIL: glError1285 записан, но исключения нет и blocked=false.
  Флаг ошибки подаётся искусственно после реальной загрузки текстуры — QA не
  исчерпывает память планшета и не утверждает, что воспроизвёл настоящий OOM.

- После исправления Chromium+Samsung (GPU Adreno650 подтверждён),2 PASS,
  56 с. Инъекция ошибки приводит к исключению `GL error 0x505`, blocked=true;
  audit содержит1285, успешный повтор даёт glError0 и разрешает публикацию.
  Реальный memory pressure/OOM этой проверкой не моделируется.
- Typecheck всего workspace, lint:fix и архитектурные проверки — exit0.
  Собственные browser/context, временный стек, Docker volumes, disposable
  traces и подключения Samsung убраны, исходное питание восстановлено.
  Полный набор движка и комнаты запущен отдельно без browser нагрузки:
  2618/2618, 244 файла,299,64 с, exit0. Все проверки прошли.
