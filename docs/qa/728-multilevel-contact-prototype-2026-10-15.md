# #728 — многоуровневый контакт с сохранением fine residual

База: `29545871`, Г/v4. Диагностический кандидат, не новая записываемая модель и не production. Включать **до ввода**, на пустом изолированном стенде:

```js
engine._settlePlan.diagnosticMultilevelContact = 4 // сдержанный
engine._settlePlan.diagnosticMultilevelContact = 8 // более крупные шаги
// 0 — принятый v4, значение по умолчанию
```

Импортировать engine из этой рабочей копии. Условия применения: detail-flow material (включая v4). Для radius>=48 прежняя контактная сетка S4; другая геометрия кисти, Г, вода, front, dry tide не меняются. Число буферов и размеры совпадают с v4. Никакого readback, CPU транспорта либо новой полной runtime-копии.

Принцип: исходный контактный оператор использует `abs(dot(...))` и обмен туда/обратно — это симметричный обмен, а не направленный backtrace. Его дальний эффект аппроксимируется иерархией обменов на расстояниях J=8/4/2/1 (режим8), либо4/2/1 (режим4). Интегральный пространственный второй момент сохраняется: Σ count×gain×J² = originalCount×originalGain. Такой же масштаб получает концентрационное смешение. Локальный остаток5%/10% связывает классы coarse решётки. При100 исходных pulse получается11/22 pulse соответственно; это расчёт числа шагов, **не измеренное ускорение GPU**. При коротком контакте<8 pulse сохраняется исходный solver.

У каждого длинного ребра проверяется каждая промежуточная мокрая ячейка и минимальный flow exposure; перескакивание через сухие щели запрещено. Перенос P и оптического C по общему неизменённому pre-step P/C; прежние integer donor и capacity ограничения сохранены. После обоих draws выполняется copy-back. Увеличен scissor halo до самого длинного прыжка. Отдельный lazily compiled shader: default v4 shader и его стоимость не меняются.

Fine реконструкция остаётся прежней: fine input + bilerp(coarse final−coarse initial), а не upscale всей кисти. Поэтому сохранены исходные волокна и профиль Г. Это не математически точное v4: меняется пространственный kernel, округление и отбор узких каналов. При реконструкции сохраняется прежний clamp, поэтому абсолютное сохранение массы fine результата не доказано. Требуется просмотр тонких гребёнок, подтёков, жёлто-синего контакта и puddle/drop. Большой jump может недооценить перенос по узкому извилистому каналу; локальная доля лишь частично исправляет это.

19 targeted tests прошли; web typecheck и штатный oxlint прошли (только существовавшие предупреждения). Targeted tests проверяют второй момент, границу exchange, общий P/C pre-step, единственное владение семью coarse буферами, finish/abort/context-loss и default-off. Pixel/hardware проверяет общий root harness; подагент не запускает сервисы или браузер.

Временные ресурсы: собственных сервисов, браузеров и сборок нет. `node_modules` — symlink на базовую рабочую копию после точного сравнения lockfile; исходники shared остались в этой рабочей копии. Worktree и ветка — сохраняемый результат, не disposable.
