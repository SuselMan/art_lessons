# Накопленная история: диагностика восстановления WebGL

Источник: combined b8633207, frontend5314/backend4537, собственная комната fd7_wS7X. Исходники, физика и формат операций не менялись. Один аппаратный Chrome/Vega, два участника. Chrome закрыт в finally.

Исходный длительный soak завершил шесть раундов (686966 мс, 11,45 минуты завершённой работы), затем упёрся в ожидание idle60с при восстановлении истории58штрихов/65операций. Состояние прогресса того ожидания не было снято, поэтому исходный timeout остаётся inconclusive; это не подтверждённый deadlock и не выполненный20минутный soak.

Контрольный повтор заново открыл ту же историю без серверного snapshot. До первого loss был реальный carried checkpoint с prefix8, не исходный prefix48. Во втором цикле checkpoint отсутствовал. Это ограничение воспроизводимости сохранено явно.

Поллинг каждые5с не читает GL: фиксируются rebuild.start/applied/part, settle.next/ops.length, очередь, pending, paperLoaded и logcount. Прогресс первого цикла11→31→47→59; второго24→39→53→60. Оба завершились без остановки прогресса. Probe установлен один раз; повторная установка wrappers исключена.
