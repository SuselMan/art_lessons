# Обычная Room: Surface, GL2/MRT/front — 8 октября 2026

На frozen `97e31b45` выполнены две руки настоящей Room: GL1 OFF и
GL2 + MRT + front batching ON. Кисть 400: сначала вода, затем пигмент;
один автор, один слой. В обеих руках включены joined/deferred, mixed выключен.
Это WebGL Grafetto, не bounded WebGPU-сцена.

**Качество PASS:** упорядоченные поля, material и whole RGBA побайтно совпали.
UI Dry, meaningful Undo (пигмент удалён), Redo и свежий читатель завершились;
Dry/Redo/fresh совпали внутри каждой руки и между руками. Операции сохранены
сервером; GL0, потери контекста и ошибок страницы нет. ON подтвердил реальные
constructor-флаги, MRT выполнил 87 пар без fallback.

Одна пара не доказывает устойчивый выигрыш. Pixel upper bound включает
синхронное чтение GPU и меняет последующую cadence; это не задержка физического
пера до показа экрана. Мокрые промежуточные пиксели не заявлены идентичными.
Для устойчивого standalone wall-замера см. [полный factorial](728-webgl-factorial-surface.md).

Первая попытка ещё до ввода остановилась с `paperLoaded=false`: в frozen
hosting отсутствовали baked assets. Затем восстановлены те же 7 файлов
(12 150 964 байта), без регенерации; SHA проверены. Валидный OFF завершился,
но между руками память была ниже обязательных 1700 MiB — контроллер остановился.
После освобождения своих контекстов и восстановления памяти ON запущен отдельно
с тем же source/helper. Порог abort500 не ослаблялся. Чужие вкладки/Chrome не закрывались.
