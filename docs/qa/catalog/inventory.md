## Недостающее покрытие и дальнейшие задачи

- Адаптировать NIGHT harness в runner с явным seed/env/cleanup и dry-run: сейчас нужна ручная подготовка.
- Нормализовать остальные исторические runs по case/device/runtime; пока отсутствие индексированной записи — NOT RUN для новой lane, не отрицание истории.
- QA-042: открытый 748, точное совпадение разных GPU не достигнуто; необходим regression input на каждую исправляемую причину.
- QA-041/040:744 и 787 — отдельно бюджет видимого Undo/открытия и изолированные performance повторы на каждом GPU.
- QA-045:777/778 — durable terminal reject, старые вкладки, browser restart и cross-batch mapping; expected FAIL остаются.
- QA-049:747 — multi-tile A4/infinite; не выдавать поддержку восьми мокрых слоёв за поддержку страницы.
- QA-043:791 и старое closedDry-наблюдение 752 требуют сохранённого actual до oracle и повторяемого входа.
- QA-046: аппаратное воспроизведение mixed-history785 и отдельная причина прежнего all-M70 исключения.
- QA-038/030: согласовать lastactualmaterial/длинный hold и семантику переноса активной воды при copy/merge.
- QA-048/050/051/052: непрерывная лужа 30 мин, действительный cached export-only вход, аппаратный stylus/palm и полный урок.
- iPad M70: нет аппаратных результатов этой ночи; Surface touch22/24 незавершён, board-ACK аппаратный gate не пойман.

Новые продуктовые fixes, новые issues, внешняя система тест-менеджмента и весь большой прогон
в 793 не входят. Существующие issue номера/ограничения сохранены; дальнейшая автоматизация
не выдаётся за выполненную в этой задаче.
