# WebGPU PoC: проверка поведения после отзыва Ильи

2026-10-08. Илья сообщил: смешивания не видно, рисование выглядит как карандаш.
Первоначальный программный oracle и аппаратный вывод проверяли арифметику и доступность, но не доказывали выразительное поведение акварели.

## Контрольная аппаратная запись

Surface, Intel gen-12lp, Chrome 154, первоначальный PoC 030dd978.
Сценарий Mix colors, работающая симуляция, 512×384, наблюдение 10 секунд.

| Метрика | Начало (13 шагов) | Через 10 секунд (616 шагов) |
|---|---:|---:|
| Подвижный пигмент | 18252.698 | 12791.478 |
| Осевший пигмент | 1732.607 | 7193.826 |
| Общая масса | 19985.304423 | 19985.304248 |
| Пространственная дисперсия массы | 5094.666 | 5431.691 |

Линейный масштаб пятна по sqrt(variance) вырос лишь примерно на 3.3%.
Это не самостоятельная метрика цветового смешивания: требуется ещё профиль каждой
компоненты, перенос за исходный контакт и проверка повторного смачивания.
Аппаратный скриншот показывает две полосы с локальным зелёным перекрытием;
существенного движения вдоль водяной области эта проверка не подтверждает.

## Причины в текущей модели

- Один шаг переноса охватывает соседнюю ячейку; расстояние диффузии растёт как квадратный корень числа шагов.
- Направленный контактный перенос слаб и затухает множителем 0.9 за шаг.
- Осевший пигмент не возвращается в подвижную фазу под мокрой кистью.
- Диагностические кнопки оставляют симуляцию на паузе; рисование после них нужно проверить отдельно.

## Следующая проверка

- [ ] Пигмент заметно распространяется за исходный отпечаток внутри воды.
- [ ] Два цвета взаимно перемещаются в мокрой области.
- [ ] Проход мокрой кистью перемешивает существующую краску.
- [ ] Сухой промежуток между лужами блокирует перенос.
- [ ] Диагностика не оставляет обычное рисование неожиданно замороженным.
- [ ] Сохраняются масса, неотрицательность, replay и undo/redo.
- [ ] Исправленная модель проверена на настоящем Surface.

## Независимый аппаратный gate Q8 brush

Ветка прототипа также содержит отдельный перенос production brush compute
(66ad4dc5, в объединённой ветке 73104df1). Он не исправляет интерактивную физику.
Software Dawn дал byte parity, но настоящий Surface выявил расхождения:

| Fixture | Отличающиеся P/C байты | Максимальная разница |
|---|---:|---:|
| zero | 0 / 0 | 0 |
| capacity | 141 / 166 | 3 |
| partial | 1715 / 2308 | 5 |
| brush400 | 57115 / 79955 | 4 |

Следовательно, этот перенос пока не проходит аппаратный gate точности.
Причина ещё не локализована. Один прогретый GPU sample brush400: 1.901 ms;
это не FPS и не полноценное сравнительное измерение.
