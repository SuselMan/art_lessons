# #772: проверка отмены из-за потери GL-контекста

Источник: `02cf7c98`, WT744; MockGL, один worker, без аппаратной проверки.

Проверено: мокрый L → удерживаемый собственный ввод → чужое скрытие L →
`_handleContextLost` → `_handleContextRestored` → завершение replay jobs →
новый мокрый жест на другом слое K.

После loss остаются `_dryAtPenUp=true` и `_puddleRebuildAtPenUp={L}`.
Проверки очистки этих двух внутренних состояний не прошли, но проверка
реального последствия прошла: после нового UP слой K не сушится, материал
сохраняется даже после `finishDrying()`. Непустой старый набор отложенного
replay предотвращает глобальную сушку в этой последовательности.

Это отличается от подтверждённого #772 `hide → Undo(layer_add)`, где отмена
удаляет L из набора, и следующий UP действительно запускает глобальную сушку.
Дополнительный runtime-фикс context loss не внесён: расхождение материала не
доказано. Временная исследовательская проверка удалена из набора тестов.
