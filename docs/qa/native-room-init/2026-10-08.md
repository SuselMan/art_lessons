# #728: нативная Room — ресурсы до первого штриха

Это аудит и ограниченный кандидат, **не повтор аппаратной проверки**. Известные
сбои остаются: Surface до ввода потерял доступную RAM 1751→364 MiB, после чего
контроллер закрыл свою вкладку; Samsung принял size40 stroke, затем потерял GPU
process. Доказанной причины OOM/driver/compiler/watchdog нет.

## Доказанный лишний init

`backend.ts` раньше сразу создавал пять standalone material fields и два
brushOut, все RGBA8 1024²: **28 MiB явных texture payload**. Room их не использует:
материал принадлежит `RoomWatercolorExecutor`, source executor передаёт реальные
получатели. Кроме того, заранее компилировались 14 ribbon/stamp pipelines,
composite, две brush pipelines, raw diagnostic presentation и clear: 19 всего.
Room использует отдельные composite/brush/presentation владельцы. Две paired
ink pipelines на каждый source owner не нужны single-phase Room executor.

Frozen actual Fine `fine.e59ea6fa.paper` — **2048²**, проверено gunzip существующего
asset. Paper RGBA =16 MiB, lattice251²RGBA=252004 bytes (0.240329 MiB). Старый
backend до создания первого owner: 44.240329 MiB явных texture payload плюс
неизмеренные driver allocations, staging и canvas backing. Новый Room-owned
backend:16.240329 MiB, clear pipeline одна. На первом source добавляется 1×1
нулевой fallback water (4 bytes), если реальная availableWater не передана.
Это не измерение всего GPU heap; 28 MiB сами не объясняют потерю 1.4 GiB RAM.

CPU сохраняет production LA8 MiB и expanded RGBA16 MiB; loader может удерживать
height/catch intermediates, браузер/driver staging неизвестен. Старый expansion
создавал 4,194,304 временных массива на Fine texels. Новый indexed byte assignment
удаляет этот allocation traffic, сохраняя каждый Uint8. Actual Fine + неизменный
production `buildPaperCatch` даёт одинаковый RGBA SHA256
`31fdd40322f108302f3452c6427a82ddfc8a540819f4a1a356998838d0db63a4`.
VPS CPU два замера old318/322ms, indexed53/51ms. Это не время устройства и не GPU
или memory peak. Synthetic4096 benchmark сохранён отдельно как stress, не actual Fine.

## Границы кандидата

`roomOwnedResources:true` выбирает только DEV Room runtime. Standalone defaults
остаются eager. Room не конфигурирует лишний WebGPU canvas, не создаёт standalone
материал/brushOut/composite/brush/raw presentation. При ошибочном обращении к
standalone API — явная ошибка. Source shader модули и pipelines создаются по
первому использованию; pipeline descriptors, entrypoints, blend, vertex layout,
Q8 targets и порядок source phases прежние. Никаких изменений GLSL/WGSL math,
бумаги, дозы, packed ops, journal или settle schedule.

Постоянный zero fallback заменяет только прежнее никогда не записываемое default
water field: clamped integer textureLoad любого координатного значения возвращает
тот же zero RGBA; реальные targets.availableWater по-прежнему имеют приоритет.
Scratch/plan fields1536, foreign resources, source publication и native→GL bridge
после начала рисования этим атомом не оптимизированы. Lazy compile переносит CPU
compiler cost на первый source; улучшение init не означает улучшение start latency.

## Проверки и следующий аппаратный gate

6 targeted tests PASS: все65536 LA пары; actual source pipeline descriptors
lazy/eager, cache без повторного compile; Room init texture allocations/canvas
не тронут; foreign proof one-shot/retirement. App typecheck и scoped lint PASS.

Перед новой owned tab контроллер должен записывать CDP console events на диск:
`[native-room-init] paper:load-start`, `paper:expand-start` (LA bytes),
`paper:expand-done` (RGBA bytes), затем adapter/device start/done и backend groups.
Маркеры синхронны и выдаются до следующего потенциально тяжёлого этапа. Первым
проверить только paperReady/resources, RAM floor, validation/device-lost без
штриха; далее separately source40/settle. **В этом отчёте hardware нового атома
не запускался, Samsung GPU не трогался.**
