# М13: перенос всей исходной лужи без подавления пигментным фоном

Основа worktree3db95412. Цель: одновременно убрать clean/painted regression М12 и last-stroke-only М11, не вводя очередь или зависимость цели от готовности старой работы. М01/06/11 frozen не изменены. М12 убрана из селектора как неудачный опыт; прямая историческая URL сохранена.

## Отличие от М11

М11 отделяла только последний слой от предшествующего материала. М13 переносит всю исходную лужу одним общим оператором, с одинаковой линейной формой для каждого канала P/C. Движение задают водная область и фиксированная мезоструктура капиллярной ёмкости; коэффициенты не зависят от плотности/цвета фона. Это новый художественный алгоритм на существующей native pipeline, а не буквальное сохранение разделения М11 и не побайтный аналог production.

Canonical input из контроллераМ12 сохранён: на DOWN raw material восстанавливается из исходных P/C/coverage. Презентация не подмешивается в новый input. Один native job, DOWN отменяет его; новая цель с нуля. Нет накопленных jobs, доведения старой цели до конца, работы старой задачи во время нового штриха или цепочки priorGoal+delta.

Внутри target:
- mobile = вся исходная краска, fixed первоначально0;
- seed фронта из всей исходной водной coverage, одинаковый для чистого/окрашенного входа;
- carry: по каждой паре соседей перенос пропорционален (A_j cap_i - A_i cap_j)/max(cap_i,cap_j), одинаково для P/C. Rate≤.22*trav, четыре соседа; пара антисимметрична до RGBA8 записи/клипа;
- каждый промежуточный texel вдоль stride проверяется по wet domain. Stride>32 выключен, а не пропускает непроверенный сухой промежуток;
- ёмкость .35..1 по фиксированному native wcRimNoise на мезомасштабе, shader координаты uv*1024: пока только полный Mini1024². Это новая эвристика бумаги, не измеренный материал;
- brush contact: ранее проверенный bounded integer exchange unblocked-brush-v11, без общего channel-room lock;
- обычные native diffusion/deposition/composite и морфинг сохранены. Нет дополнительных material FBO относительно прежнего target; только программы/quad заменённых операторов.

Инъекция проходит через приватные программы WatercolorPasses и восстанавливает все методы/program/uniform/position в finally. Фрагмент собирается из frozen native shader с guard на форму исходника. Для production нужна явная интерфейсная реализация, не этот QA hook.

## Online и ограничения

Только текущий Samsung. Не доказана межустройственная byte parity; fixed hash в highp и RGBA8 могут различаться. До Grafetto нужны одинаковый журнал/seed/model version на двух устройствах, разный темп исполнения, поздний вход/история/Dry. Frame batching исходной live-кисти отдельно не проверен; совпадение повторов одного raw input этого не заменяет. М13 не production-ready. Галерея не пересчитывалась, push/prod нет.

Отклонённые промежуточные варианты: symmetric min исходного направленного wcCarryWeight закрывал пары; наследованный plateau gate мог дать0переноса (GPUprobe firstcarry delta0). В финальном операторе новый симметричный water-domain gate. Одной хорошей tracer-цифры без визуальной проверки недостаточно.
