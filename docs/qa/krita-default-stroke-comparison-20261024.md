# Сравнение доступных кистей Krita, 24.10.2026

Задача806 — импорт и соответствие кистей. Проверены все117 пресетов текущего
Krita-каталога@6, включая3 ластика и6 чистых blender.20 пропущенных
специализированных пресетов в этот прогон не входят.

## Что действительно выполнено

- Официальная нативная Krita5.3.4.1, gitbd6e8d0, из KDE AppImage на VPS.
  Все117 выбранных ресурсов нашлись; имена/filename/preset XML SHA сохранены.
- Grafetto eccdc7c2, фактически раздаваемая собранная QA-версия, Samsung SM-T970,
  Adreno650. Использован конструктор именно загруженного движка, а не mock/
  отдельный headless rasterizer. Тесты на отдельных холстах не отправляют ink
  в пользовательскую доску. Каждый временный engine/context уничтожен.
- 1024×512 RGBA, размер48px, цвет#b3442c. Три независимых горизонтальных линии:
  давление1; давление0.1→1; давление0.75 через синюю подложку#2060c0.
- По3 повтора каждой кисти в каждой программе:702 оригинальных PNG.
  Все экспорты успешны; Grafetto GL0. Размер/opacity/flow нативного preset
  сверены с источником; расхождений opacity/flow не обнаружено.
- Метрики сравнивают9 пар повторов каждой пробы; отдельно измерена вариативность
  native A/A. Все117 пар первого повтора просмотрены на контактных листах,
  все3 пробы каждой пары. Это не ручной просмотр каждого из702 оригиналов.

## Ограничения и вывод

Krita Node.paintLine принимает QPoint и давления концов, создаёт новый gesture
на вызов, оставляет time/speed/tilt/rotation нулевыми; RNG не задаётся через API.
Grafetto использует PointerInput с257 точками, timestamp0, нулевым наклоном.
Полный freehand с конечным временем, вращением и наклоном требует других тестов.
У Ink-1 Precision/Ink-2 Fineliner обнаружена несогласованность: наш renderer
заново выводит speed из travel/max(1,dt), несмотря на нулевую входную скорость.
Эти2 случая выделены отдельно; их нельзя по этому тесту объявлять обычным
провалом импорта или полноценной проверкой движущегося пера.

Автоматическая группировка, **не сертификат идентичности**:

| Группа | Число |
|---|---:|
| Близко в этом тесте |10|
| Есть отличия |23|
| Сильные отличия |82|
| Нужен отдельный тест скорости |2|

Основные визуально подтверждённые семейства проблем:

- Bristles2–4: потеря характерной формы/кончиков, сплошные прямоугольники.
- Grain/Texture: плотность, бинарные отверстия и неверная геометрия масок;
  Dithering почти исчезает, Big/Spines/Spray становятся прямоугольниками.
- Wet/WaterC: плотность/pressure response/края и смешивание сильно отличаются;
  Round-Fringe местами превращается в полый контур, Round-Grain — в полосатый
  прямоугольник. Это не объясняется одним случайным seed.
- Чистые Blender: Grafetto добавляет красную краску на чистом поле, где Krita
  только смешивает уже существующие пиксели.
- RGBA: потеря цвета/фактуры и масштаба, другая реакция на давление.

Отдельный контроль на самом Samsung: Android Krita5.3.4 GUI, Basic-5 Size Opacity,
40px, black, pressure1,127 Android stylus events; PNG сохранён штатным PNG export.
С нашим renderer на том же Samsung alpha-mask IoU при threshold25 =0.9752735.
Толщина совпадает; native endpoint немного короче. Этот один контроль не заменяет
117 нативных Android прогонов. Для Qt stylus motion нужен BUTTON_PRIMARY во время
контакта; вариант без него давал лишь точку и не использован как успешный эталон.

## Артефакты и проверка отчёта

Защищённые артефакты рабочей копии: `temp/device-runs/krita-stroke-20261024/`.
`comparison.json/csv` содержат каждую кисть и индивидуальную визуальную заметку;
`native-results.json`, `grafetto-results.json`, `proof.json` — версии/метаданные/SHA.

воспроизводимый harness; `native-runtime-setup.json` описывает portable environment.

открывает1024×512 originals. Static report размещён на существующем закрытом QA.
Приватная входная ссылка хранится вне Git, production не менялся.

Playwright viewer:117 карточек, поиск WaterC16, фильтр speed2, переключение
повторов/1:1, desktop/mobile viewport, ошибокJS0. Реальный iPad подтвердил HTTP200
для отчёта через HTTPS gateway. Native VPS runtime/Xvfb/скачанный AppImage удалены
через зарегистрированный qa-cleanup. Android helper и свой seed удалены после
сохранения контрольного PNG. Остаются QA frontend/backend/Postgres и отчёт для
просмотра; пользовательские исходники, recovery-файлы и комнаты не удалялись.
