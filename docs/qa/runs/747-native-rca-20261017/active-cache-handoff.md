# Продление активных QA-доказательств без копирования runtime

После закрытия Samsung-контекста нужные данные перенесены в новый зарегистрированный disposable cache puddle-747-active-20261017 с TTL8часов. Скопированы credentials/metadata одиннадцати собственных тестовых комнат, карта существующих слоёв, пять выбранных отчётов с gzip Contrast/P/C, R32 Room-report и полный принятый журнал десяти операций. Всего32проверенные копии,5332528байт. Исходники, зависимости, runtime, трассы, видео и base64-логи не копировались.

Частный path-mapping-manifest содержит from/to, размер и SHA256 каждой копии; новое размещение ledger пересчитано. Байтовая идентичность копий проверена. Права каталогов0700, файлов0600. Старый cache намеренно не закрыт до перехода ссылок других агентов; его срок истекает около15:28Europe/Vilnius.

Комнаты не удалялись. Следующие проверки используют новый путь. Временный QA frontend drop-in, собственные ADBforward/reverse и ссылка paper пока нужны для работы. Недоступный удалённый Vega Chrome остаётся отдельной неподтверждённой уборкой; его ownership сохранён, закрытым он не объявляется. Собственных активных Samsung страниц/GPU-контекстов и runner-процессов после проверки нет.
