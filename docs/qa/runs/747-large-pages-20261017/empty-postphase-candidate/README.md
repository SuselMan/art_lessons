API: `skipEmptyPostphase?:boolean` default OFF; `postphaseRect?(interior,allocated,{skipped:boolean})` callback for every reconstruction rectangle. Enabled and proved empty: yield then continue before allocateMany(8), reconstruct and both readbacks. Final P/C pages remain their initial logical zero; solved coverage snapshot and existing publication/edge preservation are unchanged. Callback records actual kept/skipped; no implied timing claim.

Proof inputs are capture-owned materialSupport, which scans all channels of P/C, water/local/foreign and coverage. It excludes original presentation RGB; existing dry substrate is separate. Any nonzero dry P/C intersects support and MUST keep. Coverage-only support also conservatively keeps. Unknown/malformed/mismatched dimensions/rects/union fail closed.

Important finite edge condition: MaterialFieldSnapshot.readRect defaults to CLAMP, NOT zero outside the page. Helper maps BOTH allocated interval endpoints through clamp(x,0,width-1) and forms the sampled inclusive pixel set. A completely exterior halo samples a one-pixel edge strip/corner; simply intersecting rect with finite page would be unsafe. The whole allocated rectangle includes reconstructionHalo; proving only its interior is insufficient. All geometry/endpoints are safe finite integers and positive extents.

With every allocated raw P/C/water texel zero, guard sees exact raw0 and wet0, while reconstructed result is a finite RGBA8 sample. Existing guard publishes material zero; omitting only that reconstruction is safe under this zero invariant. Global calculations and solved/coarse diagnostic captures still happen. This is not a dry-nonzero passthrough proof, nor a claim that arbitrary blank presentation pixels imply no material.
