# Scoped persistent captured backing — external candidate only

Base runtime: 466745f1. Served source, services, browser and GPU unchanged. Review/apply patch via SHA manifest; no architecture, shader, sampler, budget or quality change.

Opt-in `PagedPuddleInspection.persistCapturedBacking` defaults OFF. Source capture uses an explicit job scope, cap 64 MiB persistent proof bytes; immutable per-native-window restore uploads use a distinct scope, cap 6×1536×1536×4 = 54 MiB, disposed before scratch teardown in that window's finally. Source/window persistent maxima sum to 118 MiB, NOT a total-process CPU bound: existing one-shot proofs, raw snapshots, transient readRect/readPixels arrays and other allocations are separate. Cap overflow source reads retain original one-shot behavior; overflow uploads get no proof and ordinary eviction reads. No new image copies are made.

Buffer proof is token+contentRevision+same owned Uint8Array. First eviction memoizes uniformReadback; nonuniform repeat evictions reuse that array without another scan/read. Uniform adoption clears full proof and retains existing four-byte tuple; its ordinary hydration/eviction already needs no further read. Hydration drops ordinary nonuniform backing but leaves scoped token proof until release. Nonresident release preserves ordinary backing needed to restore content. Any writer, potential fbo writer, idle discard, destroy or context forget invalidates through existing centralized revision path.

CPU upload uses existing restorePixels method/order, not writePixels. Registration follows successful exact full upload; expected revision must advance by exactly one, catching reentrant write. No upload verification GL read is introduced. Inputs must be exact owned, aligned full-size Uint8Array with an ordinary ArrayBuffer (offset0, buffer.byteLength equals view.byteLength), preventing oversized-view retention/alignment surprises. Arrays must remain immutable until scope release. This is a trusted internal ownership contract, not verification of arbitrary caller-supplied bytes.

read() reserves persistent admission across possible reentrant callbacks; failures return reservation, cancellation during read releases a just-created token. Scopes hold release/counter functions, never a second array list. Old token releases cannot retire a later capture. Persistent counters include resident AND nonresident proof arrays; one-shot counters remain separate. Callback cancellation/error uses existing Target outer/window finally paths, unchanged.

CPU tests: 24 actual overlaid production-class tests, repeated eviction/hydration, identity/no duplicate read, all writer classes incl copy/region/fbo, uniform reuse, upload exact identity, cap/overflow, mixed scopes, discard/destroy/context forget, reentrant read/write/cancel, failed I/O and malformed ownership. MockGL texImage2D uses an alpha-oriented representation, so upload byte-equality assertions use per-pixel equal-channel data; actual GL upload argument identity is checked independently. Native device parity and memory/timing need explicit later GO. No device claim from mocks.

Overlay web typecheck passes; production regression file included separately in final check. Existing memory-pressure order may change when repeated GL reads disappear: native all-stage/final gate remains mandatory. No production enablement.
