# Компактные доказательства целевого QA undo-v1

Два настоящих GPU: Vega (AMD/OpenGL) и Surface (Intel/D3D11).
Одна сохранённая история, свежие браузерные контексты, М70 R2, холст 512×512.
Проверка выявила меж-GPU расхождение target во всех четырёх непустых слоях.
В `crossgpu-metrics.json` — точные размеры и метрики RGBA; пустые слои совпали.
В `bridge-crossgpu-diff.png` слева направо: AMD, Intel, абсолютная разница ×12.
Сырые GPU-массивы удалены после сохранения метрик и этой картинки.

Это промежуточный результат **до исправления восстановления состояния undo
при загрузке snapshot**. Самостоятельный сценарий на одном AMD показал:
после перезахода отменённый мазок А ошибочно восстанавливается в effective log,
а живой snapshot ещё содержит правильную картинку без А. Этот отдельный блокер
нельзя приписывать разнице GPU. Здесь не утверждается финальная готовность модели.

Приватных ссылок и авторизации в этом каталоге нет.
