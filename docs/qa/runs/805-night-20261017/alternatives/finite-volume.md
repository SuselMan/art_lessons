# Coarse-to-fine finite-volume exchange

Separate id `alternative-finite-volume-exchange`; v13 unchanged. Four/six steps,31/45draws. Each step freshly averages current fine mobile into256² coarse, computes incoming coarse exchange, updates fine, then partitions deposition. No additive delta, highpass or masked bilerp. Four-face coefficient≤.1875, symmetric path-min gate of all crossed coarse cells. A coarse cell is admitted only if all16raw water bytes>0. Thus blocked cells send/receive nothing; fine original inside them stays in its cell (local adsorption can partition it but sum unchanged).

Fine update C_i'=C_i(1−Σout_cell)+incoming_cell·receiver_i. Receiver integer codes sum exactly262144 in each4×4cell, factor=code/16384, hence Σreceiver=16. With fresh avg=ΣC/16, total incoming equals total outgoing on paired faces. Outgoing≤.75 ensures positivity. Fixed/mobile split and deposition are partitions, so WHOLE ideal float pipeline conserves mass, including blocked regions, not just low solver. Dry final returns literal raw. No CFD/momentum or shape expansion claim.

To avoid8bit coarse average/incoming systematically breaking this identity, both stages use TWO RGBA8 targets packing all four channels as16bit UNORM. Four coarse producers +one fine producer +two deposit producers per step. Maximum5samplers, WebGL1minimum8. Seven fullRGBA8 targets28MiB plusfive coarse targets1.25MiB and CPUaux4MiB. Receiver is bounded paper affinity .75..1.25 normalized percell; this can redistribute density, not multiply global brightness. Compile/alloc before timing; static receiver/domain CPUprep in upload outside run.

Remaining precision risks: packed16 rounding, fineRGBA8 rounding, saturation of fine/fixed channels (not globally bounded≤1 by mass conservation), premul channel rounding, and GPU floating arithmetic. No unconditional quantized mass certificate. CPU whole scalar-channel pipeline simulates split→6exchanges→deposit→sum, all4barrier grid phases, dryidentity and pigmentzero. 800cases: ideal max relative error5.3e-15; packed16+byte max drift .0856%, mean +.00508% on randomized moderate-density inputs. This is not a bound for saturated images or GPU proof. Actual commoninput mass/Premul and dry-barrier controls remain mandatory.

Full registry/allconfigs FakeGL drawledger/lifecycle PASS, strict TS0. FakeGL doesn't compile/execute GLSL. No GPU resources/services/dependencies created; no visual/speed claim. Future acceptance must compare captured input/water-stroke/variable-wash/fine-detail and measure grid artifacts/overflow, not just ideal conservation.
