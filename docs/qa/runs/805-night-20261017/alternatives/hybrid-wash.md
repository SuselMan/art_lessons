# Barrier-safe coarse wash / detail hybrid

New `alternative-coarse-mobile-detail`, two presets, prior ids unchanged. Full1024 raw +256 coarse: 8coarse four-face diffusion passes (stride4,2,2,1,1,1,1,1), fullres reconstruction, 2terrain blur passes, 2seed split passes, exactly2paper-guided donor/deposition steps, final sum:20draws. Ten fullRGBA8 targets40MiB +four256RGBA8 targets1MiB; CPUaux4MiB. CPU min-water/mean-pigment reduction is in upload, outside run timing, like earlier lowres candidates; report upload+run separately for total comparison.

Each4x4 coarse donor is admitted only if ALL16 raw water bytes are positive. Blocked coarse pigment is zero: raw pigment inside a blocked cell cannot seed the coarse solver. Every stride traverses all intermediate coarse gates. Reconstruction explicitly evaluates all four clamped bilerp donor cells (union up to8x8raw cells): if ANY blocked, returns raw unchanged. This forbids a1px dry stripe from becoming an interpolation shortcut, including grid phase and page edges. Near-dry but nonzero paths remain permitted; this is a fixed-wet-domain approximation, not a saturation/threshold claim.

Inside accepted footprints output is `mix(initialLow,raw,detail)+mobility*(solvedLow−initialLow)`; presets detail.7/mobility.65 and detail.4/mobility1. Detail1 retains all original high frequencies (including undesirable blocks), detail0 loses fine raw detail. Neither setting knows image semantics. Small subsequent correlated deposition uses mobile.2/.35, terrain scale4/5, no water-gradient rim or brightness multiplication. Raw-water-zero final returns original literal RGBA. Fullres deposition uses integer-cell path-min gate, stride1 here; it cannot cross a raw dry stripe. Pixels near barriers can retain original blockiness; safety takes precedence over smoothing there.

Only ideal paired low diffusion is conservative/positive (outgoing≤.85). Reconstruction, footprint mask, detail attenuation, clipping, RGBA8 and fixed saturation are NOT globally conservative. Actual mass ratios and optical-channel image quality must be measured; no fake conservation guarantee. CPU tests:16barrier configurations (vertical/horizontal/diagonal/edge ×4phases),16378dry pixels, sampled full reconstruction footprints;300ideal face-flux tests max mass error6.3e-13. Full registry/allconfigs FakeGL lifecycle/pass ledger and strict TS pass. FakeGL does not compile/execute GLSL. Device gate remains dry exact, pigment-zero/isolated pools, deterministic repeats and captured input/artistic/correlated/hybrid PNG comparison. No performance/quality claim before GPU proof.
