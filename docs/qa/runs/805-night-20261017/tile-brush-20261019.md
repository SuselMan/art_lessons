# Настройки кисти в режиме тайлов,19 октября2026

Запрос08:15: вернуть рабочие настройки кисти. В режиме тайлов доступны размер,
вода, пигмент, краска и произвольный цвет. Они фиксируются на начало мазка:
размер задаёт геометрию, вода/пигмент — отдельные маски входа, цвет и непрозрачность
задают немедленное отображение. Появление исходного мазка не ждёт target.
После отпускания пера запускается поиск путей по реальному нарисованному входу.
Если нарисовано несколько мазков во время расчёта, следующий расчёт берёт последний
полный вход. Tiled и whole используют один неизменяемый снимок.

Это по-прежнему диагностическая кисть и поиск путей, не родная кисть/full P/Csolver:
количества материала не моделируются физически; цвет смешения не вычисляется,
карта путей окрашена цветом последнего пигментного мазка. Без собственных мазков
по-прежнему используется тестовая волна. Явная пометка осталась на стенде.
