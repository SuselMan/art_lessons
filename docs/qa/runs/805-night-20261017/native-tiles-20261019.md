# Настоящая модель на А2,19 октября2026

Исправлена подмена задачи диагностической кистью: канонический Mini теперь
использует настоящую кисть и весь текущий combomask-солвер, включая цветовой
перенос, осаждение, общую кромку и фон. Диагностический Canvas2D-вход из
режима рисования убран. Полный размерА2=3508×2480, S1.

Первый полный вариант делит draw-проходы на ядра назначения, но хранит
рабочие состояния в полноразмерных текстурах. Все ядра читают общее прежнее
состояние. Это устраняет искусственные швы, но **не уменьшает объём памяти**
и не является завершением физического тайлинга. Отдельный halo-exchange остаётся
нереализованным следующим этапом. Подробности: [README](../../prototypes/native-tiles-805/README.md).

Проверено на SamsungSM-T970, Awake, собственная foreground-вкладка:
- На1024² настоящий цветной мазок: tiled/whole точны по SHA P,C,coverage.
- НаА2: настоящий мазок и повтор со вторым цветом; GLerror0.
-320pxволна через почти всю ширинуА2: первый target≈1943мс, второй≈2020мс
  в предварительной сборке. Полное чтениеC≈321/1314мс соответственно.
  CPUмаксимум пачки4операций≈19.2/3.6мс; это НЕ чистое GPU-время.
  ЧтениеC включает ожидание ранее отправленнойGPUработы, не только копирование.
- Tiled/whole повтор из того же source наА2: P,C,coverage побайтно совпали.
- Просмотрен реальный скриншот: акварельная фактура, смешение двух цветов,
  бумага, полный волнистый мазок; это больше не картинка одной карты путей.
- На опубликованном combomask после явной проверки фактического профиля:
  два320pxволнистых жестаА2≈1779/1957мс, exactP/C/coverage; отдельные средниеА2PASS.
- Обычный Mini: девять профилей, main/worker и morphon/off, pointer→targetGL0.
-16 профильных тестовPASS, сборка9профилейPASS.

Цель≈1с с плавным вводом пока не достигнута. У чтенияC есть сильная блокировка,
ручное сравнение делает ещё два полных расчёта/чтения и может блокировать UI
ещё дольше. Эта проверка отделена от измерения естественного жеста.
Морфинг в режимеА2 временно выключен; обычный Mini сохранён.

combomask; финальный a2-wave-public-report.json повторно собран на правильном профиле.
