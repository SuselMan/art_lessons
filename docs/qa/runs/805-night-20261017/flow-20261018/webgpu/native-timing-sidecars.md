# Отдельное время native-расчёта

Время функционального `componentLoopMs` включает доказательные чтения и не становится временем алгоритма. Старый timed-v1 с зависимым чтением одного пикселя также не доказывает готовность всего поля: особенно если этот пиксель расположен на сухом фоне.

Новый допустимый контракт — `native-preloaded-source-to-common-cpu-material-v2`. Основное время: `sample.totalToFullReadbackMs`, до возврата уже предусмотренного полного чтения common-C в CPU, перед хешированием. `totalReadyMs` остаётся вторичным интервалом до зависимости одного пикселя, `computeReadyMs` — вторичным суммарным временем внутренних расчётов. `setupReadyMs` описывает предварительное выделение ресурсов и не прибавляется задним числом к основному таймеру. Из времени ничего не вычитается.

Исходные семь CPU-плоскостей и бумажный ресурс уже подготовлены. В основном интервале находятся разбиение на компоненты, материализация/загрузка материала, core-расчёт, объединение и полный readback. Поэтому это не задержка пера и не чистое GPU-время. У worker другой объём подготовки и readback вне основного таймера: коэффициент native/worker не вычисляется.

`review_native_timing.py` принимает только закрытые успешные sidecar с тремя фактическими sample/hash. Все три вывода должны совпасть с common carrier уже сертифицированной функциональной клетки, исходные семь плоскостей — с её источником, input/binary/scale/encoding — с frozen-каталогом. Сборка и флаги должны совпасть с отдельным явно разрешённым manifest, байты которого перепроверены. Архивный `proofReportSHA` сохраняется; растущий функциональный report не обязан иметь прежний whole-file SHA.

В карточке используется медиана двух последовательных прогретых повторов (первый сохранён в evidence). Сравнение с original разрешено только для того же входа, совпадающего режима и границы таймера. Это сравнение отдельных стендовых серий, а не обещание универсального выигрыша. Карточки без такого sidecar продолжают показывать «Время расчёта уточняется». При ошибке sidecar доказательное время не подставляется.

Полные sidecar остаются отдельно от компактного browser payload. В HTML достаточно actual времени, названия контракта, пояснения и процента для сопоставимых native arms.
