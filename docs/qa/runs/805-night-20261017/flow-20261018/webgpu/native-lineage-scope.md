# Новый состав сравнения: родной расчёт

По запросу 18 октября самостоятельные исследовательские модели убраны из пользовательского сравнения. Это классификация происхождения алгоритма, а не оценка картинки или авторства исходного кода.

Остаются четыре позиции: `original`, `native-lazy`, `native-one-octave`, `native-cache`. `mini-worker/runtime.ts:12–22` создаёт настоящий PencilEngine с `front8-detail-flow-v4` и `createNativePuddleTarget` из `mini-puddle/native-target-v70`. `mini-worker/build.cjs:14–19` меняет родной `shaders.ts` и `WatercolorFrontPaths.ts` для выбранного кандидата. Lazy откладывает вычисление feather-шума, одна октава упрощает его, feather cache подставляет сохранённое поле в тот же native/prefix pipeline. Расположение cache helper в каталоге `webgpu/` не превращает его в самостоятельную WebGPU-модель.

Все 130 worker choices прежнего каталога — отдельные модели относительно этого родного расчёта. В частности, macro40/exact/fused/GPU initializer оптимизируют новый u32 coherent/hydraulic solver: macro40 → macro21 → macro19/macro14 → macro8 integer state. Они не являются переносом родной последовательности WC water-front/field/material passes. `alternative-artistic-front` и DSL имеют собственные front/transport/rim GLSL; похожие названия и отдельные приёмы не означают перенос родного ядра. Native capture предоставляет входные байты, а не происхождение алгоритма.

Входной reference сохранён как пятая позиция; это не алгоритм. Пользовательский состав сейчас: 7 уже сертифицированных мазков × 5 позиций =35 результатов, без пропусков. Это не обещание завершить отменённые 135×30. Все исходные 135-данные и протоколы сохранены отдельно. Фильтрация удаляет choices из DATA/catalog, а не прячет их через localStorage. Удержание original, глобальное скрытие/возврат, увеличение и компактный payload сохраняются.

Новый эксперимент с виртуальными потоками воды — отдельное явно запрошенное исключение. Пустые опции не публикуются. Он добавляется только после фактической проверки на всех тех же семи входах с общей OD-визуализацией; 16/64/256/1024 шагов обозначают checkpoints, а не полностью высохшие цели.

Основное native время — только отдельный контракт полного CPU-readback v2. Старый proof-loop и зависимость одного сухого пикселя не являются основным временем. По художественным эффектам отдельного разбора времени пока нет; число проходов не является долей времени.

Стендовые ~699 мс Mini-волны включают три отдельные полноразмерные QA-задачи: в последнем повторе compute основной лужи 221483 пикселя —146,8 мс, water-only компонент 3 и 1 пиксель —135,2 и117,2 мс. Это не время одного основного solver и не разбиение стоимости художественных эффектов. Не смешивать последний повтор с медианой всей серии.
