# Полная матрица: план исполнения, а не готовые результаты

CPU-инвентаризация: **134 выбора ×30 сцен =4020 слотов**, из них3990 расчётов и30 исходных картинок без solver. Это110 опубликованных вариантов/ссылок плюс24 действительно измеренные DSL-конфигурации из `measurements/real-program-search-v14.json`. У24 программ нет результатов для этих30 сцен; они не добавлены в массивы готовых картинок. Все129 worker-конфигураций проверены через actual `assertDefinitionConfig`; непробованные registry presets автоматически не включаются.

`review-job-manifest.cjs` строит конкретные запросы с индексами входа/выбора, параметрами и repeats3. Он не получает GPU/device/context и не вызывает candidate.create. Полный4020-job JSON сохраняется в зарегистрированном приватном cache; компактный `runnable-coverage-inventory.json` содержит SHA и блокировки без приватных путей. `choices[]` соответствует `comparison-coverage-plan.json`. Файл планирования сам не является командой начать GPU-работу.

## Входы

15 сцен читают существующие неизменяемые6MiB binary из `flow-all15-catalog.json`: RGBA4MiB, вода1MiB, бумага1MiB. Ещё15 получают детерминированные байты из текущего `createFlowFixture`, с SHA исходников генератора. Размер всех входов1024×1024, seed805. Все30 входов прошли полный CPU просмотр: **RGB>A:0, глубина при A=0:0**. Поэтому дополнительный форматный адаптер для этой конкретной матрицы не требуется. Это результат проверки данных, не универсальное свойство оптических пигментов.

19 входов совпали с опубликованным `commonInputSHA`/`fixtureSHA`. У11 старых статических карточек такого поля нет: текущие SHA зафиксированы, но историческое совпадение не заявляется. Менять байты из-за нового правила неподвижной лужи не нужно: версия алгоритмической политики хранится отдельно. Если позже найдётся исторический SHA этих11 сцен, его следует сравнить, а не переписывать источник.

## Реальные блокировки

- **3870 worker jobs:** конфигурации валидны, входы доступны, но каждый алгоритм должен получить проверенный контракт неподвижной исходной мокрой области. Старые картинки этого не доказывают. Candidate error/unsupported не заменяется другим алгоритмом.
- **60 native jobs:**13 canonical и2 authored native-flow имеют воспроизводимый native replay. Требуется перед расчётом сохранить исходные P/C/coverage/water/foreign, SHA полного checkpoint и проверить converted common SHA. Existing common binary не является native checkpoint. Нельзя подменять исходник перерисованной картинкой.
- **60 native jobs:**15 синтетических functional сцен не имеют native raw/replay. Обратный перевод common RGBA/воды/бумаги в исходный многоплоскостной материал необратим. Эти клетки остаются отсутствующими, пока не согласован явный native seed adapter и точная область его эквивалентности.
- **30 input-reference jobs:** solver не нужен; показываются ровно исходные байты и фиксированный, входозависимый оптический масштаб.

Если новый вход реально содержит RGB>A, clamp/подмена A или подбор масштаба по результату недопустимы. Малый lossless вариант для common-моделей — отдельные независимые глубинаRGB и массаA в u16/f32 с явным декодированием исходных байтов; это уже изменение контракта моделей, а не невидимая упаковка bounded RGBA8. Native требует настоящий checkpoint или новый объявленный seed contract.

## Воспроизведение без GPU

```sh
node docs/qa/prototypes/805-algorithm-search/review-job-manifest.cjs \
  "$QA_STATIC/flow/comparison.json" \
  docs/qa/runs/805-night-20261017/flow-20261018/webgpu/comparison-coverage-plan.json \
  "$QA_FLOW_CACHE/flow-all15-catalog.json" \
  "$QA_FLOW_CACHE/native-all13-endpoint-scenes.json" \
  docs/qa/runs/805-night-20261017/flow-20261018/native-scenes.json \
  "$QA_FLOW_CACHE/review-134x30-job-manifest.json"
node --test docs/qa/prototypes/805-algorithm-search/review-job-manifest.test.cjs
```

Три CPU-теста проверяют отсутствие clamp, точные входные SHA, обязательный отказ при несовпадении SHA и явные blockers. Генерация manifest и анализ всех30 входов завершены; GPU-запусков не было. Новых моделей, фоновых расчётов, сервисов или сборок этот подэтап не создаёт.

## Исправление encoding18 октября

Все30 actual inputs имеют `encoding: optical-density`, в том числе15 `createFlowFixture`. Manifest теперь передаёт **input.encoding**, а не предполагаемый request default premultiplied-rgb. Regression проверяет actual flow generator → executable worker request. После регенерации все30 SHA трёх полей совпали с предыдущим manifest: изменена только семантическая метка. Старые отчёты с неверным request encoding не переписываются в валидные результаты новой политики.
