# Захват реального raw wash для общего входа #805

CPU helper `webgpu/native-capture.ts`: `convertNativeCapture(raw)` возвращает `{input,manifest}`. Источники — полные owned RGBA8 readbacks inkColor/local solvent/optional foreign solvent/paperHeightRGBA, все GL bottom-up. Размер, seed, tileOrigin, actual paperWorldSize и paperScale обязательны. Никаких GPU действий helper не выполняет. Все три output plane независимо переворачиваются ровно один раз в top-left. Новые массивы можно передавать с transfer, исходные engine-owned данные не detach.

Root QA adapter одноразово перехватывает resetFromScratch после появления sourceEntry, перед original reset/Contrast. Readbacks вне любых timed samples. Нужны именно raw C и отдельный solvent, не P.b/goal/скриншот. Root отдельно записывает raw/input SHA, источник, epoch и состояние source completeness. Missing solvent не подменять coverage.

Линейная конверсия: native mass=2*C.a/255, optical depth=8*C.rgb/255. Общий down-only s=min(1,255/(2*max всех C channels))). Common optical-density RGB/A=round(2*s*Cbytes), без silent clipping и без исправления RGB>A или depth при A0. Эти случаи разрешены самой optical-density моделью; premultiplied RGB validator не должен их отвергать. Вода=min(255,localA+foreignA), unit nativeV=4*water/255; число saturations записано. Это новый нормированный общий вход, не доказательство эквивалентности native deposit/solver/composite.

Root-owned paper draw использует экспорт NATIVE_PAPER_CAPTURE_FRAG: native front UV=(gl_FragCoord.xy+[tileX,-(tileY+height)])/actualPaperWorldSize*actualPaperScale. Это S1/full-field контракт; при другом settleScale нужен явный пересмотр, не молчаливое применение. Actual paper texture/filter/wrap сохраняются; R8 quantization явная. GL framebuffer/viewport/program/texture-unit/VAO/enables/color mask восстанавливает root adapter в finally; никаких texture parameter изменений исходного paper. Один readback вне timing. Не использовать compositor origin [tileX,-tileY].

Транспорт: structured-clone объект `{input,manifest,rawHashes,inputHashes}` плюс fresh output ArrayBuffers, либо Blob этих bytes+JSON. Не PNG/canvas codec: никакой gamma/colorspace/alpha обработки. Для каждого алгоритма одинаковые immutable bytes и encoding. Capture CPU tests: 3 PASS (units/Y/water/depth, scale, invalid inputs), strict TypeScript PASS. GPU compilation/capture ещё не выполнялись этим агентом.
