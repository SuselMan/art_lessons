# #802: Mini1024 — расчёт в воркере

Цель: проверить глазами и измерить, сохраняет ли основной поток отзывчивость, когда расчёт М70 выполняется без пауз в Worker. Контроль — тот же код в главном потоке. Это эксперимент для пункта «Акварель готова к релизу», производительность планшета, #314.

Принцип: WebGL-контекст, исходные мазки, расчёт цели и морфинг принадлежат одному потоку. HTML, настройки и приём PointerEvent остаются в main. Canvas передаётся через transferControlToOffscreen, сообщения несут ввод и настройки, а не массивы пикселей. GPU остаётся общим. Новый ввод может ждать завершения синхронного расчёта внутри Worker — это отдельная граница отзывчивости, которую нельзя скрывать за плавным HTML-индикатором.

## Проверки

| Сценарий | Что сделать | Что оценить |
|---|---|---|
| Первый запуск | Открыть страницу на Samsung | Бумага загрузилась, контекст Worker работает, нет ошибок |
| Большой мазок | Кисть320, вода95%, пигмент34%, PB15; волна через1024 | Время от UP до готовой цели; анимация продолжается |
| Отклик HTML | Сразу после UP нажимать счётчик, менять настройки | Индикатор и кнопки не замерзают; замер max heartbeat gap |
| Новый мазок | Начать второй мазок сразу после первого | Очередь не теряет начало/конец; измерить задержку показа |
| Сравнение | Повторить в main без пауз | Та же математика, видна разница в блокировке HTML |
| Несколько мазков | Три пересекающихся разноцветных штриха | Они смешиваются; морфинг работает после каждого |
| Очистка | Новый лист во время расчёта | После очистки не возвращается старый результат |
| Сушка | Высушить, затем рисовать | Сухой результат остаётся; новый штрих работает |
| Сохранение | СкачатьPNG | Получается изображение нужного1024размера |
| Изменение размеров | Повернуть планшет | Ввод совпадает с изображением; размер модели остаётся1024 |

Побайтную эквивалентность нельзя доказывать независимыми живыми штрихами: начальное авторское состояние может различаться. Для неё нужен отдельный фиксированный вход полей. Один GPU не доказывает межустройственную детерминированность.

## Ресурсы

Новых серверных процессов нет. Статический эксперимент отдаётся тем же QA HTTPS-хостом с существующей защитой доступа. Приватные URL и nginx backup находятся вне Git. Опубликованная сборка сохраняется на время визуальной проверки Ильи, собственные браузерные контексты и ADB mappings убираются после замеров.
