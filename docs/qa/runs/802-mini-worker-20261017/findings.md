# #802: результаты эксперимента

Первый запуск на Samsung выявил `ReferenceError: document is not defined` при создании диагностического overlay областей (`mini-puddle/diagnostic-regions-v69.ts`). Сам движок загрузил бумагу и WebGL; ошибка произошла при установке интерактивного контроллера. Это DOM-подсветка для диагностического режима, которая в живом морфинге скрыта; для обоих live-only вариантов эксперимента она заменяется локальным пустым адаптером. Оригинальная подсветка, модель и действующие старые стенды не меняются.

Метрика «цель» на странице — время от приёма pointerup главным потоком до JS-сигнала контроллера после подготовки целевой картинки. Она включает очередь ввода в Worker, но не является отдельным измерением завершения GPU. Плавность main проверяется RAF-интервалами и кнопкой-счётчиком; очередь рисования — временем между пересылкой события и его обработкой движком.

Запуск второго штриха «во время расчёта» должен подтверждаться фактическими временными метками. Последовательность команд CDP через VPS сама добавляет задержку и может не попасть в короткое окно; такое прохождение не доказывает мгновенный отклик нового штриха.
