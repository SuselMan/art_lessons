# Поздняя зависимость структуры при восстановлении snapshot

Кампания #745. Исправление: 09d9b1a4.

`prepareSnapshotReplay` проверял `plan.replayStructure` один раз перед циклом
подгрузки пиксельной истории. Подгрузка включает общие undo/redo комнаты и может
впервые обнаружить undo удаления/merge. План становится структурным позднее,
но загрузка/проверка исходной структуры уже пропущены. В частности неизвестный
snapshot-only корень мог быть принят, хотя восстанавливать его исходную
структуру невозможно. Это fail-open, не доказанная потеря пользовательских данных.

Минимальный случай: исходный план содержит только undo сушки слоя L;
его полная история приносит undo удаления S. В исходной памяти сервера нет ни
S, ни управления его удалением. После расширения требуется структурный replay.

Исправление: обработка структурного префикса внутри того же монотонного цикла
зависимостей, с единственной загрузкой. Повторно проверяется reconstructable base.

Проверено: regression с поздним undo удаления, а также отказ при отсутствующем
исходном layer_add; 228 тестов server rooms/snapshots/replay прошли. Backend не
перезапускался; реальный GPU к этому серверному правилу не относится.
