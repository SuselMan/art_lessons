# Мокрый duplicate отличается от воспроизводимого результата

Кампания #745. Реальный Vega, common freeze9df0f12c. Новая512²комната,
два независимых автора. `night-wide/layers.cjs`, QA_LAYER_CASES=duplicate-wet.

Последовательность: создать слой → нарисовать М70 мазок → дождаться рассчитанной
цели (морфинг ещё продолжается) → layer_duplicate → считать actual пиксели
назначения → отдельно full-replay oracle назначения.

Получено10631отличающихся байт. У назначения нет мокрогоcontroller entry,
поэтому вызов close(dest) перед чтением является no-op. Source перед actual
чтением не закрывается. Таким образом сравнение действительно ловит copied
presentation против воспроизводимого материала, а не различие двух oracle.

Ожидаемое минимальное требование: копия на всех клиентах и после перезахода
воспроизводима. Будущая семантика сохранения воды в копии требует отдельного
решения; текущая зависимость от кадра морфинга этому требованию не соответствует.

Доказательства: temp/device-runs/745-layers-duplicate-wet/report.json и failure0/1
PNG. Комната оставлена только для расследования, приватная owner-auth внеGit;
точный путь в private-fixture-path.txt. Оба своих browser contexts закрыты.

Независимый merge-wet: два мокрых слоя разных авторов → merge. Аналогичное
расхождение20661байт, доказательства temp/device-runs/745-layers-merge/.
Dry duplicate проходит actual=oracle, временная комната удалена.

Дополнительный аудит oracle: replayMergeInto/replayDuplicateInto также читали
scratch сразу после replayInto, до material goal. Поэтому исправить нужно обе
ветки, затем сравнить против канонического материала (и освобождать puddle temp
до destroy). Root выбрал read-only canonicalTiles proxy на goal, без подмены
живых пикселей, с сохранением воды оригинала при duplicate.
