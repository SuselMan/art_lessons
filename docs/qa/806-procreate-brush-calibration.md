# Сверка Procreate-кистей с Grafetto

Только подготовка к сравнению: эталонные штрихи Procreate пока не сняты.
Использовать личный набор владельца; изображения и архивы в Git не помещать.

`QA_OUTPUT=/private/evidence npx tsx e2e/brushCalibrationQA.ts` создаёт отдельную
review-комнату с четырьмя текущими кистями Procreate rendering5. Сверху вниз:
Main Brush, Wet Brush, Wet Blender, Loaded Colour Brush. В каждой строке две
сухие цветные полосы, синий штрих с записанным давлением0.15→1 и отдельный
отпечаток с давлением0.7. Подложка нужна, чтобы даже почти пустой blender имел
цвет для переноса. Отчёт сохраняет точные descriptor IDs/параметры, ошибки,
диапазон давления и результат live/reload; PNG хранится только приватно.

На iPad повторить в Procreate на белом листе с теми же цветами/порядком штрихов:
синий RGB примерно10/51/191, красный191/20/10, жёлтый230/166/8. Давление повторяется
приблизительно; не считать ручные жесты побайтным эталоном. Использовать одинаковое
визуальное соотношение размера кисти и длины линии, записать цветовой профиль холста.

Сравнивать по отдельности:

- Отпечаток: форма, зерно, мягкость края и насыщенность при касании.
- Длинный штрих: расход заряда, зерно, taper и зависимость от давления.
- Пересечения: перенос исходного цвета, размытие, прозрачность и тёмный край.
- После отрыва: меняется ли изображение при ожидании; не предполагать временную
  симуляцию только по названию Wet Mix или Bleed.

Поправки делать в общей модели параметров. Отдельные ручные пресеты для этих
четырёх кистей не создавать. Исходные архивы не менять, отсутствующие factory
изображения не заменять похожими. Результат сравнения и необходимые параметры
записать компактно рядом с приватным QA-отчётом.
