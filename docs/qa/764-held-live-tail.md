# #764 — хвост удерживаемого мазка отправляется без движения

06.11.2026. База `858d865ef86875b7ff1d456a65c44a4d58e7b56a`.
Worktree `764-release-held-tail`, ветка `agents/764-release-held-tail`.

Очередь live dabs получает один timeout до ближайшей границы 60 мс, когда движение
пришло раньше неё. Таймер принадлежит жесту; отменяется при новом жесте, UP,
сбросе async local stroke, context loss и destroy. Первый пакет не ждёт интервал
(`-Infinity` вместо нулевого времени предыдущей отправки). Состав durable операций
и dab claims не меняется.

## Проверки

- До: 1 FAIL / 18 peer-live тестов; после остановки с открытым жестом второй пакет
  не приходит, очередь не освобождается. Проверка использует штатный pointer pipeline.
- После: 18 / 18; отдельные проверки UP, destroy, context loss запрещают поздний пакет.
- Полный движок: **1880 / 1880, 171 файл, 364.16 с**.
- Typecheck, финальный typecheck:e2e, lint:fix, map:check, map:rules: exit 0.
- `e2e/specs/heldLiveTail.spec.ts`: **2 PASS, 111.8 с**. Chromium/SwiftShader и
  настоящий Samsung SM-T970, Chrome 156, ANGLE/Adreno 650/OpenGL ES 3.2,
  DPR 2.125, viewport 824×1149. Собственные Postgres/API/frontend, порт 6255.

Один и тот же короткий пакет движений исполняет настоящие обработчики пера
`_onStart/_onMove` внутри страницы (метод device penbench). Это не физический
S Pen и не измерение общей плавности. Часы/таймеры браузера не подменяются;
обёртка callback только считает пакеты и вызывает оригинальную сетевую отправку.
После burst движений больше нет. Жест остаётся открытым, durable stroke ещё нет;
проверяется освобождение очереди, следующий packetSeq и точное число dabs хвоста.
После UP наблюдатель получает каноническую операцию того же strokeId.

На Chromium: первый пакет 1 dab, очередь 18; второй пакет 18 через **61.9 мс**.
На Samsung: первый пакет 1 dab, очередь 18; второй пакет 18 через **61.1 мс**.
Surface/Lanpad недоступны (No route to host); iPad в этом прогоне не проверялся.

Первый browser rig ошибочно требовал ровно один пакет во время burst; на software GL
движения заняли 61 мс и успели отправить два. Исправлено тестовое ожидание: хвост
должен добавить один пакет к фактически уже отправленным. Android `/json/new`
отказал создавать target; проверенный rig открывает отдельную QA-вкладку через
paired ADB, находит только её уникальный URL и закрывает только её.

## Уборка

Собственная вкладка Samsung закрыта, отсутствие target с портом 6255 проверено.
Параметр stay_on_while_plugged_in восстановлен в исходные 7; исходный Dozing возвращён
через sleep key. Собственные forward 29264 и reverse 6255 удалены.
Компактные логи, source SHA256, паспорт и device-cleanup.json сохранены в игнорируемом
`temp/764-release-held-tail`; disposable runtime/БД/volumes, trace/video и dependency
views убраны после фиксации результата.
