# Пигмент до завершения расчёта — Samsung, 14.10

Предыдущий функциональный smoke проверял запись команд, но не время появления
пигмента. При viewport с полями вокруг A3 композитор отклонял material preview:
его extent не покрывает весь viewport. Вода отображалась отдельным путём, а
канонический пигмент появлялся позже. Квадратный standalone скрывал этот дефект.

Ограниченный лист теперь явно помечает preview как полный слой. Его отображают
также при viewport за пределами бумаги. Частичный preview бесконечного холста
сохраняет прежнюю проверку покрытия; export читает canonical, selection приоритетна.

Samsung SM-T970 / Adreno650: pointer stroke 600ms, zoom0.3, A3. Инструментирование
фактического drawTileComposite подтвердило рисование material texture во время
активного штриха и pending canonical queue при viewport шире бумаги. Это проверка
пути вывода, не измерение физической pen-to-pixel задержки. GL0, context loss нет.
