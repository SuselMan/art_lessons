# Длинный штрих 400: протокол и границы доказательства

Кандидат исследует обычную Room на неизменённом движке `c2ee5645`, joinedTouch=true и отдельном DEV physicalBatchTwo OFF/ON. Каждый arm создаёт свою комнату 1024×1024, отражает размер400, воду100 и пигмент100 в UI и движке, проводит два последовательных штриха по одной траектории. Между штрихами нет ожидания canonical idle: второй проверяет рисование по ещё мокрой области.

Траектория состоит из шести участков по300мс, с двумя coalesced samples/rAF. Координаты заданы в world-space; применяется обратное реальное PointerInput-преобразование камеры. Круг кисти радиуса200 остаётся внутри листа. Путь: (300,300) → (600,300) → (600,500) → (300,500) → (300,700) → (600,700) → (600,500).

Измеряются длительности DOWN/MOVE/UP, возврат `_display`, интервалы rAF во время движения, pending canonical requests и прогресс текущего settle job. Эти значения описывают синтетическую подачу PointerInput и CPU submission. Они не измеряют физическое касание пера или GPU timestamp. Material readback и PNG выполняются после drain, отдельно от измерения движения. OFF/ON создают разные авторские записи: точная same-packed parity здесь не заявляется.

Контроллер использует только cached Samsung CDP9454 и свою новую вкладку с уникальным marker. Условия: freshRAM1700MiB, abort500MiB, hard120с/arm, запрет перезаписи прежних артефактов, строгие GL/page/HTTP результаты. Не выполняются wake, power-настройки, Chrome restart, очистка кеша, сканирование, сопряжение или закрытие чужих вкладок. При отсутствующем DevTools socket допускается только подтверждённый census `/proc/net/unix` и запуск нашего QA intent; существующий повреждённый socket не обходится.

## Первая попытка

Source/API preflight прошёл. До открытия вкладки получено2196MiB свободной памяти, но cached CDP вернул Empty reply; штрихов и PNG нет. Forward9454 привязан к актуальному cached endpoint, а фактический `/proc/net/unix` не содержит chrome_devtools. Это отказ инструментального bootstrap, не результат акварели. Повтор автоматически не выполнялся; диагностический raw сохранён отдельно.

CPU-проверки покрывают временной рецепт, bounds, реальное affine-преобразование и восстановление pointer capture, запрет запуска без allocation, сохранность прежних артефактов и fail-closed cold-bootstrap. Аппаратного результата длинного рисования пока нет.
