# #728: настоящий DEV Room callback нового brush transport

Принцип: существующий CPU delivery и Operation Log неизменны; новый оператор применяется **после actual native source landing** и до осадка. Это эксперимент новой физики, не exact ускорение старой модели. Query `wcNative=1&wcMomentTransport=1` принимается только в DEV. Без wcNative новый flag отказывает; production игнорирует query и оба defaults OFF.

Runtime замораживает recipe из уже retained canonical dab, не вызывает DabSystem/prepareDelivery повторно. Обязателен existing per-dab segmented source path: произвольная multi-dab группа явно unsupported, иначе число transport passes зависело бы от coalescing. Состояние направления продолжается через newFilm/chunk flush, поскольку gesture epoch там меняется; новый контакт без canonical previous начинает новый tape. Рассогласованная previous continuity отказывает. CPU oracle: одна retained tape, разбитая [2,1,3] / [1,3,2], даёт одинаковые recipes и финальные P.B/C, включая stationary direction carry. Actual native author/replay Room parity ещё требуется.

Executor по завершении source читает фактические inkLoad/inkColor и проверяет каждый ROI pixel C≤P.B. Если carrier unsupported, transport **и rebase не исполняются**, source публикуется неизменным; report содержит число/максимум/примеры нарушения. Никакого clamp. При supported carrier — текущий cleared contact из immutable coverage commands, availability из общей canonical coverage.B/A (не solvent P.B, который в solvent record нулевой), joint GPU transport, source copy/rebase, второй live composite и публикация. GPU invalid counter проверяется отдельно; расхождение с CPU audit завершает arm как ошибку. Console prefix `[native-moment-transport]`, owner `.momentReport` доступны диагностическому контроллеру.

CPU readbacks здесь **намеренно диагностические**: до принятия реальных carrier нельзя молча включать новый оператор. Они добавляют около8MB readback на1024 tile/контакт и не годятся для оценки отзывчивости или production пути. Оператор добавляет current-contact rasterization, четыре integer passes, full-texture output copies и film rebase. Следующий cost experiment — separate pack→unpack in-place без sample/write feedback в одном pass; пока текущий proven synthetic texture gate использует разные input/output.

Сохраняется explicit bounded native contour: один origin-zero1024 tile; transport ROI≤512²; outside-tile/full multi-layer не добавлены. Большая составная contact/composite область может отвергаться guard, его не обходить. При OFF `publishCurrentToGl` не читает материалы и не создаёт новых GPU команд. Actual unsupported carrier unit test сохраняет P/C и не вызывает transport; positive source owner tests подтверждают transport→sourcecopy→film base→film clear и rollback leases. Surface standalone THREE texture arms прошли exact0 ([отчёт](728-wet-moment-texture-surface.md)); это ещё не actual Room gate/качество новой акварели.
