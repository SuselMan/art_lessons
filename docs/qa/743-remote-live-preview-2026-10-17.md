# #743: видимость акварели у наблюдателя до UP

17.10.2026, вторая ночная волна. Проверки автора из первого отчёта не
проверяли экран наблюдателя. Найден отдельный подтверждённый путь:
`appendPeerLiveDabs` безусловно пропускал все акварельные live-пакеты,
и наблюдатель получал пигмент только при записанном chunk/UP.

Исправление использует уже принятый принцип отдельной презентации:
входящий пакет даёт временный след на экране, но не меняет канонический
материал, воду, журнал, snapshots или watermark нарисованных dabs.
Записанная операция всегда рисует целиком через обычный M70 pipeline.
Она удаляет только свой префикс временного следа; поздние пакеты не
воскрешают уже записанный префикс. UP сам не удаляет ещё не записанный след.
Cancel, peer leave, reset, resize и context loss очищают временные буферы.

Презентация компонуется на месте своего слоя, с его видимостью/opacity
и ниже более высоких слоёв; canonical export её исключает. Чистая вода
имеет серый временный след. Это декоративный stamp preview, а не точная
симуляция растекания до получения операции. Вода незаписанного чужого
мазка не становится входом канонического материала.

Память ограничена 64 MiB на framebuffer, 64 состояниями жестов/маркеров
поздних пакетов, 6400 незаписанными dabs на состояние. При отказе выделения
каноническая операция по-прежнему придёт и нарисуется. Счётчики dabs
презентации независимы от канонических claims.

Проверки кода: pure cursor/prefix tests, тесты engine live/end/cancel/gap
без вмешательства в слой, compositor stack/export; прежние peer-live тесты.
MockGL не доказывает видимый цвет M70: аппаратная observer-before-UP
проверка проводится отдельно перед объявлением задачи исправленной.
