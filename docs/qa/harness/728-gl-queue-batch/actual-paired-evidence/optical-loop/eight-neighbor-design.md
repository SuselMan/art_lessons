Actual four-axis GPU optical images0→12: normalized h4 .006323→.036902, h8 .000905→.018687 (fixed initial darkness centroid, exclude r<4px). In the same images period8 Fourier x/y modulation decreases .003273→.002662/.009788→.007712. These support large angular/cross deformation, not increased period8 source striping. Metrics are optical-darkness diagnostics, not pressure/mass attribution.

`CommonEightNeighborTransport.mjs` is an isolated defaultOFF CPU prototype, 128/256 highROI, same fraction for all eight P/C channels. Axial weights4, diagonal1. Flat equal-capacity stencil satisfies Mxxxx=3Mxxyy because 2wa+4wd=12wd => wa=4wd. Total transfer rate5/6 matches the second moment of equal-weight four-axis stencil (8-stencil covariance .6 vs4-stencil .5 before scaling). Thus directional error can be reduced by actual common mass redistribution, without applying an RGB blur.

Eligibility: high-world wet/cost path checked at every integer pixel of hop; a diagonal additionally requires BOTH orthogonal corner cells at every step. This rejects crossing a dry diagonal crack or cutting a corner. Outside ROI rejects before any step; no source mass can disappear or pile at a clipped edge. t0 zero rate/travel is exact, including boundary source. Fractions nonnegative, total<=1, same8 channels, original readonly, mixed-color ratios donor-convex. Tests cover these properties.

Synthetic radial flat-field12-step hop1 comparison: second moments agree within4.1e−7 at endpoint. Added signed fourth anisotropy four-axis122.01 vs8-neighbor1.57, ~98.7% lower. Initial rasterized radial source already has fourth-moment error; the added signed moment is the relevant change, not absolute final error. Optical h4 excludes a central disk and includes discrete sampling, so it is not a pure stencil theorem.

Limitations: frozen pressure/front is still not natural evolving water. This prototype uses wet/cost/capacity eligibility and harmonic capacity but omits actual uphill path flags/gradient conductance; it is not an actual-pressure solver equivalence or GPU visual result. Actual dyadic hop schedules need separate safe ROI admission. Do not increase fixed12steps or claim artist readiness.
