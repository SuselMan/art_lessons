# Этап3: typed late-bound source replay port, ещё не GL renderer

QA `TypedGlSourceReplayPrototype` использует production `CanonicalDrawCommand`, не генерирует dose/delivery/geometry при replay. Constructor отделяет каждый segment, копирует uniforms/Float32 arrays/rect, сохраняет signed-zero и phase order. Execute лишь после `bindCurrentCanonical().landedVersion===expectedPredecessorVersion`; отказ старого base не расходует single-use record. Destination refs не сохраняются при input capture: bind получает actual current canonical fields после predecessor land.

Explicit ledger: optional running coverage snapshot, initial filmP clear→actualPload copy→filmC clear→actualCload copy; coverage commands; firstV filmclear→actualVload copy; V commands→mode1,k1 base+film on original GL scissor; P/C/halo draws original MAX/add; final P then C base+film sums indivisibly для каждого segment. Water-only не добавляет P/C sums. Между segments нельзя flatten фазовую последовательность или убрать Q8 landing boundary. Film initialization раз на gesture, V после coverage и до pigment. Не shader fusion.

Tests подтверждают typed command order/late base target IDs, mutable original input не меняет captured F32 bits, oldbase rejected, single-use, phase reset rejection, segment sums retained, water-only V-only landing. Это contract/port proof, не actual GL byte parity. Imported production command builder остаётся источником math; fake trace не доказывает отсутствие rounding/GL-state расхождений.
