# Отложенный joined UP: Surface CPU/native canonical oracle

Controller подключается только к явно проверенному own Surface CDP/profile. Новое создание/очистка профиля/task и forwarding выполняются отдельно с PID/cmdline guard; Browser.close не вызывается. `remote-device.mjs` — контракт fc5829c3: actual renderer-device RAM, only-owned contexts и transport disconnect.

Переменные: QA_APP (own5343), QA_RUNTIME (локальная точная source copy для манифеста), QA_MANIFEST (HEAD/files path+sha256), QA_OUT (новый каталог), QA_DEPS (existing realdeps), QA_SURFACE_CDP, QA_SURFACE_OWN_PROFILE, QA_SURFACE_MEMORY_PROBE (JSON exec file,args; encoded PowerShell через HOME hop). Никаких токенов в этих файлах. GPU запуск требует согласованного слота.

QA_BOOTSTRAP_ONLY=1 создаёт только пустую own Room и снимает actual predicates initial/reload, без native inputs. В full rig штатно выбирается watercolor, затем сохраняется strict ready/actor/paper/unlocked guard.

Нативный фиксированный tape проверяет материал, wet/time, 38 full field roles на текущем fixture, реальные REST persisted IDs, whole RGBA и UI Dry/Undo/Redo/fresh. Не выдавать Engine calls за DOM/rAF input latency. Манифест сам по себе не гарантирует runtime: перед input actual HTTP raw Engine/Room/Plan SHA обязателен. Сырые ошибки остаются отдельными; timeout/null/empty/unmapped не PASS.
