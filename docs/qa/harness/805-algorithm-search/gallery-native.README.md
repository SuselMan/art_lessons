# Native-карточки записанных сцен

`gallery-native.cjs` воспроизводит упакованные dab-операции через `appendOperation` в свежем собственном Worker-контексте Samsung. Весь выбранный сюжет равномерно вписывается в 700px с центром1024; меняются только XY и размер dab. Давление, форма, угол, время, порядок и идентичность wash сохраняются. Runtime явно назначает копиям пресетов модель front8-detail-flow-v4 через общий withWatercolorModel; исходные пресеты, применённые пресеты и SHA реально воспроизведённых операций сохраняются.

Запуск: `QA_CACHE=<registered-cache> QA_OUTPUT=<private-output> QA_REPEATS=5 node gallery-native.cjs`. Необходим свой проверенный CDP19336. `QA_SCENES` ограничивает IDs, `QA_SOURCE_FILE` выбирает другой manifest. Сборки `native-v4-original`, `native-v4-lazy`, `native-v4-one-octave` должны быть заморожены с manifest SHA и запечённой бумагой.

Перед сравнением проверяются полные SHA исходных P/C/coverage/own-water/foreign-water/backdrop и преобразованного общего входа/бумаги. Lazy обязан совпасть по P/C/coverage и PNG. Для одной октавы такого требования к старой модели нет. Каждый повтор сбрасывает один target из неизменного raw; окончательное изображение выводится без морфинга. Таймер включает reset/solve/dry/final-composite и чтение1px зависимого результата; полные SHA и PNG исключены. Это время готовности зависимого результата, не чистое GPU-время и не полная очередь показа.

Отчёт сохраняет все samples, первый отдельно от тёплой медианы. Порядок control→lazy→one-octave фиксирован; это ограничение сравнения. Все контексты закрываются в finally, пользовательские страницы не меняются. Секреты, PNG и6MiB inputs остаются вне Git.

CPU-проверка: `node --test gallery-normalize.test.cjs`.
