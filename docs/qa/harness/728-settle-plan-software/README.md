# Captured-input canonical settle tape

This harness executes the actual production GL planner/passes and the generic
planner/native adapter on identical Q8 captured inputs. It compares every byte of
all ten working roles after each quantum, then all present landed roles. GL and
WebGPU validation errors fail the gate. Contact motion must change actual scissored
brush outputs and the landed pigment relative to the static control.

The field is deliberately 128×128, with a nonzero world origin. This is a component
oracle, not proof of production 1536 field allocation, Room lifecycle, source
stamp/ribbon raster equivalence, hardware equality, performance, or animation.
The baked medium paper and canonical noise are real inputs. No alternative physics
or hidden GL processing runs inside the native backend.

Run software validation from the worktree:

```sh
node docs/qa/harness/728-settle-plan-software/check.mjs
```

Build a standalone page for a sequential hardware check:

```sh
node docs/qa/harness/728-settle-plan-software/build.mjs temp/whole-plan-hosted
```

Serve that directory over a trusted HTTPS origin with the existing production
`/paper/` assets available at the same origin. The button executes all four
cases; bounded JSON is in `window.__settleTapeResult`. Readbacks are validation
work and must not be used as GPU timings. Identify the actual device/backend separately when hosted; the harness does not
infer hardware provenance from the browser API.

Foreign-water sensitivity is a separate positive gate: intermediate role hashes
must change between the contact control and foreign-puddle input. A zero effect
fails the gate even if GL/native outputs agree, so an inert fixture cannot silently
claim foreign-water coverage. Final foreign pigment equality alone is not a failure
if a meaningful intermediate effect exists.

Software result (SwiftShader), deep-water capture: exact=true and pixelParity=true
for all four tapes, zero validation errors. Operations 59/58/88/88. Contact motion
changes 7589 brush bytes and 488 landed P bytes (maximum 11) versus static. Foreign
water changes 605 working-role checkpoints and 11613 landed P bytes (maximum 19).

The separate front primitive uses a cost-zero seed, dry coverage, and a foreign
rectangle. After 12 canonical steps the dry control reaches 45 cells/radius3.606;
the foreign case reaches625/radius16.971. All 24 step outputs are byte exact on
SwiftShader. The final cost difference is624 bytes/max239. Per-step mismatch
samples/channels and the whole-tape first divergence are retained for hardware
rounding diagnosis; hardware arithmetic differences do not abort the trace.
