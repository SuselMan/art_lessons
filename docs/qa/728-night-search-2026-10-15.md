## Уже проверено

Одинаковый offline движок Fine1024, кисть380, давление.85, PB15/PY35, 2/12 перекрывающихся мазков, фиксированные stroke ID. Измеряется input+ordered Dry, далее GL finish/readback. Один прогон на комбинацию, без статистической гарантии. Каждый опыт сравнивается со своей непосредственной базой; разные серии не образуют общий рейтинг из-за прогрева и вариации устройства. GPU AMD ноутбука / Adreno650 Samsung. Полная галерея не пересчитывается.

- `ratio`: мультипликативный возврат крупной сетки вместо остаточного. На пересечении появилась светлая линия, художественно хуже. Отброшен.
- `subcopy`: copyTexSubImage2D вместо переопределения хранения при равных размерах. Samsung12 Dry20054→20029мс, побайтно одинаково; существенного выигрыша нет. В рабочий код не добавлен.
- `mrt`: один парный GL1 проход P/C вместо двух, со shared face fractions. AMD12 Dry6196→4874мс, полный13068→11518мс; 2/12 canonical hashes exact. Samsung не имеет требуемой MRT capability; аппаратный тест остановлен до рисования кандидата. Это не решение задачи Samsung.
- `cellzero`: досрочный выход целой клетки при нулевой дозе/сухой воде. Samsung12 Dry19986→19938мс: существенного выигрыша нет.
- `cached`: кеширование общих данных грани в одном GLSL проходе. AMD12 Dry6288→5062мс, полный12505→10710мс, exact. Samsung12 Dry20008→22787мс, стало хуже. Samsung2 имеет646176 отличающихся каналов, max81, meanAbs0.5068; AMD exact не переносится на Adreno. Не применять к старым записанным моделям.

AMD12 Dry6246→5894мс, полный12761→12590мс, exact; выигрыш мал. Первые диагностические попытки GL1282: оставленный на unit4 цветовой временный buffer конфликтовал с последующим fieldOp при landing. Исправление состояния устранило GL1282. Не объявлено готовой оптимизацией.
