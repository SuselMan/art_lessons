# М12: одна исходная лужа, одна отменяемая цель

Основа c2f6c970. По уточнениям Ильи22:30/22:32/22:38: запрещено использовать готовность/прогресс прежней цели для нового конечного результата. Презентация вправе зависеть от предыдущей картинки; canonical material/target — нет. Применимость к онлайну является обязанностью разработки, не ручного художественного QA Ильи.

## Контракт

- Исходный материал всех мазков хранится отдельно от presentation. На DOWN возвращаем raw P/C/coverage; никаких mix(base,target,elapsed) в новом canonical input.
- Новый ввод dispose/cancel старого job. Никакой очереди, ожидания завершения, выполнения старого job во время новой кисти или цепочки priorGoal+newDelta.
- Новая цель полностью пересчитывается из исходного материала общей лужи, параметров/seed. Старый рассчитанный результат не участвует даже если успел завершиться.
- Сушка: канонический результат текущей исходной лужи; презентационный clock не становится параметром модели. После завершённой сушки материал становится новым сухим основанием.
- Для online нужны общие исходные события/параметры/seed/версия модели и одинаковая семантика Dry. Проверки двух устройств/позднего входа/undo пока НЕ выполнены. Stand не доказывает online-ready. Старые М01/06/11 остаются frozen для сравнения, не становятся эталоном синхронизации.

## Окончательный эксперимент

Контроллер от М11, но commit активной мокрой лужи берёт только raw base P/C/coverage. Native target от М06, без pre-gesture-only reference: мобильная часть выделяется детерминированно по положительным локальным перепадам начальной плотности (четыре соседа12px, smoothstep .02.. .2). Одинаковый скаляр для P/C. Остальное native carry/remobilization/deposition/composite, фиксированный внешний контур, прежний morph clock. Это эвристика нового художественного варианта, не доказанная физическая модель и не byte parity с М11. Два GPU draw phase split, без новых полностраничных буферов относительно М11.

На восьми быстрых касающихся мазках внутренние структуры появились по всей полосе, но видны тонкие светлые контуры и усиленные полоски. Это известный художественный недостаток, не объявлять задачу решённой или качество достаточным до оценки Ильи. Визуальный скачок raw/model на новом DOWN ещё нужно отдельно оценить. М12 только Mini, не переносить в Grafetto автоматически.

## Отклонённые промежуточные подходы (в М12 НЕ входят)

1. Цепочка priorGoal+newDelta: давала неровные стыки при паузах, но зависела от готовности прежнего расчёта, запрещена контрактом.
2. Один активный job+один coalesced pending snapshot: скрытая очередь, прямо отвергнута Ильёй; удалена. Быстрая серия ждала2.5сек против0.53сек.
3. Продолжать старый расчёт16ops во время новой кисти: старые результаты опять влияли на итог; удалено.
4. Градиентная фаза с минимальной подвижностью20%: всё поле продолжало сеять фронт, гладкая картинка; не выбрана.
5. Фаза из поперечного координата кисти: слишком ровные границы; не выбрана.
6. Процедурные пятна подвижности: искусственные повторяющиеся облака; не выбраны.
