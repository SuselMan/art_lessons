# #744: повторное использование сухих эпох при Undo

Локальный кандидат, 17.10.2026. Художественный solver, журнал операций и правила Undo не меняются.

## Изменение

После завершения записанной сушки/скрытия планируется обычный пиксельный checkpoint. Применяются существующие guards: незаписанные мазки, активный source, ремонт истории, pending/rebuild/контекст. Только полностью известные слои без network snapshot coverage получают новое доказательство.

Доказательство сохраняет immutable effective material prefix до записанной сухой границы. При использовании сверяется состав/порядок/ссылки операций, включая саму границу. Смена pigment→water-only с тем же ID, потеря защиты воды, undo сушки, late history и reorder отвергают checkpoint. Подтверждение, заменившее объекты без изменения материала, тоже может консервативно отвергнуть его. Проверка кэшируется по revision и effective-view identity.

`closedWashIds` отделены от `washIds`: первые — доказанно завершённые эпохи, вторые — перенесённый мокрый scratch. Один постоянный `m70:<layer>` через несколько сушек больше не запрещает безопасный checkpoint. И `best()`, и каждый `startOf()` проверяют доказательство. История не удаляет доказанно неизменные сухие checkpoints при отмене более позднего действия.

## Проверки

- Oplog + checkpoint + engine guards: 163 теста / 14 файлов прошли до дополнительного transform-regression.
- Новые проверки: undo более позднего мазка использует CP, undo раннего пигмента/Dry отвергает, water-only same-ID и исчезновение foreign-защиты отвергают, backfill отвергает, чужая сушка/open source не доказываются, unproven closedWashIds не используются.
- Engine проверяет реальные pencil pixels с пустым M70 событием для политики эпох: Undo сохраняет исходные пиксели и вызывает `_applyPixelOp` **0 раз**. MockGL не моделирует жидкость, поэтому качество M70 этим тестом не подтверждается.
- Engine callback test: release открытой эпохи не создаёт CP; release во время rebuild не создаёт CP; release закрытой эпохи создаёт проверяемый CP.
- Web TypeScript build и lint затронутых модулей прошли.

## Что измерить аппаратно

Одинаковый журнал: 100 либо 800 M70 операций → recorded Dry → один новый мазок → Undo нового мазка. До изменения eager invalidation удаляет старый CP; после изменения ожидается сохранение CP и replay только хвоста (при отмене единственного хвостового мазка — ноль старых операций). Снять wall time DOWN/Undo→ack→swap, cp.start/число replay dabs/goals, live canonical pixels против full replay на каждом участнике. Затем undo раннего мазка и undo Dry: CP обязан быть отвергнут, картинка снова должна совпасть с oracle.

Время на реальном GPU ещё не измерено этим кандидатом. **Открытая эпоха из 100 мокрых мазков без записанной Dry по-прежнему требует replay**; мокрые snapshots не добавлялись. Чтение/упаковка сухого CP имеет собственную цену; оно вынесено из пути Undo. Новые данные не публиковались, временные процессы не создавались.

## Закрытая эпоха после cold-history rebuild

Дополнительный runtime baseline подтвердил, что source, закрытый до swap приватного job.fresh, не создавал CP: released callback ещё не видел его среди root layers. Теперь после swap используется тот же guarded scheduler. Проверяются текущий root target, canonical dry proof, отсутствие snapshot coverage и все обычные _takeCheckpoint guards. Runtime regression проходит через настоящий sliced rebuild: jobs1→0, пиксели сохраняются, появляется проверяемый CP. Targeted checkpoint/callback + snapshot suite: 64 PASS (4 файла). GPU latency повтор ещё не проводился.
