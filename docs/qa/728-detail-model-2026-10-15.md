# Отдельная модель быстрой сушки с мелкой структурой, 15.10

Код86d81732, ветка agents/728-watercolor-room-integration. Новая модель `front8-detail-v1` записывается в preset каждого мазка; старые версии сохраняют формулы. QA default остаётся одобренным Б `front8-fine-v1`. Для нового автора — `?qaFastDry=detail` на create/room QA. Production/push не выполнялись. Художественное одобрение Ильи ещё требуется.

Крупные мазки работают на S2. Внешний фронт получает стоимость высыхания в мировых единицах; искусственная граница рабочего окна затухает, физическая граница листа не обесцвечивает краску. Внутри движущегося мазка восстанавливаются бороздки точного исходного отпечатка с изменением, которое рассчитала крупная сетка. Неподвижная капля этого восстановления не получает. Оптическая плотность цвета восстанавливается отдельно от массы и затем связывается с P.b. Это приближённая новая численная модель, не побайтная оптимизация Б; сохранение массы не заявлено как отдельная доказанная теорема.

## Измерения

Синтетический engine Fine1024, кисть380, PB15/PY35, последовательные пересекающиеся жесты и ordered Dry. От CPU queue idle ждём завершения GPU чтением канонического тайла до остановки таймера; следующий rAF включён в frame gaps. Это не физический pen-to-photon. Samsung SM-T970/Adreno650 подтверждён Awake, powered/stayOn=true, keyguard=false; ноутбук headed Chrome/AMD Radeon Renoir, Monitor On. Эксперименты на каждом GPU эксклюзивны.

Перенесённый код: Samsung12 Dry8431,6мс, extra completion tail1024мс уже включён; GL0/no loss/no pageerrors. Ноутбук12 Dry2050,1мс, GL0. Предыдущий ABBA на том же алгоритме: Samsung12 Б22074–22079мс / кандидат8380–8444мс, ноутбук6881–6889 /2035–2042мс. Это примерно62% и70% сокращения полной Dry соответственно. Малые выборки без доверительного интервала.

Рывки не устранены: Samsung12 p95framegap568мс, max585мс в перенесённом коде. Нельзя объявлять задачу плавности закрытой по выигрышу общей сушки.

## Полная комната

На ноутбуке два участника headed Chrome, два широких пересекающихся мазка, Dry: peer exact0/max0; undo, redo, redo peer, перезаход, восстановление WebGL-контекста — exact0/max0. Экспорт и network snapshot доступны, GL0, pageerrors[]. Hardware identity отдельно зафиксирован в engine benchmark; room harness сам строку renderer не сохранял.

Samsung: настоящая QA-комната, два широких быстрых мазка, кнопка Dry, undo изменяет рисунок, redo и перезаход с повторным вводом имени возвращают те же canonical tile hashes. Экспорт PNG1978268байт, GL0/no loss/pageerrors[]. Первоначальный harness ошибочно ожидал engine после reload, пропуская форму Join; исправленный запуск прошёл. Проверка создания комнаты на портретном планшете использовала Enter для submit: pointer click перекрывался карточкой формы; удобство этой формы здесь не проверено.

## Другие варианты и пределы

S4 с корректным компактным размером поля и двухступенчатым уменьшением текстур: Samsung12 около5877мс, ноутбук1568мс, один прогон. На границе смешения заметна клеточная структура, в модель не включено. Первая попытка S4 ошибочно сохраняла минимум1536 вместо384/512: замедление не является доказательством бесполезности S4. Текстура S4 должна уменьшаться как площадь4×4, а не четырьмя центральными пикселями.

Продолжается проверка укрупнения групп контакта кисти. Текущая записанная detail-модель сохраняет прежнюю группировку. Результаты новых runtime override нельзя выдавать за поведение86d81732.

Компактные отчёты/воспроизводимые harness: `runs/728-detail-model-2026-10-15`. Запускать из disposable с TTL; Samsung harness читает приватную entry-конфигурацию с диска, секретов в архиве нет. Сырые пиксели и промежуточные изображения остаются в текущем временном каталоге до фиксации вывода и уборки. Два прежних QA frontend и один backend сохранены, новые постоянные сервисы не создавались.
