# Переход акварели к сухой картинке

Изолированная проба presentation-анимации (#324). Эндпоинты — реальные PNG
нынешнего движка до и после settle, захваченные на GPU. Каждый вариант точно
показывает исходную текстуру при t=0 и одну сухую текстуру при t=1. Физические
поля, история операций, checkpoints и production shader не меняются.

Плавное смешивание, пространственно неоднородное проявление и ограниченный
двунаправленный optical-flow morph сравниваются с прежней квадратичной кривой.
Flow считается заранее только для прототипа; это не готовый real-time алгоритм.
Он требует двух готовых изображений и может ошибаться в соответствии деталей.

`assets/cases.json`: `{cases:[{id,label,wet,dry}]}`; все пути локальны assets.
`flow.py assets` дописывает карты flow и SHA256 неизменённых PNG. Разработческий
venv: numpy/Pillow/OpenCV. Их нет в приложении Grafetto и его зависимостях.

HTML/JS можно сервить статически. Сравнение начинается после готовности сухой
картинки. В настоящем движке отдельно проверить ранний старт/истечение reveal
во время длительного settle и непрерывность при повторном касании мокрого мазка.

Управление: обычная сушка 12 секунд, начинается сразу после запуска, который
имитирует pen-up. «Высушить за 2 секунды» переводит текущий прогресс в Hermite
segment до 1, сохраняя позицию/скорость (ограничение касательной обеспечивает
монотонность). Сушка может завершиться раньше, если осталось менее 2 секунд.
В loop-режиме ускорение завершает текущую сушку без нового цикла.
