# scripts/archmap — эта карта

Генератор карты архитектуры: снимает граф импортов (dependency-cruiser), повторы (jscpd) и
историю правок, склеивает с описаниями из map.yaml и рендерит одну самодостаточную
HTML-страницу. `map:check` падает, когда код и карта разошлись.
