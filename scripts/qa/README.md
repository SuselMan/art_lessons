# scripts/qa

Численные QA-oracle для локальных диагностических вариантов движка. Они не
исполняются в приложении и не заменяют проверку WebGL на реальном устройстве.
Каждый скрипт обязан явно задавать входы, границы и область доказательства;
production-физика и журналы пользователя здесь не изменяются.
